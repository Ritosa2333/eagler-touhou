# 常见问题

遇到黑屏、下载失败或进不了房间，可以先按下面的步骤排查。

## 游戏打不开或卡顿

遇到闪退、黑屏、卡顿或触控中断，先更新浏览器，再打开同一作品试一次。

| 设备 | 建议先试 |
| --- | --- |
| Android | 最新版 [Chrome] 或 [Edge] |
| Windows | [Edge]、[Chrome] 或 [Firefox] |
| Windows 7 等旧系统 | [兼容指南](compatibility.html)里的 Supermium 安装步骤 |
| iPhone、iPad、Mac | 系统浏览器 |

Android 上建议优先使用最新版 Chrome 或 Edge。华为设备可以试试系统浏览器；其他设备的系统浏览器和部分第三方浏览器可能出现兼容问题。使用 Via、卓易通或夸克时遇到断触，可以先换浏览器排查。

> [!NOTE]
> 如果启动器打不开，或 WebGL 2.0 检测失败，请查看[设备与浏览器兼容指南](compatibility.html)。

## 资源下载失败

1. 暂时关闭 VPN，以及 IDM 等会接管下载的扩展，然后重试。
2. 如果仍然下载失败，可以改用资源导入包。

成功打开过启动器并下载所需资源后，断网或服务器暂时不可用时仍可能离线游玩。尚未下载的资源需要联网获取或手动导入。

## 加入房间和观战

联机使用点对点连接和服务器中转。连接失败时，在[联机大厅](lobby.html)打开「检查网络」，按检测结果排查后重试。

房间卡片会显示当前能否加入或旁观。部分作品支持开局后加入观战，具体玩法见[联机玩法介绍](multiplayer.html)。

## 存档与进度

「存档」可能指两件不同的事：

- **保存当前这一局**：游戏中途退出后，不能从原来的关卡、残机等状态继续，下次需要开始新的一局。一局通常约 25 分钟。
- **保存游玩记录**：成绩、通关记录等数据可以保存。它们保存在当前浏览器中，退出游戏后不会因此消失。

支持导入、导出的作品可以与对应原版游戏交换存档。例如 th06、th07 的存档文件通常叫 `score.dat`。

登录后，可以在个人主页的「云存档」查看支持同步的作品。

> [!WARNING]
> **存档按作品区分。** 即使文件都叫 `score.dat`，也要导入各自对应的作品，例如 th06 的存档不能用于 th07。

## 操作、攻略与剧情

- 启动游戏后，点右上角的「?」查看操作说明。
- 原作说明和剧情收录在[东方 Project 附带文档总览](https://omake.thwiki.cc/)。
- 想了解各作的系统和打法，例如妖妖梦的樱点系统，可以查阅 [THBWiki 攻略页](https://thbwiki.cc/%e6%b8%b8%e6%88%8f%e6%94%bb%e7%95%a5)。如果对东方 Project 的世界观或游戏机制还不熟悉，也可以从 THBWiki 开始了解。

## 可玩的作品

[启动器](./)列出已上线的作品，[联机大厅](lobby.html)列出支持联机的作品。新作品需分别适配运行、输入和资源，联机支持也按作品接入；二次创作的适配进度请关注项目公告。

新典因版权风险及投入等因素不在移植范围内。
