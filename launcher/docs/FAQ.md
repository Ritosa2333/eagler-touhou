## 遇到 游戏闪退 / 卡顿 / 黑屏 / 加载异常 / 断触 等问题怎么办？

推荐优先使用以下浏览器：

- **Android**：[Edge](https://www.microsoft.com/edge/download) / [Chrome](https://www.google.com/chrome/)，请使用最新版本，不建议使用 Via。华为设备不要使用卓易通或 Via，可以尝试系统浏览器。

    **其他 Android 设备不建议使用系统自带浏览器和各种国内浏览器。你也可以用，但可能会有一定的 BUG，如目前已知夸克浏览器会断触。**

- **Windows**：Edge（系统自带） / [Chrome](https://google.cn/chrome) / [FireFox](https://www.firefox.com/)
- 如果您在使用 Windows 7 及以下的版本，请使用[Supermium](https://www.supermium.net/) 作为上述浏览器的替代。
- 苹果：随意

若使用以上任一浏览器却仍然遇到了问题，再与我们反馈。

若旧版浏览器无法进入首页，或 WebGL 2.0 检测失败，请先查看[设备与浏览器兼容指南](compatibility.html)，其中包含 Supermium 安装和 Chrome OpenGL 后端设置步骤。

## 游戏有操作说明 / 攻略吗？游戏剧情在哪看？

本网站有自带的操作说明。启动游戏后，**点击右上角的 "?" 图标**，即可查看。

如果想看原版游戏自带的游戏玩法说明、游戏剧情，可以访问[东方Project 附带文档总览页](https://omake.thwiki.cc/)。

关于游戏攻略（比如想知道樱点系统怎么玩），可以前往 THBwiki 中的[游戏攻略页](https://thbwiki.cc/%e6%b8%b8%e6%88%8f%e6%94%bb%e7%95%a5)查看。

> 如果您对东方Project的世界观和游戏玩法了解不深，我们更建议您先去查阅 THBwiki，其对游戏机制的解析十分全面易懂。

## 游戏可以“存档”吗？

STG游戏存档分两个概念。

- 一种是「一局中途停下，退出游戏，能在下一次打开游戏时继续以原先的残机等状态玩这一局吗？」。
  这个答案是：**不能**。因为：原版/所有的STG类游戏机制便是如此。不过，一局游戏平均下来也就 25 分钟左右，很快就能打完。

- 另一种是「我的游玩数据，比如通关记录、游玩时长等非游戏内状态数据，能保存下来吗？」
  这个答案是：**完全可以**。并且通过测试，和原版游戏互通，存档文件为：“score.dat”。

>  **注：不同游戏存档不能混用!** 如 th06 的 score.dat 不能在 th07 使用。

## 还会增加其他作品吗？

已上线作品以[启动器主页](./)为准，支持联机的作品可在[联机大厅](lobby.html)选择。

其他作品需要分别适配运行、输入、资源和联机功能，公开进度请关注项目公告。

对于*新典*，我们**不会移植**。因为版权风险太大，并且性价比不高。

二次创作的适配进度也以项目公告为准。

## 下载不了资源怎么办？

首先，确认**没有使用 VPN**。

其次请避免使用会接管网页下载的浏览器插件，目前已确认 Internet Download Manager 等插件可能与网页资源加载不兼容。

站点成功打开过一次后，即使 服务器随后不可用 或者 你断网了，刷新或重新打开页面也可以进入启动器（较新的浏览器几乎都支持）。

实在无法下载的话，就请使用导入包了。

## 网络联机问题

联机结合 P2P（点对点）连接与服务器中转。遇到连接问题，可在[联机大厅](lobby.html)打开「检查网络」，查看检测结果后重试。

房间是否可加入或旁观，以大厅对应房间的入口和当前状态为准。支持旁观的对局可在游戏开始后加入旁观，具体功能由作品和房间能力决定。
