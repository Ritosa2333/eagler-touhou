# 游戏封面

[作品进度表](../../../../docs/TOUHOU_PROGRESS.md)使用 THBWiki 的 33 作游戏封面。

| 目录或文件 | 内容 |
| --- | --- |
| 当前目录中的图片 | 保持来源格式与尺寸的原图 |
| [`thumbnails/`](thumbnails/) | 最高 80px 的 JPEG 缩略图，表格中按 40px 显示 |
| [`sources.json`](sources.json) | 来源页面、下载地址、尺寸、字节数和 SHA-256 |

Windows 正作用 `th06`–`th20`，PC-98 用 `th01`–`th05`；小数点作省略点，如 `th075.jpg`。添加封面时同时补齐来源记录和缩略图。

封面著作权属于对应游戏权利人，使用遵循原素材的许可条件。
