Computers

Windows 7 and earlier

  1. Download and install Supermium（Alternative download）。
  2. Use Chromium 108 or newer.
  3. Run the WebGL 2.0 test. You can enter after it passes.

IE / older Chrome

Windows 10/11: install the latest Chrome or Edge。

Older Windows: install Supermium, shown on the left.

WebGL 2.0

Update graphics drivers

  1. Install the latest graphics driver and restart.
  2. Open chrome://settings/system and enable graphics acceleration.
  3. Restart Chrome andtest again。

Try OpenGL

  1. Open chrome://flags/#use-angle。
  2. Select OpenGL, restart and test.

If the option is missing, close Chrome and append this to its shortcut: --use-angle=gl。

Phones

Huawei

Avoid Zhuoyitong and Via. Try the system browser.

Other Android phones

Avoid Via. Install the latest Edge or Chrome。
