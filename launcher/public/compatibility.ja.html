ブラウザーが基本的な互換性チェックに合格しませんでした。

確認結果

  • ブラウザーと WebGL 2.0 を確認中…

パソコン

Windows 7 以前

  1. ダウンロードしてインストール： Supermium（別のダウンロード先）。
  2. Chromium 108 以降をご利用ください。
  3. 次を実行： WebGL 2.0 テスト。合格したら起動ページへ進めます。

IE／古い Chrome

Windows 10/11：最新版をインストール： Chrome または Edge。

古い Windows：左側の Supermium を導入してください。

WebGL 2.0

ドライバーの更新

  1. 最新の GPU ドライバーを導入して再起動します。
  2. 開く： chrome://settings/systemでグラフィックアクセラレーションを有効にします。
  3. Chrome を再起動し、再テスト。

OpenGL を試す

  1. 開く： chrome://flags/#use-angle。
  2. 選択： OpenGL、再起動して確認します。

項目がなければ Chrome を終了し、ショートカットの末尾に追加： --use-angle=gl。

スマートフォン

Huawei

卓易通と Via は避け、標準ブラウザーをお試しください。

その他の Android 端末

Via は避け、最新版を導入してください： Edge または Chrome。
