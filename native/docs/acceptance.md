2026-11-27 范围更新：个人主页及全部账号界面使用正式站网页，原生只维护书架、游戏详情及设置、联机大厅和必要配套。旧原生账号、资料、裁切及关系列表的实现与专用验证已归档。当前迁移状态见[账号网页入口](account.md)。


当前视觉验收以[四类核心界面](baseline.md#当前交付范围)为范围。账号、消息、云存档与联机配套亦为支持范围，可复用网页。其余独立页面已[归档](../archive/web-only/README.md)，下表的 CONTENT 阅读页、状态页及 WHR 独立总榜记录为历史证据，不再作为原生维护或交付门槛。

当前核心 UI 候选的源码、Windows 包与截图已对应登记，按[交付记录](evidence/windows/ui-handoff.json)开始用户验收。

## 平台检查

Windows 的悬停、详情、切栏、排序、滚动和弹层使用同一 SDK 的 Release 产物采集实际 `FrameTiming`，普通与减少动画另做控件回归。两轮波动、首进编译、后台计时和文件计算见[性能验收记录](../archive/performance-20261128/report.md)。其他平台设备帧率不由 Windows 结果推定。

macOS、Linux 和 iOS 已补齐官方启动工程与应用配置，当前处于源文件检查阶段，未编译验收。各平台的系统能力、最低系统版本、构建命令及设备缺口见[平台清单](platforms.md)。

- Windows x64 Release 预览包已通过进程启动和实际页面走查。系统文件选择器已完成 th06 DATA 导入、取消及返回验证，安装文件与发布清单哈希一致。更新包已从真实系统选择器验证取消后按空格重新打开。th09 存档、单个录像和录像 ZIP 经实际系统对话框导出，大小与 SHA-256 均一致。[文件往返](game.md#windows-存档与录像往返) Windows 目前使用 Skia 兼容路径，首帧白屏的触发条件仍待稳定复现。[兼容说明](../README.md)记录了重新启用默认渲染器前的复验项。
- 早期 Android 0.1.0 Release 预览包保留为历史构建记录：当时核验了调试签名、启动 Activity、最低 API 24、目标 API 36、arm64-v8a、armeabi-v7a、x86_64 和 64 位原生库的 16 KB 对齐，以及包内作品目录、封面、快捷语音和 Cupertino 图标字体。当前按用户要求不运行 Android 构建或设备测试，手机布局在 Windows 上以 320 和 390 px 回归。早期 APK 的结果不代表当前源码已完成 Android 验收。

Windows 自动化批量填字在搜索框未生效，普通按键可输入并检索。现象与已知的[工具合成快捷键兼容问题](https://github.com/openai/codex/issues/43575)相符，目前未验证本次运行中的底层键码。中文输入法及实体键盘快捷键仍须人工复验。

逐项给出来源、控件位置、输入和预期结果。截图采用同主题、视口、语言和数据。返回、滚动、键盘、触屏和减少动画用实际入口检查。按 Windows、Android 记录安装、启动、交互及退出。原生游戏执行以确认占位反馈并返回发起页为验收。
