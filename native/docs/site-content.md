# 站点入口与网页

桌面工具区与手机抽屉仍为核心导航的一部分，沿用现有位置、分组和共用账户卡。主题和语言继续使用现有 Flutter 控件。

帮助、首次使用、联机玩法指南、关于、隐私、条款、支持、服务状态及独立排行榜通过系统浏览器打开正式站。链接携带启动器语言，明确指定的语言参数沿用原值。打开失败在原页面提示，书架搜索、滚动与路由不变。

账号表单、条款、隐私同意，以及个人主页内的评分、战绩和录像，均由正式站应用内网页负责。对应旧 Flutter 实现已归档。大厅和等待室的评分卡随联机配套维护。

[旧页面规格与证据](../archive/web-only/docs/site-content.md)已归档，不再跟进原生布局、翻译和平台适配。[归档目录](../archive/web-only/README.md)记录停止维护的实现、专用测试和资源。
