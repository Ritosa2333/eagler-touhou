# TH02 网页练习工具

首版：2026-10-24，配置身份 `th02-browser-practice/1`。参照 移植交接（原工作区本地文件 `../TH02-04-PRACTICE-PORTING.md`）、TH04 网页实现和 TH02 原生状态机接入，运行入口为 `web/solo.html`。

## 使用

运行 `start.bat`，进入单人游戏。默认仍从原版菜单开始，保留原版资源、拾取、死亡与关卡流程；辅助默认关闭。页面上的“特定练习”按钮或 F12 可选择练习目标。

| 操作 | 行为 |
| --- | --- |
| Backspace | 展开／收起右侧紧凑辅助菜单；辅助快捷键仅在此菜单展开时切换 |
| F1 | 原生碰撞先消除命中弹，再消费受击；Miss +1，不死亡、不追加无敌帧 |
| F2 | 保留死亡动画、掉火力、掉道具与复活，绕过备用命扣除和最终 Game Over |
| F3 | 0 Bomb 也能走原生发动流程，不扣库存；统计实际发动次数 |
| F4 | 锁住开启时的火力，默认关闭；关闭后原生拾取恢复 |
| F5 | 阻止实际超时／循环耗尽结束，保留攻击推进；HP 击破仍结束 |
| U | 原生射击／Bomb 碰撞仍运行，返回给敌人的伤害为 0 |
| Shift+D／A／S | 禁用 Bomb／网页扩展低速／射击 |
| Shift+F | 紧凑菜单展开时重试已提交的特定练习配置，保留当前辅助 |
| Tab | 独立开关右侧 Miss、Bomb、火力、Rank 与时间统计 |
| F12 | 打开实际游戏图像范围内的设置面板，并请求原版暂停 |

F12 面板支持鼠标／触屏点击；Tab／Shift+Tab 移动焦点，未编辑下拉框或数字时也可用 ↑／↓ 移动焦点，Z／Enter／空格确认，F12／Esc 收起。面板内的 Tab 用于导航，收起面板后才用于统计开关。退格菜单展开时，左侧场地仍可触控移动。

特定练习固定 **0 备用残机、0 Bomb**，保留当前生命；火力 1–80，动态 Rank -6–16（Easy 原生上限 4）。到达目标后进入原版暂停，Enter／Esc 恢复。准备时静音，通过原生移除标记清理准备弹幕与道具，清除受击、死亡和无敌计时；道中／关底入口先让原生关卡标题清除回调完成，再初始化目标。中弹失败或完成所选范围后停在结果菜单，可以保存本次 REP、手动重试或另选目标。结果菜单支持 ↑／↓、Z／Enter、X／Esc；未提交的表单编辑不会改变重试起点。

默认独立 BGM 在普通游玩、录制与回放中均保持真实音频时钟，25%–200% 游戏速度不改变音乐速率或重启当前曲目。声音选为“原版声音”时使用模拟器音源。低速、判定点、按键自定义、手柄与触控沿用现有单人实现。

指定道中／关底／攻击的准备期间，在原生 Boss 更新之后、道具／激光／子弹更新和绘制之前，使用本作的移除标记清理普通弹丸、掉落物及独立激光池（包括蓄力中的激光）。下一循环由原生擦除函数释放对象；使用原生整场地重绘标记覆盖两个缓冲页，动态 Boss 背景保留自己的绘制流程。到达目标后停止清理，保留目标初始化和恢复后的正常出弹。完整流程和关卡开头不执行这项准备清理。此项为参照 TH05 修复记录对 TH02 的预防性审计，发现此前漏清独立激光，并非用户已在 TH02 实测复现。

## 预载快速重试

F12 高级设置默认启用“预备快速重试（额外内存）”。当前特定练习入口就绪后，后台只预备下一次尝试；菜单出现“下次重试已就绪”即可用 Shift+F 或结果菜单直接切换。切换仍停在原版入口暂停，需要按 Enter／Esc 继续。目标始终使用上次提交的配置，保留当前辅助和速度，清除上一局按键与触控。

预载会独立启动同一练习目标，完成原生换段、准备期清弹和入口暂停，再在正常宿主 sleep 边界挂起 JSPI，并冻结练习时钟。停放期间不会推进弹幕、增加录像时钟或累计练习时间。切换后才记录并应用当前辅助选项；每次尝试保留自己的启动记录、音乐桥与 REP，可在新页面独立回放。它是轮换独立实例，不是即时存档，也不保证每次启动的随机种子相同。

若重试时尚在预备，会等待该实例；预备失败则回退到正常重新加载。重新提交目标、改变语言／声音／录制、返回完整流程、关闭预载或离开页面都会释放旧预备实例。每次切换后再预备一个后继；普通完整流程不预载。

代价是预备期间增加 CPU 使用，并额外保留一个模拟器。当前样本约增加 92 MiB Wasm 内存，另有磁盘、音频和录像缓冲；内存紧张时可在 F12 取消此选项。首次进入和尚未就绪的远期目标仍需正常准备。

## 练习目标与适配边界

关卡开头覆盖一至五面与 Extra；一、二、三、四面及 Extra 的真实道中 Boss 均可直接进入，五面没有道中 Boss。所有六场关底 Boss 可整场练习。

| 关底 Boss | 独立攻击 | 原生 HP／累计伤害依据 |
| --- | --- | --- |
| 里香 | 1、2、3 | 累计伤害阈值 700／1400，整场至 2261 |
| 明罗 | 1、2、3 | 累计伤害阈值 701／1501，整场至 2400 |
| 三面五块石头 | 仅整场 | 原生五体 HP 140／140／120／120／930 |
| 魔理沙 | 仅整场 | 900 |
| 魅魔 | 1、3、5、7、9 | 各攻击 600／700／800／1500／1100；偶数为原生过渡 |
| 玄爷 | 1、3、5、7、9 | 各攻击 1800／1800／1800／1800／1300；偶数为原生过渡 |

“正常开始”练完整场；指定攻击在原生换段后结束本次尝试，不继续操作后段。同一边界受击与击破同时出现时优先失败。关卡开头在所选关卡结束时结算。

单体 HP 可设为当前攻击原生范围内的值，0 表示原值。关卡开头、三面双体道中、五块石头及 Extra 无 HP 脚本道中暂不提供自定义 HP；界面禁用该字段，不将多体伤害伪装为单体 HP。Extra 道中由 420 帧脚本结束；F5 循环完整脚本。其他道中的期限、双体往返次数、四面横移次数和魅魔攻击次数分别接入原生比较；里香、明罗、石头、魔理沙、玄爷没有可统一冻结的固定攻击超时。

## 实现与资源保护

仅单人使用独立 MAIN 覆盖和 `wdosbox-x-practice.wasm`，启动时安装到本次运行的磁盘副本。现有四张发行盘、多人入口、原生 EMS HUD 与根目录 HUD 基线保持原样。

- `patches/practice.asm`、`tools/build_practice_assets.py`：固定中日文源 MAIN SHA、逐条核对 Hook 字节、MZ 重定位和空间预算，生成 `practice-{cn,jp}.exe.gz`、启动器与清单。
- `tools/build_practice_core.mjs`：核对源核心 SHA，在 OUT32 分发中同步接入 `0x7fd0` 加载、`0x7fd1` 输入前、`0x7fd2` 原生死亡前、`0x7fd3` 魅魔／玄爷换段比较前、`0x7fd4` 碰撞后及 `0x7fd5` Boss 更新后、实体更新前边界。描述符为 `T02PRA01`，29 个 16 位条目。
- `web/practice-{config,assets,engine,ui}.js`：本作配置与目标表、身份校验、同步状态控制和界面。原生内存写入只在上述同步回调完成。
- `web/solo.js`、`dosbox-adapter.js` 与 `replay/external-*.js`：整合单人重启、辅助／变速事件、结果边界、独立音乐与 REP。成功／失败在普通宿主 sleep 边界封存，每次尝试单独录制；新页面恢复同一磁盘覆盖与音乐桥，校验完整终态客体内存 SHA。

未知资源身份和旧版 REP 不强行兼容。练习配置仅用于 TH02，不能改其他作品录像后缀使用。

## 验证范围

原生 Unicorn 测试覆盖中日文 28 组分支、寄存器、段、栈、F2／F3、F5 超时比较、原生对话跳过及新增实体前回调的近返回 ABI。真实浏览器入口矩阵覆盖中日文 66 项：12 个关卡开头、10 个道中、12 个整场关底及 32 个独立攻击，检查目标入场、原生标题清除、暂停恢复、0／0 库存、满火力射击等级，以及普通弹丸、激光和道具池完全释放。另检查默认完整单人、原有键盘重映射、手柄／触控与窄屏布局。辅助功能 QA 明确使用同步边界的弹丸／道具夹具，不能当作自然游玩或 REP 证据。

`tools/test_practice_entry.cjs` 在中日文里香第 3 攻击、玄爷第 3 阶段中，明确注入普通弹丸、道具、蓄力激光和发射激光，核验其在绘制前标记移除、原生更新不再处理、入场前完全释放，并等待恢复后的自然出弹，确认清理和整页重绘均不会持续。`LEGACY=1` 为预期失败的反向对照：仅去掉激光清理，同样夹具会保持存活并进入暂停。该夹具报告不是自然 REP 证据。

成功与失败 REP 另用自然射击／自然中弹生成，在新页面导入重播，核验终态内存 SHA；同时检查默认开启录制下 50%／200%／100% 切速的独立音乐速率、曲目代数和音频时钟连续性。报告保存在开发机 `reports/practice-*.json`，应结合各报告的资源身份与对应代码阅读。

这些检查不代表全部难度、三种射击类型及每个目标的全程自然通关，亦不代表实体手机／手柄长期验证。三面石头、魔理沙目前只开放整场练习；后续细分需继续审计其实际状态与初始化依赖。
