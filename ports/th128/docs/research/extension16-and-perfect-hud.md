# Eighteen-record extensions and partial authored front HUD

## Evidence boundary

All executable observations use the pinned Japanese TH128 executable as
read-only bytes. No original Windows game process, allocator/API return stub or
original-directory write is involved. A returned isolated helper does not prove
an original full frame or full initialization. Unknown calls retain diagnostics.

## Emitter records and original537

The emitter contains18 records of44bytes. Their native order is four floats,
four integers, type, control and callback. `ExtensionRaw` retains neutral names
R/S/T/U,A/B/C/D rather than assigning unproved behavior to every field.

- Original509 changes R/S,A/B,type/control and preserves the other words.
- Original537 changes the first ten words and preserves callback. Selected
  slot15/index17 and adjacent-byte preservation have original fixtures.
- A type2 first record consumes record0 at birth and sets index1. The remaining
  record images survive into real bullets; emptiness checks the actual current
  type, not an assumed globally empty pool.
- The native executor tests index<18, record type, control and active flags
  before dispatch. Other types/control/callback paths still stop explicitly.

## Proven type16 mode2 subset

Actual GirlD1 uses record1: control0,type16,A60,B1,C2,D0,R0,S-999,
T/U-999999. Production supports the original bounded mode2/angleMode0 subset.

Original executor initialization retains the supplied angle offset, uses current
speed when S<=-999, resets the native timer, sets active bit16 and advances index.
The sampled initialization has no sound even with a nonnegative transform sound;
the updater does require its sound at the restart boundary. Those are distinct
calls, not a fabricated shared audio rule.

For elapsed<period, the updater recomputes temporary motion speed from the retained
base speed using `base - base*floatTime/period`, stores the velocity components
separately, and increments the initialized unit-clock timer once. It does not
decrease the stored base speed on every tick. At the original period boundary,
after any required sound, it increments the repeat count, obtains the genuine
player aim, adds/normalizes the offset, restores target speed, resets time, and
clears active bit16 at the authored limit.

Pure rules compare all state words with real initialized helper returns in
ordinary WASM and UBSan. Six additional original full pre-ANM update cases execute
the executor, type16 updater, movement and tail as one original trace. The host
matches exact position/velocity, half->full transition, timer and lifetime.
Cooldown3 becomes1 because the original decrements it in both the extension phase
and frame tail. A regression caught the missing first decrement.

The host resumes at the original extension continuation, never restarts the body
life clock or repeats a half-step. Required sound failure and reentry are sticky;
the callback cannot clear the retained failure by erasing its output string.
Malformed previous-time arithmetic is rejected before signed addition, covered
by a failed-then-passing UBSan case.

## Fourth-death authored charge HUD

The fourth ordinary death reaches Perfect Freeze charge10000. The original
mandatory calls are sound72, charge notification424b80 and charge UI425820.
They are not simply acknowledged as successful callbacks.

- `PerfectHud` executes the original `front.anm` root0 and13 children, preserving
  actual script IDs/sprites, coordinates, alpha/scale changes and lifetimes.
- Notification case2 requires replacing its previous handle with actualfront47,
  native layer23. The native factory itself remains an emulation boundary; the
  portable host supplies its real Scene construction, not an invented native
  allocator return.
- Original425820 is executed to a real return on an explicit intrusive root and
  three child nodes. It enables child12/13/14 at10000/20000/30000 respectively.
  The portable operation updates those actual child draw flags.
- Actual47 replacement, authored110-tick ending and collection are tested.
  The currently executed front scripts have no RNG reads; a future RNG request
  stops instead of introducing a guessed independent RNG stream.
- Browser loads original front bank5. Desktop and390px checks show the original
  frame and notice,15 nodes at the threshold, four deaths and charge10000,
  without page errors or horizontal overflow.

This is not the complete native HUD/controller initializer. Numeric score/high
score/motivation/power/frozen-area text, all UI handlers, full lives/options,
Perfect Freeze use and the rest of the game remain separate obligations. Existing
explicit eight control-callback snapshots are still not native initialization.

## Additional native semantics corrected or enabled

- ANM82 dispatch45c501 writes the directional bit0x40000000, not the inherited
 0x20000000. Type20 draws use retained original emission angle plus native half-pi
  normalization, rather than recovering the angle approximately from velocity.
- ANM85 dispatch45c494 writes bit0x80000000, not bit0x40000000. Actual-front
  assertions first exposed the wrong inherited mapping; only this proven flag
  meaning was changed.
- Typed inherited lvalues-9981/-9980 resolve to Enemy+1414/+1418, existing word4/5.
  Four integer lvalues-9985..-9982 resolve to1404..1410, word0..3. Typed writes,
  readbacks and actual spawn inheritance are tested without arbitrary-address
  writes. Unproved globals still fail closed.
- Difficulty predicates-9953..-9950 compare equality with0..3. Twenty original
  integer returns and20 original float pre-return stack samples establish this.
  An initial disassembly interpretation of float inversion was disproved by the
  executed values; it was not propagated to production.
- Original261 prepares absolute coordinates with mode1 and retains inherited
  words. Native mode1 still mirrors applicable angles. A synthetic inheritance
  test originally used260 and therefore saw pi-angle; the fixture was corrected
  to ordinary257 rather than changing native mirror behavior.
