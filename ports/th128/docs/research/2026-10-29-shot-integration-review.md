# Main-Thread Shot Integration Review

This is a main-thread review and regression log, not an independent-agent review.
The user explicitly stopped all subagents and prohibits further delegation.
No original Windows game process, installer, branch, commit or external publication ran.

## Corrected Findings

1. Real pl00 shot scripts5/7/9 use mode1. The native returning0x45fad0 helper
   and its stored FSINCOS pair are now executed separately and matched in WASM;
   axis-aligned or renderer-only corners are not substituted for lifecycle bounds.
2. A reused slot is not fresh zero memory. Native dirty-slot vectors expose
   retained angular flag+0x44; unsupported angular reuse rejects. Genuine ordinary
   reuse preserves native-unwritten fields and resets the actual timer stores.
3. Native positioned shot sound uses the born shotX, not playerX. A regression
   checks the real negative first-shot offset. Requests are journaled; live game
   sound playback is not claimed.
4. Shot pool identity and replacement ANM handle are independent. Replacement
   gets a new bounded handle and shot-owned primary updates follow handle birth
   order. Full ordering against every global ANM system remains unverified.
5. A callback that returns true with a diagnostic, throws or reenters cannot
   authorize completion. Sticky failures preserve committed hit state and prevent
   repeating birth, effects or impact settlement on retry.
6. Native first positive query impact precedes reading the2000-source secondary
   pool. A callback that activates a source now produces a required source-contact
   boundary, not a fabricated complete zero-source result. Pending queries do not
   publish a completed damage total.
7. Enemy after-ECL processing clears0x400000, then flags0x21 gate the ordinary
   shot query. Six executed native prefixes and guarded world tests cover this.
8.402/403 visibility is level-triggered on existing ANMs. A mutated actual first
   enemy ECL initially still drew a hidden sprite; the runtime now applies the
   real Hide/Show result. A genuine missing owner is a lookup-miss no-op.
9. Player normal state/focus timers advance before shot/enemy phases only in
   the explicit shot context; they are not frozen constants used to bypass the
   native equal-time query gate.

## Supported Delivery Boundary

The browser shot diagnostic uses actual resources and explicit live-null
callback bindings, cumulative area0/difficulty1 and2000 inactive secondary flags.
It emits, moves, animates, retires and reuses real shot slots. Its first enemy
contact intentionally stops at0x43ec8a without decreasing HP. The optional core
can execute replacement hit ANMs and requires a genuine impact host before it
returns damage. The browser does not silently opt into a fake reward handler.

PlayerFireRules supplies only actual head/charge prefixes and mandatory call
requests. Z input, full charge presentation, freeze release, audible game sounds,
world damage/post-damage scripts, enemy death/items, complete player death/respawn,
STD backgrounds and full-stage progression remain incomplete. The first-stage
and full-port plans must stay open regardless of component test totals.
