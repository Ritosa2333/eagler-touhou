# TH128 单机行为还原基线

这是《妖精大戦争 ～ 東方三月精》的独立 C++ 行为还原，不是原作官方源码或逐指令还原。`restoration` 保留原作逻辑与验证记录；`portable` 在其 Git 历史上增加可重建的原生目标。Web 启动器、练习辅助和联机各自验收。
