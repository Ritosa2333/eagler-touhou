# 录像累计擦弹数保真修复（621–627）

原版录像的每关头部在字节偏移0x28保存累计擦弹数。原生录制器未写入该字段，回放恢复器和绑定器也未处理它。621使用未修改的原版第二关头部和实际private101初始化World，在0次游戏更新下复现：恢复接口返回成功，但2529次擦弹变成0。

修复只涉及NativeRunReplay、OwnedReplayPlaybackInput和WorldExports三个原生文件。普通路线和EX录制生产调用传入实际计数；恢复器在完整头部校验及HUD充能成功后恢复计数；绑定器要求实际计数与头部一致。冰冻能量、随机数、输入数据、通关和成绩许可不因该字段改变。

支持的录像计数范围为0至1,000,000,000，沿用已有内部关卡交接校验范围。初始enable_graze接口仍限制0至99,999,999；正常擦弹自增上限也保持不变。这两个范围并不相同，本修复没有调整物理或数值增长规则。旧录像头部为0时仍可恢复和绑定。

## 边界

这是录像字段保真修复。当前源码没有把累计grazeCount用于碰撞、生存或游戏RNG计算，不能把此修复称为解决了617在4906帧提前GameOver的问题。完整23707帧兼容性仍未通过；本轮没有重跑整段录像、六线或EX。

[摘要与产物摘要值](native-replay-graze621-627.json)保留实际范围。源码对应private102，运行产物在私有验收目录；公开运行目录、浏览器及设备验收状态保持原样。日文、续关完整终局和独立部署等剩余任务见[状态表](STATUS.md)。
