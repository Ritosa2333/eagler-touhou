# DSH 首轮交付复核（2026-11-16）

本轮复用六个驻留 DSH，分别负责协议与构建、高刷新率与焦点、触控、多语言、练习、Replay与终局。已完成的六线及 EX CPU 验收继续沿用，没有重复完整路线，也没有重编成功的 core100。

## 已整合修复

结算菜单处理松键时，原逻辑仅通知菜单输入对象，没有清除页面保存的按键和抑制集合。这可能把已松开的键带入返回后的主菜单。

DSH 定位该问题后，MAIN 用完整生产 keyup 处理器复现失败（case589），按最小改动清除对应键后通过同一断言（case590）。Git 目录内另用真实 `OriginalMainMenuController` 验证五种按键释放后只接收仍被保持的按键，且无额外确认边沿；EX 控制器六项回归通过（case592）。测试的原生与设备接口为明确模拟边界。
