# 妖精大战争 · Runtime116 v8

本地网页版运行包，包含已验收的第三步六项Web适配及真正TH128 thprac。复用成功core116，未重新编译核心。原DAT＋OGG资源ZIP另附，继续使用原来的同一份资源包。

1. 解压Runtime ZIP；需要Python 3.9或更新版本，以及支持WebGL2的浏览器。
2. 在解压目录运行`Start.ps1`。也可在PowerShell运行`powershell -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1`。
3. 打开窗口显示的地址，默认`http://127.0.0.1:8140/play.html`。
4. 首次选择`th128-dat-ogg-5e3bcbd5ebb8b171.zip`，等待校验后点击“开始游戏”。以后用同一地址会读取已安装资源。

新包使用8140端口，与旧版8138分别保存资源、设置和存档。如端口已占用，可运行`Start.ps1 -Port 8148`。不同端口的浏览器存储各自独立。无需停止或刷新旧版页面。

方向键移动，Z射击/蓄力，C连射，X完美冻结，Shift低速，Esc暂停。路线选择页自动显示thprac；Backspace显示七行辅助工具，F1–F7切换辅助，F12打开高级速度选项。练习Replay随文件保存参数，播放时锁定现场输入和练习修改。

逻辑默认固定60Hz；显示插值与逻辑分开。实际流畅度取决于设备。原版旧录像617兼容性、物理手机多指等额外兼容项目单列维护。浏览器字体栅格不保证逐像素等同原版ImGui。

本包没有内部验收控制栏，不包含个人存档、测试夹具或Windows THPrac注入工具。关闭服务终端可结束本地服务。全部运行文件在本机，不需要公网部署。
