# Pause owner async regression

Run `node tests/pause-owner/check.cjs` for the current checkout. Optional arguments select an exact alternate sound.mjs and play.mjs pair for admitted RED/GREEN verification. The test runs real production JS with synthetic native/audio/DOM seams and explicit entered/release barriers.

The nine scenario helpers originated from the resident DSH revision2 packet; the previous presentation-at2 preflight was rejected because that barrier was never reached. MAIN added late-error, unchanged-action and whole page-caller checks, then independently ran599RED and600GREEN. Git delivery602 also runs the related sound/EX/Main suites.

This does not execute original game code, construct a native World or prove device audio lifetime. See ../../docs/port-pause-owner600.md.
