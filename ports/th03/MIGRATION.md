# TH03 DOSBox-X 迁移记录

日期：2026-10-13。目标为独立目录 `th03-pc98-fast`，原项目保持只读。

单机页入口修正：初始 #screen 增加 screen 定位容器，将等待遮罩限制在游戏区域；播放器挂载后移除外层 screen 类，仍由内部 viewport 保持游戏画面比例。启动前不进入 immersive，完成资源挂载后再进入游戏布局，系统全屏由玩家点击全屏按钮。仅静态检查，待用户复测。

用户要求：沿用 TH03 当前按键与设计；用户亲自逐步测试。没有启动服务、浏览器、游戏、音频或真实联机，不能宣称玩法回归通过、启动成功或性能提高。

单人启动设置：启动按钮旁新增“启用低速（按住空格）”和“低速时显示判定点”。与游戏内“按键与触控”面板的原有设置双向同步，沿用原存储键、低速及判定点实现；低速关闭时判定点选项禁用，但保留已保存的偏好。键盘玩家可在启动前设置，无需开启触摸模式。

启动按钮修正：solo-worker-client.js 初始化时两次解构声明 onError，导致浏览器 ES 模块解析失败，单机页及本地双人入口无法绑定启动事件。配置回调改用独立局部名称；新增 solo-bootstrap.js，在页面初始化完成前禁用启动按钮，加载失败时直接显示具体错误并提供刷新。资源审计强制使用 ES 模块语法检查，避免 Node 自动解析模式漏掉重复声明。仅静态检查，游戏启动待用户复测。

开头动画／资源挂载修正：TH03 的 ZUNSoft 动画由 OP 前的 `zun -3` 播放，原快速启动仅在 OP 前恢复 CPU 预算，导致整段动画使用驱动初始化的 1000 cycles。现在在每个 `zun -3` 前恢复本地 max 100%／联机 30000，OP 入口仍恢复同一预算。FAT12 文件名改用 Shift-JIS/CP932 解码，与 TH04 挂载逻辑一致；原来逐字节转成 Latin-1，使 `夢時空1.DAT` 和 `夢時空2.DAT` 的 MEMFS 路径成为乱码。内容及磁盘目录不修改，导出仍按原目录项偏移写回。新增两语言数据包名称／原字节、六个动画入口预算与六个 OP 入口预算的静态检查。动画卡顿的配置问题已确认；黑屏是否完全消除，仍待用户在电脑上复测。

## 已接入

- 从 `th04-coop-lab` 复制固定 DOSBox-X/js-dos emulators 8.5.2、JSPI/完整 Asyncify WASM、4 KiB SIMD undo helper、原生状态/FS/continuation 回滚和直接画面呈现。
- 原 TH03 app/solo 入口及 Worker 改调 DOSBox-X，保留 controls.js / fire-control.js / native-pause.js / native-music.js / 原生 EXE/COM / 磁盘。
- 专用键码转换支持 TH03 原生 P1 T/B/F/H/Z/X，P2 数字键盘 8/2/4/6 与方向左右射击/攻击；页面可见按键与连发／蓄力不变。
- 从原 HDI FAT12 提取 YUMEZIKU，保留全部游戏文件，执行原 GAME.BAT；临时 FASTBOOT.BAT 的六个 OP 入口前恢复 cycles，跳过原系统 DOS/VEM486 的启动。
- setHdd/reset 改为等待异步结束；MEMFS 写入通知带回磁盘名，变化写回原私有 HDI；原单机导出恢复原版 MAIN/音乐脚本流程保留。
- 本地双人采用现有 Worker 通信体系，发布只读 TH03 游戏状态／判定点，暂停和认输请求在 worker 内操作原生桥接。
- 网络在无用户输入下确定性推进到选人，保存启动校验，双方资源/状态一致后统一输入同步。预启动定期让出任务，慢设备等待窗口延长；房间/传输 API 保留。
- 网络帧模拟／回滚期间不提交可见画面，完成 pump 批次和重算后在同一任务中绘制 DOSBox WebGL 底图并提交到可见 canvas。
- 网络 wire/schema 为 th03-rollback/3，relay 同步更新；回滚开关、12 帧窗口、方向预测、两帧非回滚缓冲、席位、暂停/认输/隐藏状态沿用 TH03。
- 服务正确返回 .mjs MIME；默认端口本地 9876、联机/隧道 9877；隐藏失去含义的 NP21 MHz 控件，保持兼容 clock 字段固定为 32。

## 证据

`reports/migration-static-audit.json` 检查原项目 205 项基线、TH03 原按键/桥接、引擎和联机摘要、两语言磁盘、临时启动脚本的原命令保留、模块引用和 JS 语法。Python 仅解析语法；没有执行游戏逻辑。文件审计调用 FAT12 读取、内存中的补丁打包和资源提取，未启动 DOS。

三个运行 WASM 与当前 TH04 文件字节相同。JSPI 包装器额外导出 MEMFS/nativeExports 供文件写回通知。源项目文件哈希在迁移前存于 `build/source-baseline.json`，用户在旧项目另作修改后该对照检查需相应更新，不能将差异当新项目损坏。
