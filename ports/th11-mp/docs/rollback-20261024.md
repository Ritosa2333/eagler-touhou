# TH11 回滚绘制与性能验收 | 2026-10-24

局部绘制版本在本轮生产包检查中通过两端原生状态、精确 Replay 和完整游戏区域像素对照，但未通过 100 ms 长尾性能门禁：两端最大呈现停顿为 224.1 / 178.6 ms。同一修正后脚本下的基线通过本次门禁。当前结果没有建立绘制改动的性能提升或稳定通过门槛的结论。

本轮检验 TH11 MP 的局部绘制改动：显式传入四边形几何模式，省去临时修改、恢复 VM flags；将只写栈上几何或字形 VM 的计算放入已审查的 `HostScope`；同次多人几何提交复用透明度查询。模式 5/7 的真实矩阵与 flags 修改继续进入日志。所有权机制见[整堆回滚设计](ROLLBACK.md)，正式性能准入见[开发指南](DEVELOPMENT.md)。

这是 2026-10-24 新执行的构建、Wasm 回归和浏览器检查，原始回执与产物保存在 `artifacts/rollback-20261024/`。本页和[机器摘要](rollback-20261024.json) 从这些文件直接提取身份与数值，原始回执哈希在提取时重新计算，程序与输入身份按各次回执分别保留。它们不重建、替换或重新标记 [2026-10-23 记录](rollback-20261023.md)：此前 `jr-10` 的正确性通过、100 ms 长尾性能失败结论继续保留。

## 启动乱序的独立证据

`draw-unprofiled-01/peer-1-failure.json` 中，HELLO 的注入序号为 1，READY 为 2，`startupBytes[28]` 分别为 1 和 2。旧注入器为每个包独立设置定时器；其计划 due 值按序递增约 0.001 ms，实际发送顺序发生反转。

| 席位 1 发送端的本地时钟（ms） | HELLO | READY |
| --- | --- | --- |
| `scheduled` | 6521.0 | 6521.5 |
| `due` | 6573.394339127932 | 6573.395339127932 |
| `actual` | 6573.299999999814 | 6573.0999999996275 |
| 包签名 | 2508141854 | 1163064845 |

接收端 `peer-0-failure.json` 用匹配的包签名记录 READY 在 7386.799999999814 ms 到达，HELLO 在 7387.700000000186 ms 到达。两个先后判断分别在自己的页面时钟内完成，没有相减两端时钟。记录与生产会话对 READY 先于 HELLO 的拒绝一致。

本证据解释该次测量前的握手拒绝。FIFO 修正位于验收延迟注入器，保留生产握手检查；新可比组的脚本身份已由两份最终回执核对一致；FIFO 回归结果见下节。其他运行的长尾按各自测量记录描述，不从这次握手异常推定原因。

## 时间口径与证据保存

原生耗时为包含图形提交与可能等待的 wall time，呈现节奏在回调退出时观察计数器变化。最长停顿的分解保留回调内和回调外时间、完整回调中的 native/shell/observer 分量以及窗口边缘截断。分项只解释已观测时间的归属，不把回调外空档或同时发生的发送迟到直接归因于某个模块；原始停顿仍按 100 ms 门槛判定。

本轮正式性能比较不启用阶段 profiler，因此没有新的 capture/Update/Draw 分项性能结论。像素读回与 Replay 对照均在性能窗口之后。JSON 保留所有回执的哈希、状态、失败对象、源码与 Runtime/脚本/输入身份，以及每端关键分布和正确性结果；逐回调数据、Replay、原始 RGBA 与原始回执留在本轮 artifact 目录，不嵌入摘要。

独立只读审查另复核了每轮 19 个身份文件、全部 peer/Replay/RGBA 哈希及核心指标分布；实际 5,758 个发送包未见 FIFO 倒置、提前 due 或丢失注入序号，结束时队列计数与字节数归零。绘制版本 14 个超限呈现区间中，13 个以回调外时间为主，5 个包含待完成纠正、2 个包含网络等待；这些是区间属性，审查未对停顿或两次运行差异确定因果。完整机器审查位于 `artifacts/rollback-20261024/final-independent-audit.json`（212,968 B，SHA-256 `ccd9b7058b4173daa01d4ff3741d23ee329283defa5735f4e670f6472bb730a0`），本页 JSON 保留其身份和简要结论。
