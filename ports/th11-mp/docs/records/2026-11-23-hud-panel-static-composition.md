# th11 多人版右侧 HUD 面板静止合成 | 2026-11-23

高刷呈现下，右侧 HUD 面板的中段会在上下边框之间滑动。面板按三段合成，各段的常量位移被当成了运动参与呈现采样。现在合成段使用独立时钟，位移只按作者位置生效一次。

## 问题

面板底图是一张静态美术：顶部 16 像素边框、底部 16 像素边框、中间空白带。多人版要铺满右侧 480 像素高，于是在 `AnmRenderer::draw` 里把这张图按源区和目标区切成三段提交：

```text
源 [0,16]     -> 目标 [0,16]      原样
源 [16,176]   -> 目标 [16,464]    纵向拉伸
源 [464,480]  -> 目标 [464,480]   原样
```

每段把自己的 `script_position.y` 加上一个常量位移。呈现采样按绑定时钟和对象 id 匹配端点，三段副本沿用同一身份，于是这些常量位移被当成帧间运动按显示权重缩放。

高刷呈现权重覆盖 `[0,2]`，`alpha=1` 是权威端点。中段在权重 0 到 2 之间位移达 32 像素，而首尾两段的位移是 0，乘任何权重都不变。结果只有中段在边框之间滑动。

## 修改

`web/cpp/game/AnmRenderer.cpp` 的 HUD 面板分支给三段副本绑定一个分支内时钟：

```cpp
float static_clock=1.f;
auto strip=[&](float top,float height,float source_top,float source_height){auto copy=vm;
    copy.timer.rate=&static_clock;
    ...
```

副本因此不会匹配到作者样本，直接按合成位置绘制。分支外没有任何改动：其他对象继续沿用作者时钟和原有插值。

## 验证

`node ports/th11-mp/portable/check-presentation.mjs` 通过 8 项，其中两项为本轮新增：

| 项目 | 结果 |
| --- | --- |
| 面板三段在权重 0／0.25／0.5／0.75／1／1.25／1.5／2 下的落点 | 全部为 -8.50／-208.50／455.50，无漂移 |
| 普通精灵在 `alpha=0.5` 时仍落在两端点中点 | 41.50，符合半像素约定 |
| MP 完整构建 | 3,007,075 字节，`515fccf4c949a8e1c73aa385fbee3d67d789a4f8cf221ce241763618b861485b` |
| 三种宿主编译配置 | thprac 关闭、`--thprac`、`--presentation-lab` 均通过 |

去掉那两行后，同一份判据立刻报出 8 处漂移，中段在权重 0 到 2 之间从 -224.50 移到 -192.50。判据能抓住该缺陷，不是恒定通过。

## 复现入口

```text
node ports/th11-mp/portable/check-presentation.mjs
```

浏览器逐帧复核需要 Launcher 宿主提供运行时数据，本机以托管数据协议对接为独立待办。
