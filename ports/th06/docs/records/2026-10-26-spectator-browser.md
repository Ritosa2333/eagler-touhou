# 合作旁观状态验收

流式 Replay 通过独立玩家与独立观众的同帧状态对比验证。检查覆盖 RNG、全席位资源、自机、敌机、ECL、弹幕与道具，并将播放位置、原生菜单和音乐载入纳入行为验收。

## 场景

| 场景 | 输入与角色 | 结果 |
| --- | --- | --- |
| 原生 Extra 普通局结算 | 双人真实键盘输入，原生死亡与全灭 | 137 个同帧采样一致，旁观消费至第 2759 帧后进入原生结果菜单 |
| 原生 Extra 挑战局中途入场 | 第 1802 帧后加入，真实键盘、低速与移动 | 10000 输入帧范围内 500 个同帧采样一致，回跳、Boss 导航与 OGG 载入通过 |
| 普通第五关持续旁观 | 三人射击、移动、低速与 Bomb | 12000 输入帧范围内 600 个同帧采样一致，道中与关底 Boss 导航通过 |
| 普通局第四关切入第五关 | 三人，P1／P2 正常死亡与幽灵，P3 保持存活，进入第五关后再运行 1800 帧加入旁观 | 关头位于第 19247 帧，第 19260 至 31240 帧的 600 个同帧采样一致，道中与关底 Boss 导航通过 |
| 普通第五关网络扰动 | 单次转发延迟 80 毫秒、抖动 20 毫秒、每 17 个玩家转发包丢弃 1 个 | 12000 输入帧范围内 600 个同帧采样一致，三位玩家分别经历 3172／3157／3154 次回滚 |

第五关专项使用生产对象链接私有观测构建。观测入口指定原生起始关与受保护席位，第四关沿原生 Boss 结束流程切入第五关；比较区间内的第五关、玩家输入和弹幕继续使用原生演算。观测 WASM、正式 WASM、源对象与角色保护配置通过独立收据记录。

## 驱动

`ports/th07/tests/netplay-spectator-natural-browser.py` 同时运行 th06 与 th07。正式 Runtime 场景直接读取生产包；私有观测场景读取 `private-spectator.json` 标记构建与场景身份。

`--difficulty=4` 选择 Extra，`--physical-input` 发送真实键盘命令。`--join-stage=5 --join-frame=1800 --frames=12000` 从来源端第五关中段进入，再检查当前关头后的 12000 输入帧。`--until-end` 验证原生普通局结算，`--music=none` 运行游戏状态场景，默认接入 OGG。

播放游标直接从原生报告读取，菜单交接通过独立的本机结果状态检查。th07 的正式包同步通过 1200 输入帧、60 个同帧采样、回跳与 OGG 检查。
