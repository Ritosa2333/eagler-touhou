# 東方花映塚 th09

th09 支持网页运行与双人联机对战，普通版和多人版共用同一份游戏程序。

**适配明细：** [本游戏适配表](./ADAPTATION.md) | [全项目适配总览与分类](../../docs/adaptation/README.md)

## 联机蓄力

回滚对局默认启用本地优先蓄力。双方同步已接受的本机蓄力进度，回滚重算、旁观和录像播放复用同一份记录。

房间选项「关闭本地优先的蓄力条进度」默认不勾选。勾选后使用原版蓄力逻辑，蓄力条即时显示当前进度，蓄力输入按原版方式记录。P1 可在等待室修改选项，修改后双方重新准备，开局后固定。

两种设置均保留技能停顿开始、结束及恢复移动第一帧的输入确认，技能按游戏允许的时机释放。调度规则与验证入口见[联机技能停顿](docs/NETPLAY-STOPS.md)。

本地优先录像以 `.rpyx` 导出。原版 `.rpy` 与已有触控 `.rpyx` 按各自记录播放，房间开关不改变回放规则。接口参数和录像格式见[开发指南](docs/DEVELOPMENT.md#回滚蓄力与-replay)。

## 构建

在 `web/` 执行 `npm run web:build`，再分别执行 `npm run web:eagler`、`npm run web:eagler:multiplayer` 生成普通和多人 Runtime。两种产品包使用同一份 release WASM，通过独立变体元数据区分。

资源准备、构建步骤与源码布局见[开发指南](docs/DEVELOPMENT.md)。源码编译后，由仓库根目录发布流程组装启动器包。

## 资源

仓库不附带原版可执行文件、游戏数据、音乐、存档或 Replay。运行包需要本地合法取得的原版资源；按开发指南准备对应文件。
