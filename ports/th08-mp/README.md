# 東方永夜抄 TH08 多人版

本目录提供 TH08 多人变体的源码和独立构建配方。它与 `ports/th08/` 的普通版分开编译，包含多人玩法、网络回滚和配套运行时接口。

修复幽冥组、单妖梦和单幽幽子通关进入下一面时未补充 Bomb 的问题，按各玩家自身库存恢复少于 3 枚时补充 1 枚的原有机制。

修复前录制的多人回放保留录制时的补弹行为，新对局使用修复后的行为。

**适配明细：** [本游戏适配表](./ADAPTATION.md) · [全项目适配总览与分类](../../docs/adaptation/README.md)

## 构建

`portable/build.mjs --th08 --multiplayer`；TH08 Runtime 配方启用 thprac 与 thcrap。

快速步骤和源码布局见[开发指南](docs/DEVELOPMENT.md)。源码编译后，由仓库根目录发布流程组装启动器包。

## 资源

仓库不附带原版可执行文件、游戏数据、音乐、存档或 Replay。运行包需要本地合法取得的原版资源；按开发指南准备对应文件。
