# TH20 · 东方锦上京

TH20 的浏览器适配使用 SDL3、WebGL2 和共用启动器。游戏逻辑位于 `src/`，浏览器平台实现、Runtime 和资源接口位于 `web/`。

- [开发与构建](docs/DEVELOPMENT.md)
- [逐项适配与自动检查](ADAPTATION.md)
- [源码目录与检查入口](../../docs/architecture/source-layout.md)

原版数据、音乐和字体由使用者提供，通过启动器的内容准备和 Package Store 接入。源码来源与完整导入历史见[来源记录](../../docs/history/README.md)。
