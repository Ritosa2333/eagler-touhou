# uth05win Practice 工具

Windows 原生 ImGui 接入，界面依据本地紫版 thprac 的现有实现移植。

- Backspace：开关左上角 `Mod Menu`。每项为可点击文字；启用时为绿色 `[按键: 功能]`，F1–F7 和 U 也可直接切换。
- Esc：打开暂停菜单，方向键选择，Z／Enter 确认，鼠标可点击。Esc 继续、Q 不存录像退出、R 重新开始。
- 暂停菜单为继续游戏、退出游戏、不存 rep 退出游戏、重新开始。普通“退出游戏”进入原生录像保存流程；录像允许保存，临时作弊开关不写入录像。
- F3 新增锁梦点后，原 F3–F6 功能顺延至 F4–F7。大 Practice 配置面板通过原生 Practice Start 选角后进入。
- Tab：开关“更多游戏信息”；也可点击 Backspace 菜单中的同名条目。面板沿用紫版 `TH10InGameInfo` 的难度／角色居中标题、Miss／Bomb 双列表格、0.9 背景透明度与无标题／不可移动／不接收鼠标和导航输入的窗口行为。默认关闭，仅在游戏场景显示，使用原生本关 Miss、Bomb 计数；回放同样可查看，不改变成绩或录像。位置固定为 `(432,408)`、尺寸 `192×48`，位于右下角难度贴图所在区域，下缘避开 FPS，上缘避开火力条，不覆盖游戏画面。面板开启时隐藏原难度贴图，关闭后恢复；也避开顶部按键显示。

暂停窗口沿用 `TH06::THPauseMenu` 的 `(32,16)`、`384×448`、透明度 `0.8`、无标题栏／边框、140 像素上间隔、119 像素缩进和 `130×25` 按钮。作弊列表沿用 `THOverlay` 的 `(10,10)`、自动尺寸、透明度 `0.5`，以及 `GuiHotKey::OnWidgetUpdate` 的文本、绿色启用状态和 InvisibleButton 点击区域。暂停开关沿用原实现的淡入淡出及确认输入处理。

| 按键 | 功能 | 行为 |
| --- | --- | --- |
| F1 | 无敌 | 撞弹保留掉残音效和短暂无敌，不触发死亡或损失资源。 |
| F2 | 无限残机 | 正常 Miss 和复活，残机不扣减，最后一命也不进入 Game Over。 |
| F3 | 锁梦点 | 冻结当前梦点，道具、Miss 与 Bomb 均不改变。 |
| F4 | 无限 Bomb | 正常使用 Bomb，不扣库存，库存为0时也可使用。 |
| F5 | 火力不减 | Miss 后保留当前火力。 |
| F6 | 锁定 Boss 超时 | Boss／中 Boss 攻击继续推进，禁止因时间或循环耗尽结束阶段，击破仍正常换段。 |
| F7 | 自动 Bomb | 接收到中弹判定后，在死亡流程开始前尝试正常 Bomb；库存与禁止 Bomb 条件仍生效。 |
| U | 敌人无敌 | 自机攻击不对敌人造成伤害，敌人的碰撞与弹幕继续运行。 |
| Esc | 暂停菜单 | 按紫版现有菜单绘制继续、退出、不存录像退出、重新开始。 |

大 Practice 配置面板见下；原生 Practice Start 仍负责选角与单关结束后的录像保存。录像播放不施加实时作弊；使用作弊的本局保留录像保存入口，但不写普通通关／排行榜记录。工具开关在同一程序会话中保留，重新启动默认关闭。

## 原生 Practice Start

标题中位于 Extra Start 之后、Replay 之前。使用当前 Options 难度进入原生四角色选择，确认角色后，在选角画面上显示 thprac 练习面板。

本分支选角后进入紫版 `TH06::THGuiPrac` 样式的 ImGui 面板，正常模式仍按角色及难度检查关卡解锁。纯原生 `native-practice` 分支保留 PC-98 字形黑框选关，不接入这个面板。关卡在正常实战进入时解锁，进度保存在 game.cfg 的版本化扩展区，录像、Practice 和作弊局不会解锁。

正常模式开始或重试该单关时，初始满火力、8 个备用残机和 8B；自定义模式使用面板参数。原生引擎把当前自机也计入生命，因此内部生命值为 9，HUD 显示 8。不能续关，正常 Miss 后按练习初始设置补充 Bomb。结束该关（含第六关）直接进入原生录像保存流程，不进入下一关、结局或普通排行榜；耗尽生命同样转保存页面。

沿用原生 RPY 格式的 `m_bPracticeMode`、单关输入流、初始资源和随机种子。保存后在 Replay 菜单对应关卡列播放；该关结束即退出播放。普通 Practice 本身不算 thprac 作弊，允许保存；自定义模式保存下述初始参数。F1–F7／U 属于临时工具，不作为录像初始参数序列化。

验证：136 项生产代码检查通过，包括六关分别运行 1200 帧的移动、低速及射击输入，保存 RPY、重新载入并逐帧比较帧号、坐标、火力、资源和分数；另检查通关／Game Over 保存分流、回放单关结束、选关返回及原生窗口截图。该检查不等同于完整打通六关。

## thprac 自定义 Practice

面板沿用紫版 TH06 的字段顺序、无标题栏／边框与 ImGui 控件。Z 直接开始，X 淡出返回选角；没有额外的开始／返回按钮。上下移动焦点，左右调节数值或循环切换下拉选项，鼠标可操作控件，Ctrl+点击数值可直接输入。输入数值或打开下拉列表期间不会把 Z／X 当作开始／返回。

自定义模式可选 STAGE 1–6、Extra；Extra 自动使用 Extra 难度，其他关卡使用 Options 难度。传送仅有“无、道中Boss、关底Boss、帧”。第六关选择道中Boss时，阶段只有“从关卡起始处开始（没有道中）”，按原关卡开场开始。帧范围 0–60000，为关卡时间轴帧数。传送同步推进原背景和敌人表游标；关底传送执行原剧情 VM 完成贴图、调色板、音乐加载。

| 参数 | 范围与含义 |
| --- | --- |
| 残机／Bomb | 0–8；残机为备用生命数，内部另计当前自机 |
| 分数 | 0–99999990，按 10 分取整 |
| 火力 | 1–128（原引擎最低火力为 1） |
| 擦弹 | 单关 0–999 |
| 累计蓝点 | 0–99999，使用原累计蓝点的每 100 点奖励残机规则 |
| 单关蓝点 | 0–999，独立用于单关 HUD 和结算 |
| 梦点 | 1–128 |
| Rank | 始终使用当前难度原生上下限：Easy 16–32、Normal 24–40、Hard 44–54、Lunatic 48–58、Extra 固定 32；锁定不改变范围 |
| 锁Rank | 阻止随时间、道具、Bomb、Miss 改变 Rank，回放同样生效 |

重新开始恢复面板的初始数值及传送位置。自定义录像使用原 RPY 主体加 `TPC5` v3 参数扩展（19 个 32 位字段），文件版本为 2；当前版本可读取原版 v1 录像和旧 `TPC5` v1／v2 扩展（14／18 字段，新增对话项默认为关闭），旧程序会拒绝不认识的扩展版本，避免误按普通录像播放。这里只保存大 Practice 初始参数，临时热键开关不进入扩展。普通 Practice 继续写原版 v1。

回归检查覆盖所有 28 个关卡／传送组合，逐帧对比录像的 12 项状态与随机数序列，另检查独立蓝点、Rank 锁定、重试、Z／X、原版录像兼容和不完整扩展拒绝。实际截图写入测试 sandbox；不等同于完整打通全部关卡。

## Boss 阶段练习

自定义模式选择“道中 Boss”或“关底 Boss”后显示“阶段”。“正常开始”保留原传送行为；其余选项沿原生状态机初始化到指定攻击，开始前清除前置攻击的弹幕与奖励，保留面板指定的分数和资源。

- 四面直接列出双 Boss、舞四个阶段和雪四个阶段，任选分支；双 Boss 提供两级变招预设。
- 三面独立列出人偶飞入、三组人偶展开／护盾、五个攻击阶段和最终攻击准备。
- 一面道中支持发狂预设和起始血量。选发狂填入 200，之后以实际起始血量决定运动范围与攻击速度。
- 二面道中第一阶段提供 800／600 血两级发狂；第二阶段选择击破进入（400 血）或超时进入（1400 血）。
- 五面梦子两个固定血量发狂段提供发狂选项；从原生蓄力与瞄准完成后进入，保证瞄准角度及录像初始化一致。
- 六面神绮第六个攻击阶段提供两级发狂，并选择血量触发（5600／3800 血）或时间触发（保留 8600 起始血量，执行原生计时及激光初始化）。
- Extra 道中发狂沿原生循环边界切换；Extra 爱丽丝最终攻击可设起始血量，保留随血量变化的原生弹速与移动幅度。

阶段、发狂、进入／触发方式和起始血量写入 `TPC5` v3，重试与录像使用同一初始化路径。临时 F1–F7／U 状态不会影响阶段准备，也不会写入录像。六面道中继续保留“从关卡起始处开始（没有道中）”。

“对话”复选框采用紫版 thprac 的入口规则，默认关闭：正常 Boss 开场及第一阶段可选，后续攻击／发狂和没有原生对话的道中 Boss 不显示。四面正常开始／双 Boss 入口播放双 Boss 原始开场；舞／雪第一阶段只播放对应分支的原始对话。对话由原生脚本执行，保留资源加载、音乐及原键位推进／Ctrl 跳过，录像记录实际对话输入，重试恢复同一设置。

对话接入后通过 3935 项生产路径检查：16 个原生对话入口逐帧对照录像状态与随机数，兼容旧 TPC5 v1／v2；实际渲染确认舞／雪分支立绘、文字及菜单复选框。测试包含原有 251 组阶段／发狂预设，不代表完整通关验收。

三面爱丽丝的阶段传送只向本体施加准备用伤害，不伤害人偶，避免残留的人偶死亡动画在进入“最终攻击准备”／“阶段 5”后再各扣本体 300 血。两个入口保持原生 800 起始血量；实战击破人偶的扣血规则保留。回归覆盖四种难度下两个入口的初始血量、100 帧无射击血量及录像一致性。

## F12 高级菜单

F12 打开／关闭全屏 ImGui 高级选项，打开期间暂停游戏模拟与录像输入记录。分组沿用紫版 thprac 的折叠菜单结构。

- 游戏速度：TH05 原速为 56 fps，提供倍率和自由帧率，按“应用”生效；音乐保持原速。
- 游戏进行：“将锁残修改为不疮”使 F2 正常扣备用残机，仅保留最后一命；禁用 X／Shift／Z 和强制 Shift 只处理实战输入，不改变菜单或已有录像。Shift+D／A／S 切换禁用键位，本作没有 C 操作。
- 打开按键显示：移植紫版 `thprac_igi_key_render.cpp` 的顶部覆盖层，不使用独立窗口。方向键和功能键分组排列，沿用切角按键、按下／松开配色、低速 Δ、Ctrl Σ 和 APS；本作未绑定的 C／D 置灰。使用实际实战／录像输入，按原算法统计按下和松开边沿，窗口适配为 TH05 的 56 个模拟帧；暂停和重复绘制不会增加记录。开启后提供原版的开始／停止记录 APS、曲线和导出到游戏文件夹（`APS.csv`）。
- 启用锁时计时：按 Boss 阶段计时，以 56 帧为一秒，暂停时停止。练习模式快速 re：实际 Miss 或 Shift+F 触发，15 帧后按练习初始参数重开并跳过开场；回放不触发。
- 游戏进行中的判定点选项：“低速时显示”仅在实际 Shift 输入期间显示；“常驻判定点”在高速和低速都显示，优先于前者。两项独立开关，默认都关闭，保持原版 PC-98 无判定点显示。开启任一项的局记为辅助局，不参与普通成绩／解锁，但保留录像保存入口。
- 游戏进行中的“梦槽状态以数字显示”和“火力状态以数字显示”：默认关闭，可分别开启。开启后隐藏对应进度条，梦／火力标签移到上方统计标签所在列，并在同一行右侧用结算界面的原生数字贴图显示当前原始值（1–128）。灵梦保留原“灵力”标签，其他角色保留 Power 标签；不影响数值、录像或成绩。
- 游戏进行中的“阶段剩余时间/次数显示”：默认关闭。游戏区域右上角使用结算数字贴图显示原生 Boss／道中 Boss 的剩余超时条件：按帧超时显示向上取整的整数秒（原速 56 帧／秒）；按攻击循环超时可用“攻击循环显示”选择“轮数”或“时间”，默认保留轮数模式；轮数显示剩余次数及原字库的 `TURN` 字样，时间按本阶段攻击、等待与移动的原生帧数合并后换算为整数秒。四面雪的随机移动会影响后续归位耗时，这类预计时间加 `~` 标记。入场、对话、过渡、死亡及没有超时设定的阶段不显示；阶段改变后直接读取新阶段的计数。开启 F6 后读数最低为 0，不改写计时、攻击循环、随机序列或录像。该显示不自行触发换阶段，仍由原有逻辑决定。
- 游戏进行中的“血条提示阶段”：默认关闭。在原生血条已填充的部分，以 1 像素黑色竖线标出换阶段及固定血量变招阈值。位置按原血条 128 像素宽度和实际满血值换算，线段仅覆盖进度条的 8 像素高度。四面双 Boss 使用合计血量变招点，进入单 Boss 分支后改用对应角色的独立阈值；道中 Boss 同样支持已存在的血量阈值。连续随血量变化的强化、仅靠时间／攻击循环触发的变化不产生分割线。该项只影响绘制，不改写血量、阶段或录像。
- 游戏进行中的“红魔乡式血条”：默认关闭，与“血条提示阶段”互斥。开启后强制启用阶段剩余时间／次数，相关开关置灰；移除侧边 Enemy 与血条，改在游戏区域顶部显示原 Enemy 贴图、当前阶段之后还剩的血量阶段数、细长血条和剩余时间／次数（轮次缩写为 `T`）。血条按当前血量阶段归一化；狂暴与固定血量变招作为同一阶段内的红色区段，以细竖线分界，不增加阶段数。四面双 Boss 阶段之后还有四个单 Boss 血量阶段，分支切换后使用对应血量范围。

顶部血条动画参数依据 TH06 `src/Gui.cpp::UpdateStageElements`：每个模拟帧回填 1%、减少 2%，透明度每帧变化 4／255；暂停与 F12 期间冻结，绘制不推进动画。沿用 TH05 字库，顶部为两像素高血条；为轮次数值和 `T` 预留位置，长度为 272 像素。时间／轮数分别保留最后 10 秒／5 次淡红色提示；顶部血条同样跟随“攻击循环显示”选项。三面人偶护盾阶段的原生 600 帧自动过渡也接入时间显示。
- 反应力测试：按下／弹起两种模式、1–20 次测试、随机等待、提前输入判断，提供毫秒与帧数结果；使用独立随机数，不消耗游戏随机序列。
- 关于：显示移植来源和 ImGui 许可信息。

阶段剩余读数在 ≤10 秒或 ≤5 TURN 时，数字与 TURN 字样统一显示淡红色（RGB 255、166、166），其余时候为白色；F6 锁时后的 0 同样保持淡红色。

高级选项保存到 `thprac-uth05.ini`，不写入原游戏存档或录像参数。测试使用独立 sandbox，覆盖帧率、禁用键输入与录像隔离、不疮、判定点实际像素、锁时计时、快速重试和反应力测试。

## 构建

需要 Visual Studio C++ Desktop、Windows 10 SDK 和 Python 3。ImGui v1.82 与 Win32／OpenGL2 backend 已固定在 `third_party/imgui`，许可证见该目录 `LICENSE.txt`。

```powershell
.\scripts\Build-Practice.ps1 -GameDirectory "你的 uth05win 游戏目录"
```

脚本使用游戏目录已有的 `glew32.dll` 和 `PMDWin.dll` 生成本地 x86 导入库，输出 `Release/uth05win-thprac.exe`。将该程序放进游戏资源目录运行；原 `uth05win.exe` 可保留。
