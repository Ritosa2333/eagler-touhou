# UFO 与道具行为

以下为固定 TH12 1.00b 的行为说明，原版入口地址用于与 `decompiled/` 对读。
网页版仍有缺项，不能把这里的说明当作已全部实现。

## 库存、召唤和 HUD

- 库存编码0空、1红、2蓝、3绿；`422e80` 追加三槽。三同色召唤对应颜色，三色全异召唤彩虹；其余组合丢弃最旧一枚。
- `44a2d0` 在 UFO19 回调判断召唤；普通拾取发生在 Item22，因此第三枚拾取通常在下一逻辑帧触发召唤。
- `44a8a0` 选择原 ECL 的 `UFO_Red/Blue/Green/Rainbow`，并保留三槽至离场。
- HP 按 power/powerStep 使用1600/1900/2100/2300/2500；倒计时参数720不等于每次存活恰好720tick。
- HUD 三个物理 VM 使用 front80 和独立轮转索引。`421a60` 发9/7/8中断后轮转；`4214b0` 刷新发10+color，新增槽发17并创建 front81。
- 拾取特效使用 bullet201／202／203，从道具的屏幕坐标向逻辑槽位 `(52 + 21 × slot, 440)` 移动。`427164..42719b` 在动画绑定后设置15帧、mode4的减速插值；丢弃最旧飞碟时，新拾取特效进入第二槽。
- 跨面重建 HUD 时，槽位位置中断和颜色刷新均按保留的轮转索引映射物理 VM，保持逻辑槽位与拾取目标一致。
- 红／蓝／绿对应 front sprite60／61／62，闪烁为64／65／66；59和63是空槽。
- 大 UFO 存活时 age%16==1／9 切换库存明暗。

## 小 UFO 变色与提示

- 固定色type10..12，变色type13..15，状态6；提示为独立的 bullet211 句柄。
- 变色时钟在玩家60px范围内冻结或回退，远离时90tick进入准备、150tick换色。
- 提示同色组合发7／8／9，补彩虹统一发10；已有提示句柄保持，组合失效或库存满时销毁。
- 对话将小 UFO 生存时钟设10000，停止反弹后从外缘离场，不应直接删除。
- 满库存再拾取不追加颜色，PIVstored增加100000并受上限限制。

## 大 UFO 离场与奖励

- `44a2d0` 在age420或Boss出现时给原ECL发送逃跑信号；路径由原脚本驱动。
- 自然离场不调用死亡奖励链，不应自动发奖。
- 对话设置独立生命控制标志；随后有效Enemy更新进入 `414af0 → 44a890 → 44af00`，产生死亡奖励。
- 普通吸入在age>=60后对P／点生效；彩虹交换奖励桶。满充填只发一次额外奖励，桶仍继续累计。
- 汇总type16..18保留死亡时桶量与倍率，玩家拾取时才结算。
- Reset、析构、自然离场和死亡必须是不同路径。满池生成失败也应保留有限容量和计数行为。

## 呈现与伤害

- bullet207根生204／205／206三个环，满充填中断2需传播到直接子VM。
- 206是mode13顶点阵列；负sprite会回退ascii264白贴图，不能统一当隐藏。
- front134／135为侧栏面板，136／137为跟随敌人的HP条。
- 倍率有黄／灰闪烁；桶计数、fill百分比、倒计时与奖励文字来自不同字段。
- Source累计伤害与最终HP损失分开；Spell93..99、103..112及active+pendingBomb会有不同减伤／屏蔽条件。
