# TH14 ANM VM 原版对照

原版基线为 TH14 日文 1.00b。Oracle 执行原版 VM 更新入口 46fe50，并与 Web/GLES 构建的生产对象逐帧比较指令位置、时钟、标志、旋转、缩放、四角 UV、颜色和 RNG 状态。测试输入、全局显示参数和随机种子固定；原版安全 cookie 检查替换为直接返回。字库选择另执行原版 40b530，到实际资源加载调用前读取文件名。

| 对照项目 | 修复后 |
| --- | --- |
| 时钟、减速、延时、等待、中断、删除和停止 | 27 组相同 |
| 向量、颜色和缩放插值 | 32 组相同 |
| 速度更新与浮点参数引用 | 28 组相同 |
| 滚动速度插值，双轴各测全部 32 种模式 | 128 组相同 |
| ANM 411 的 Z 轴角度插值，含跨 ±π、与向量插值重叠、零时长 | 130 组相同 |
| ANM 418／419 一次性及持续屏幕 UV | 4 组相同 |

归档扫描通过生产 PBG 和 ANM 加载器。57 个文件共 1,906 个脚本、40,091 条指令（不含结束标记），实际使用的 90 个操作码均有映射。原版有 128 个非默认操作码（不含结束标记），本次补齐其中缺少的 411、418、419。零售归档未使用这三条。

- **字库。** 同步加载、C++ 启动 worker 和 WebGPU 后台预读均按实际显示尺寸选用 ascii.anm、ascii_960.anm 或 ascii_1280.anm。Web 的内部尺寸固定为 1280×960，使用原版高清素材并按素材尺寸绘制。继续保留队列坐标、文字步进及原版分辨率标志的处理。抽查的数字／标点槽尺寸由 16×16 变为 32×32；回退精灵槽 258 从 6×6 变为 14×14。
- **速度更新。** 和原版 472ae9 一样，只有 flags2 的 0x800000 开启时才更新角速度、缩放速度和 UV。X 缩放速度只置缩放脏位，ANM 415 写入全零角速度不再置旋转脏位；归档里有 13 处全零角速度。Y 缩放先舍入乘法再相加。
- **滚动插值。** ANM 427／428 只设置速度插值；UV 是否滚动仍由速度更新标志决定。标志开启时按原版 414140 分步舍入。

复查命令（依赖 Python Unicorn、Node 和 Emscripten；原版文件留在本地）：

```powershell
python tools/th14-build-gles.py --emsdk "<sdk>" --out artifacts/anm-vm-build --jobs 3
python tools/th14-anm-vm-oracle.py --exe "<retail>/th14.exe" --archive "<retail>/th14.dat" --build artifacts/anm-vm-build --emsdk "<sdk>" --report artifacts/anm-vm-report.json
```

加 `--strict` 时，VM 差异、缺失操作码或字库选择不符都会返回非零。报告记录每个不同字段的原版和移植 32 位原始值。修复前的 120 组对照中有 31 组不同、3 组未映射。修复后扩展至 349 组全部相同；另有 69 组[界面对照](TH14_UI_ORACLE.md)通过。父子 VM 管理、绘制队列、完整战斗和最终像素未由这份组件对照覆盖。
