# 旁观与扩展录像

兽王园房间支持只读旁观。P1 将双方确认的逐帧输入上传到 Relay，观众先重演本局历史，再跟随实时输入。旁观面板支持暂停、定位历史和返回实时。RTC 与 WebSocket 对战共用同一旁观通道。观众不提交玩家输入；观众掉线、上传拥堵和录像写入失败均与玩家对局隔离。

启动器的录像管理可以导入、导出和播放 `.rpy`，支持暂停、倍速和前后定位。多人设置中可以开关自动保存录像。保存条件是实际执行过战斗逻辑：停留菜单、选择难度或角色、观看开场剧情、等待倒计时后退出，均不保存。联机录像记录已经确认的输入，回滚预测不写入录像。每场联机对局使用同一个录像文件更新保存，结束时更新完整／中断标记。旁观保存跟随接收到的确认帧，暂停和倒带均可继续接收录像。断线后可以观看已接收的历史。

录像保存涵盖联机对局和旁观收到的确认输入。旧录像文件继续保存在存档中，播放时使用录制时的运行时构建。播放及回退在独立内存存档中重建游戏。对战录像在相同规则与种子下逐帧重演，每 120 帧核对游戏状态哈希。

`.rpy` 是网页适配的扩展输入录像，版本为 `eagler-touhou/th19-replay/2`。本文件由网页运行时播放。原版 EXE 的 ReplayInf 读取路径检查 `t18r` 标记及版本 6，尚未确认完整的 TH19 双人保存/回放协议；本格式不声明原版兼容。证据见[原版录像核对](../../../archive/th19-gameplay-20261105/story-rank-and-replay-audit.md)。录像要求相同构建版本，新版文件为每位玩家保存 held、pressed、released 三个 16 位输入值，边沿计算依据 EXE 0x430340。触屏位移、双人封装和旁观传输由网页适配层定义。文件校验包含 CRC32、帧序、按键边沿、角色、难度、规则及存档路径。每份录像最长一小时；到限结束录制，对局继续。

主菜单 Quit 直接发送启动器退出事件；联机会先保存已确认的对局记录。对战结束保留加载好的房间标题，供下一局使用。

普通版与多人版共享对象回收：失效敌机和灵体在更新末尾注销；每侧 BulletInf 容量为 2000，新弹在容量已满时跳过，已有活弹继续更新。跳过生成仍消耗原定随机数，保持确认输入的确定性。ECL 发弹和反射弹到达均使用这一容量。

开发验证入口：

```text
node --test tests/*.test.mjs
node tests/world-limits.mjs
node tests/recording-browser-smoke.mjs --url=http://127.0.0.1:<port>/
node tests/pressure-browser-smoke.mjs --url=http://127.0.0.1:<port>/
node tests/spectator-browser-smoke.mjs --url=http://127.0.0.1:<port>/
```

原生测试通过 `CXX` 指定 C++17 编译器；浏览器测试通过 `TH19_BROWSER` 指定 Chrome 或 Edge。完整旁观测试使用 monorepo 内的 Relay。
