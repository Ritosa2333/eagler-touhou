# TH01《东方灵异传》· 原生移植与多人合作

将《东方灵异传》的游戏逻辑移植到现代 C++，同一核心编译为 Windows EXE 和浏览器 WebAssembly。运行时不加载 DOS、PC-98 模拟器或磁盘镜像。支持单人、本机双人／三人合作，以及网页双人／三人 UDP 联机。

已接入神社、魔界／地狱两条路线的全部普通关、七位 Boss、路线选择、通关好坏结局、评定和姓名登记。提供 Easy／Normal／Hard／Lunatic 四档难度及 1／2／3／4／6／8 玉。保留原素材、音乐和主要演出，并包含多人规则及降低闪光的适配；不宣称与 DOS 原版全流程逐帧一致。

## 启动

发行内容包含已构建的 EXE、WASM、网页、音乐和音效，普通游玩无需编译或下载相邻 TH 项目。

| 模式 | 启动器 | 地址／要求 |
| --- | --- | --- |
| Windows 单人／本机合作 | `start-native.bat` | 直接运行，无需 Python |
| 网页单人／本机合作 | `start.bat` 或 `start-web.bat` | `http://127.0.0.1:9871/` |
| 网页双人／三人联机 | `start-lan.bat` | 默认端口 9874，使用服务窗口打印的网址 |
| 临时公网入口 | 先启动 `start-lan.bat`，再运行 `start-public-tunnel.bat` | 全员使用隧道打印的同一个 HTTPS 地址 |

网页服务需要 **Python 3.10+**，玩家推荐新版 Chrome／Edge。通过服务网址访问，不要直接双击 HTML。其他设备只需浏览器，无需安装 Python。服务窗口须保持开启。

也可在本目录执行：

```powershell
python server.py
python lan_server.py --port 9874 --no-browser
```

两条命令分别启动本地网页和联机服务，按需要选择。单机服务默认仅本机访问；需要其他设备访问本机合作页面时，使用 `python server.py --bind 0.0.0.0`。联机服务默认监听局域网接口，所有设备打开同一个 `http://电脑局域网IP:9874/lan.html`。

首页与旧多玉版采用相同四种入口：单人游戏、本地合作、局域网联机、公网联机。单人在网页选择难度和玉数后进入原标题菜单；本地合作在网页选择人数、难度、玉数和生命补偿后直接进入第一关。两种本地模式分别记忆网页设置，可用“重新设置”开始新局，也可取消设置返回当前游戏。

默认端口、`start.bat`、公网隧道目标、房间网址参数及 TURN 配置格式均与旧多玉版对齐，覆盖旧发行目录后可沿用原部署。保留原目录的 `turn-config.local.json`，重启服务并全员刷新重新建房。公网入口兼容说明见 [README-PUBLIC.md](README-PUBLIC.md)。

## 操作

| 操作 | 本机 P1／联机本端 | 本机 P2 | 本机 P3 |
| --- | --- | --- | --- |
| 左／右移动 | ←／→ | A／D | F／H |
| 射击／开球 | Z | J | T |
| 御币 | X | K | Y |
| 独立 Bomb | C | L | U |

标题和菜单使用方向键选择、Z／Enter 确认、X／Esc 返回。普通关过场后，等待任意玩家按射击才同时开球和启动倒计时；Boss 按自身登场流程开始。普通关清关后确认进入下一关，第五关击破后选择魔界／地狱。

Windows 中 Esc／空格暂停，F1 返回标题，F2／F3 切换人数／玉数，F4 切换难度并重开，F5 重开，F6 切换 Bomb 闪光，F7／F9 开关音效／音乐，F8 开关测试无敌，F10 进入第五关，F11 查看成绩。标题 OPTION 可调整难度、人数、玉数、生命补偿及测试无敌，再选择 START 应用。网页提供相应设置、触屏、全屏和音频控制。

Windows 失焦暂停；本地网页切后台或失焦后暂停，需要手动恢复。联机切后台会释放本机按键，浏览器后台限速仍可能使全队等待。

## 多人规则与通关

玩家共用关卡、阴阳玉和团队分数，各自持有残机及 Bomb。P1 为原色，P2 蓝色，P3 绿色；Boss 开战血池随开局人数和玉数调整。

- 用尽残机后成为可移动的幽灵；幽灵接触存活队友可复活，不扣队友残机。过关也会带回幽灵。
- Bomb 道具由任意活人拾取后，全员（含幽灵）各加一颗，每人上限五颗；施放只扣施放者库存。
- 多人失命只清除人物周围半径 64 像素内的白弹；单人失命、Bomb 和 Boss 击破保留各自的全局清弹规则。
- 全员阵亡后可不限次数续关：重开当前路线当前关，分数清零，全员恢复开局残机和一颗 Bomb。
- 无续关进入所选路线好结局，有续关进入坏结局。结尾字幕打字时，Z／Enter 先补全文字，再次确认推进；X／Esc 跳到评定。

评定后登记最多八字符姓名：方向键选字符、Z 输入、X 删除、Enter 或 END 保存。四档难度各保留前十名；调试或无敌局带 `*` 标记。Windows 成绩保存于 `%LOCALAPPDATA%\TH01NativeLab\scores.dat`，本地网页保存在当前浏览器站点中，两者不自动同步。全灭选择 No 后目前直接返回标题，尚未接成绩登记。

## UDP 联机

沿用 `th01-multiorb-lab` 的四位房间号、WebRTC DataChannel／ICE／STUN 打洞、可配置 TURN 和备用 WebSocket 转发。运行当前原生 WASM 核心；Windows EXE 的联机尚未接入。

1. 所有人打开同一个联机网址。房主选择人数、玉数、难度、生命补偿和连接方式并创建房间。
2. 队友输入四位房间号加入，房主可轮换座位。
3. 全员准备后由房主开始；校验版本并测量输入缓冲后进入游戏。

每台设备都使用 P1 键位控制自己的座位。任意玩家可开球、请求暂停；只有房主操作菜单、恢复、路线选择、结算、续关和姓名登记。声音及音量仅影响本机，联机页点击“启用声音”播放。

联机专属规则：幽灵移速降低 50%；X 御币反弹的白弹可以伤害玩家，最多再弹回一次，之后再被 X 挡住就消除。刚弹开的弹暂时保护出手者，离开挥动范围后返回也能伤到本人。单人和本机合作保持原规则。

输入缓冲推荐保留“自动”：稳定低延迟连接可选到1步，比原最低2步减少约17.7毫秒固定缓冲；三人会计入经房主转发的完整路径，较慢或有抖动时保留更多缓冲。

单人、本地合作和联机设置均提供“起始关卡”：默认正常流程，也可直接选择神社、魔界或地狱的普通关及全部 Boss。选关练习直接播放该关登场演出，之后照常推进；重新开始回到所选起始关，练习成绩不保存到正式排行榜。联机由房主选关，全员可在大厅看到；修改关卡后需重新准备。

三人采用房主星形拓扑，按约 56.4 步／秒确认输入；输入到齐才推进，不预测、不回滚。每 120 步核对状态，版本不一致、失步或断线会停止全局。没有断线重入或主机迁移。联机开局统一默认成绩，不读取设备单机成绩；登记另存 `th01-native-net-scores-v1`，每个新房间仍从相同默认表开始。

局域网 UDP 房间仅需 Python 标准库。备用 WebSocket 转发需要：

```powershell
python -m pip install -r requirements-relay.txt
```

公网全员须使用同一个 HTTPS 地址。临时隧道需要安装 `cloudflared`，并保持房间服务与隧道两个窗口开启；隧道提供网页和信令，UDP 中继由 TURN 提供。需要 TURN 时运行 `configure-turn.bat`，本机配置不会上传。详细步骤见 [联机说明](README-NETPLAY.md)。

已在同机独立 Edge 进程中验证真实双人／三人 UDP、三人 WebSocket、换座位、开球、暂停、Bomb、换关、续关、版本核验及失步全停。跨 NAT、真实公网 TURN、实体手机和长时间公网对局尚待实际网络验收。

## 仓库内容与更新

`.gitignore` 参照其他 TH 项目使用发行白名单，保留完整 `web/`、服务端、依赖清单、公开说明和启动器，并单独保留 `build/th01-native.exe`。WASM、音乐、音效和运行清单均纳入发行，下载后即可启动。

开发源码、原始资源快照、工具链、测试报告、缓存、临时隧道网址和 TURN 凭据留在本地。`build/` 中除发行 EXE 外的内容不上传。此发行白名单不等于完整开发源码仓库。

`.gitattributes` 保留网页资源原始字节，避免 Git 换行转换破坏 SHA-256。更新时完整替换网页及其联机清单，重启服务，全员刷新并重新建房。当前联机协议 `th01-native-lockstep/1`，不能与旧 DOS 多玉版混房。

完整本地开发工作区使用 Python 3.10+ 和 Zig 0.13 重建：`python tools/build.py --zig C:\path\to\zig.exe`；也支持 `TH01_ZIG` 环境变量。构建自动生成联机 SHA 清单；仅修改联机 JS 时运行 `python tools/prepare_netplay.py`。发行包不含重建所需的全部开发输入。开发记录和原详细 README 保留在本地 `docs/`。

游戏逻辑来源：[ReC98](https://github.com/nmlgc/ReC98) `debloated`，固定提交 `28d59d31331e27fcbe61d1b65bd8c0cd618757d8`，包含本地多玉／合作适配。美术、音乐沿用既有游戏资源，不代表 ReC98 上游提供这些资源；原作权利归原权利人所有。
