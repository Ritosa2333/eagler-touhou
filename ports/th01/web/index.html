进入本地合作 →
02 / LAN

局域网联机

同一局域网内支持双人或三人，使用四位房间号加入。

进入局域网 →
03 / ONLINE

公网联机

支持双人或三人。优先 UDP 打洞，可选 TURN 中继或 TCP 转发。

进入公网联机 →
如何开始？

单人和本地合作使用 start-web.bat。局域网使用 start-lan.bat，其他玩家打开服务窗口显示的局域网地址。公网先运行房间服务，再运行 start-public-tunnel.bat，或使用已经部署的公网网址。

单人从原标题菜单开始。本地合作在网页选择难度、人数、玉数与生命补偿后直接进入第一关。手机自动显示触屏操作，菜单提供方向键和确认。

联机支持两人或三人。房主在网页选择设置，全员准备后直接开始。所有普通关过场结束后等待任意玩家射击开球和倒计时。
