# 神灵庙符卡名右对齐

符卡宣言名按原版右对齐入口布局，短名与长名随 CP932 字节长度保持右侧落点。正文缩放、贴图条带、VM 位置和入场动画继续使用现有生产路径。

## 原版依据

`0x4135c3` 调用 `0x46e970`，后者使用 `sprite_width - (nominal_height - 1) * strlen / 2` 计算布局坐标，经 `0x46e810` 传给 `0x45aef0`；`0x45afcf` 再将横坐标乘二，供双分辨率的 `TextOutA` 栅格使用。居中入口是另一个函数 `0x46ea30`。

对日文 v1.00c 的原始函数执行 Unicorn 算术探针，固定精灵宽度 320、名义高度 17，仅替代格式化字符串和下游绘制边界，获得：

| CP932 字节数 | 原版布局横坐标 | TextOutA 横坐标 |
| --- | --- | --- |
| 12 | 224 | 448 |
| 14 | 208 | 416 |
| 16 | 192 | 384 |
| 20 | 160 | 320 |
| 32 | 64 | 128 |

旧实现把布局坐标当成已经倍增的栅格坐标，选用了 `Center`。生产符卡名现在使用 `Right`；相关旧测试及注释按原版入口更正，新增长度矩阵回归。
