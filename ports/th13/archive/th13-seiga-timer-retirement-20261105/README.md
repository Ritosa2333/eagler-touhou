# 神灵庙青娥退场倒计时清理

敌人销毁时统一撤销其 Boss 槽登记，使青娥退场后的倒计时随战斗对象退出。其他 Boss 槽继续保留，战后演出中尚未退场的 Boss 继续维持原有计时显示。

## 原版依据与触发路径

原版敌人管理器 `0x418e00` 的摘链分支调用 `0x417d20`，进入析构函数 `0x419320`。`0x41938b..0x41939a` 检查 Boss 标志和登记索引，清除管理器 `+0x5c` 对应的槽位。

真实 `st04mbs.ecl` 的 `MBossDead` 先等待 120 帧，再向 `(-256,64)` 移动；随后还要等待 120 帧才执行 `512(-1)`。敌人可能在该指令之前因越界被销毁。移植版原先在伤害销毁和显式 `512(-1)` 中清理登记，通用摘链路径缺少析构时的清理，因此 HUD 门条件持续成立。

修复位于 `StageSim::step_frame` 的统一移除分支，覆盖 ECL 返回、越界和已标记死亡的清理。HUD 继续使用原有 Boss 槽占用条件。
