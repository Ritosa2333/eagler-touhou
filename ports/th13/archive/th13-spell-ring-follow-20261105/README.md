# 神灵庙符卡环跟随

符卡背景环按原版 Update26 更新位置，每帧向 Boss 坐标移动剩余距离的 5%；符卡名称和关卡背景继续使用各自的固定锚点。暂停时不更新跟随位置。

## 原版依据

日文 v1.00c 的 `0x412d00` 更新函数在 `0x412dfe..0x412eb1` 读取 Boss 槽 0 的位置，更新管理器 `+0xac/+0xb0/+0xb4`，再将结果写入 `+0x20` 所指 effect 脚本 13 的 VM 平移字段 `+0x574/+0x578/+0x57c`。系数地址 `0x4aeda8` 的双精度值为 `0.05000000074505806`。

每轴计算顺序为单精度差值、双精度乘法、单精度步长、单精度累加。原版 Unicorn 探针覆盖连续追踪和目标反向的 12 帧，生产回归逐轴核对浮点位型。
