## 0. 总纲：一个覆盖层、三个分支状态机

覆盖层对象 = `DAT_004c22c0`（1000 字节，0x42c550:84 关卡首帧建：FUN_0043da30 →
构造 0x43d880；0x42bfa0:125-131 析构 FUN_0043da60）。每帧由 FUN_0043dbc0 按态分发：

```
state(+4) │ 分支机              │ 进入口（写态函数）
   0      │ 对局中监视（ESC/失焦）│ 开局即 0（0x43dbc0:17-22）

0xd..0x15 │ GameOver/续关        │ 0x43f570(全灭, mode0→0xe)
0x16..0x1f│ 结算B（Extra/符卡）  │ 0x43f720(mode2→0x1e, mode≠0→0x1f, mode0→0x17)
```

关键公共语义：三机全部先置 GameInf(DAT_004c2194)+0x60 的 **0x10 位**（冻结对局：
0x42c550:263 三旗 0x10/0x20/0x40 任一非零 → 对局 update 返 3 不推帧）；年龄计数
= param_1+0x14（帧）；DAT_004df120 = 结算页变体暂存（0=默认 1=GameOver 系
2=ESC/暂停，写点 0x42c490/0x42c550:241/0x43f570:69/0x43f720:64/0x439e10）。
