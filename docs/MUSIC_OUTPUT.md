# Web BGM关闭模式832–837

当前启动器支持`music:'ogg'`和`music:'none'`。none关闭本次会话的BGM输出，音效仍使用原输出；没有修改保存的音量、默认设置、原生逻辑、录像或个人存档。MIDI继续明确拒绝。

此适配器仍依赖完整且已验证的DAT＋OGG包。none是输出静音，曲目可以继续读取、解码并保留真实source生命周期，不表示无需音乐资源或节省下载/解码成本。runtime-info明确报告requiresCompletePackage与有限适配范围。

## 输出归属

`music-output.mjs`对OGG直接返回原destination，不新增节点；none在BGM专用路径加入0增益节点，以destination/context为归属用WeakMap复用。StageMusic、OriginalTitleAudio、普通终局Music7交接、旧标题/音乐室及结局数字PCM都接入。原音量、渐隐、停止和Music7重接在静音门上游执行，无法重新打开输出；音效不经过该门。

游戏保持实际source/fade/stop及既有严格收据和原生ACK顺序，没有假造完成。Web的“听过曲目”设置辅助函数在none不写seenMask；原生档案的逻辑标记未改，均不冒充设备可听证据。
