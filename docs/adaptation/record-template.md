# 验证记录模板

将下表复制到仓库的 `archive/<主题-日期>/` 下，文件名说明作品与检查主题。结果文件放在同目录，或链接到对应 CI 运行及附件。

| 字段 | 填写内容 |
| --- | --- |
| 提交 | 完整 commit SHA；有未提交修改时附补丁或树身份 |
| 源码 | 例如 `ports/th10-mp` |
| 构建 | `normal` 或 `multiplayer`；Runtime 文件哈希和编译选项 |
| 公共库 | 本次构建使用的 common 来源记录 |
| 环境 | 操作系统、浏览器版本、设备、显示刷新率 |
| 网络 | 联机时填写通道、人数、延迟与抖动设置 |
| 检查编号 | 本作 ADAPTATION.md 中的编号 |
| 操作 | 可重复执行的步骤、输入和样本 |
| 结果 | 实际观察到的结果及差异 |
| 附件 | 日志、逐帧对照、截图或测试运行链接 |

完成后，在 `ADAPTATION.md` 的“运行验收记录”节注明检查编号、模式与结果，并链接这份记录。后续修复使用新的记录，便于比较两次构建。
