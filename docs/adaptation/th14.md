# TH14 网站接入

TH14 使用 [AdingApkgg/thp](https://github.com/AdingApkgg/thp) 的独立 C++ / SDL3 / WebGL2 运行时，以 `retail-memory` 目录适配器接入启动器。作品显示在「测试版功能」中，状态为适配测试中；本接入不代表已达到原版 1:1。

## 发布输入

- 已构建的 TH14 目录运行包及 `runtime-files.json`，包含 SDL Wasm、工作线程、归档解码器、`Th14StageMemoryWorker.wasm` 和字体栅格。
- 日文 v1.00b 的 `th14.dat` 和 `thbgm.dat`。内容准备器核对原版哈希，输出 `th14.data` 和 18 首 Ogg Vorbis；文件在虚拟文件系统中挂载为 `/th14.dat`、`/music/*.ogg`。
- 网站封面和站点图标。原作数据、音乐及生成运行包由运营方部署，不加入 Git。标准封面准备器已登记 `th14-card.jpg`，默认使用仓库内现有卡图，也接受 `--override-dir` 下的同名 JPEG。

`ogg` 组件和其他作品一样使用 libvorbis 质量 5。循环起止继续从原版 `thbgm.fmt` 读取。已安装的旧 FLAC 包可以继续播放，更新资源后切换为 Ogg。没有 MIDI 模式。

## 构建修复后的运行时

生产核心直接使用 [THP `59a8cc4c`](https://github.com/AdingApkgg/thp/commit/59a8cc4cc5ae404d8439019b35f4915f75c03c5d)。该提交已整合 Goan114 的 ANM／界面／原版高清字库与纹理、Ogg／短输入及浏览器调度修复，并补回无纹理绘制时解绑旧 sampler。配置保留原版的 640×480、960×720、1280×960 三档。`tools/th14-anm-vm-oracle.py`、`tools/th14-ui-oracle.py` 和 `tools/th14-texture-display-oracle.py` 提供原版组件对照。协作补丁文件仍保留原始差异；后续 `19170e47` 的延迟颜色清屏／alpha 优化是独立候选，尚未作为这里的生产核心发布。

在独立 THP 工作树直接构建该提交。原先的运行目录用于提供不随核心编译的启动协议模块、归档解码器和字体：

```sh
git -C /srv/source/thp fetch origin main
git -C /srv/source/thp worktree add --detach /srv/source/th14-release 59a8cc4cc5ae404d8439019b35f4915f75c03c5d
python /srv/source/th14-release/tools/th14-build-gles.py --emsdk /srv/emsdk --out /srv/build/th14-core
```

```sh
bun launcher/scripts/prepare-th14-content.mjs --original=/srv/original/th14 --output=/srv/content/th14
cd launcher
bun scripts/prepare-th14-runtime.mjs --input=/srv/build/th14 --output=/srv/runtime/th14-template
node scripts/assemble-th14-runtime.mjs \
  --template=/srv/runtime/th14-template --core-build=/srv/build/th14-core --output=/srv/runtime/th14
bun run build
bun scripts/package-server.mjs \
  --games=th14 --test-build=1 --profile=web-release-th14 --output=/srv/releases/th14 \
  --th14-build=/srv/runtime/th14 --th14-assets=/srv/content/th14 \
  --th14-ogg=/srv/content/th14 --music=ogg \
  --artwork-dir=/srv/artwork --font=/srv/fonts/unifont.otf \
  --vanilla-font=/srv/fonts/msgothic.ttc --site-url=https://example.invalid/
bun scripts/verify-server-build.mjs /srv/releases/th14
```

源码工作区的 `ports/th14` 对应 THP 独立检出，供发布来源登记使用。模板准备步骤去除归档加载器的 Node 后端；组装步骤核对构建回执中的核心模块和工作线程身份，替换模块并重写启动壳和目录清单。打包器发布不可变 generation、内容描述符、哈希和版本清单。

最新核心另修正 TH14 Player 激活前的空速率时钟及 tick 默认速率；六种自机初始化、960 次时钟比较、加载回归和静音普通开局通过，完整录像／画面／声音及旧加载 RNG 反例仍开放。[验证范围](https://github.com/AdingApkgg/thp/blob/59a8cc4cc5ae404d8439019b35f4915f75c03c5d/docs/porting/TH14_PLAYER_INITIALIZATION_NOV13.md)。

当前核心另补齐33个Player移动历史点和八个僚机初始Y；原版六自机90步、当前35,000回调所测状态及弹字段通过，三面相机缓存差异仍开放。正式包仅重编1单元、核验复用145，原点39个完整响应均通过，公网首轮37个通过、两个连接重置文件完整重取后也通过；没有Range、缓存清除或完整性绕过。既有18首Vorbis保留，实际生产解码器及流式适配器另通过99,457,880帧独立解码比较、54个寻址窗口与循环边界检查；这不代替浏览器播放、最终PCM或整作1:1验收。

测试站的固定 1280×960 运行时使用 [TH14 核心补丁](../../launcher/patches/th14-runtime.patch)。它保留上述 Player 初始化和纹理绑定修复，并启用延迟颜色清屏、道具空槽跳过、矩形消弹共享旋转以及 ANM 绘制链直接摘除。测试构建使用下面的补丁入口，再执行相同的目录组装和打包命令：

```sh
git -C /srv/source/thp worktree add --detach /srv/source/th14-test 5eb4ac87d227027f390fa006e1126a094b820860
git -C /srv/source/th14-test apply --index /srv/source/eagler-touhou/launcher/patches/th14-runtime.patch
python /srv/source/th14-test/tools/th14-build-gles.py --emsdk /srv/emsdk --out /srv/build/th14-test-core
```

组装测试包时可用 `--max-file-bytes=15728640` 限制单文件大小。超过上限的字体表以 gzip 文件发布；浏览器解压后核对原始大小和 SHA-256，再交给游戏使用。

## HTTPS 和线程

当前运行时使用共享内存线程，部署必须提供可信 HTTPS，并在网站与运行时响应中设置：

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
Cross-Origin-Resource-Policy: same-origin
```

不可变 Runtime generation 的响应还必须包含 `Cache-Control: no-transform`，让 CDN 保留哈希清单登记的原始字节。Cloudflare 的 WebMCP／JavaScript Detections 自动插入脚本会改变 HTML 长度和哈希；不要通过放宽启动器校验来兼容改写后的程序。仓库静态服务器已为 generation 路径设置此指令，其他反向代理也应保留它。Cloudflare 的相关行为见[缓存指令说明](https://developers.cloudflare.com/cache/concepts/cache-control/)。

TH14 的不可变 `runtime/th14/<generation>/fonts/*.bin` 使用既有 HTTP 压缩管线；这只改变传输编码，解压后的资源字节仍按清单完整核验，`no-transform` 保留。其他作品和任意二进制路径的压缩规则不变。

仓库静态服务器可通过环境变量开启这些响应头：

```sh
EAGLER_TOUHOU_CROSS_ORIGIN_ISOLATION=1 node scripts/serve-static.mjs /srv/releases/th14 8208
```

HTTP loopback 可通过 SSH 转发用于浏览器验收；它连接的是远端生产服务。普通远端 HTTP 不能满足共享内存的安全上下文要求。使用 Cloudflare Tunnel 时，将目标域名的 ingress service 指向该 loopback 服务，并确认公网 HTTPS 响应保留以上三个响应头。隧道无需将本机监听端口开放到公网。
