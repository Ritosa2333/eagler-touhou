# TH12 密集弹幕与 Bomb 展示管线

## 固定逻辑，按实际刷新节奏组织展示

TH12 的游戏逻辑、弹幕、Bomb、道具生成及 RNG 保持不变。展示管线改用 Wasm 定长记录传递 owner、动画谱系和激光连续性信息，避免每帧对全场对象进行 JSON 编码、解码。旧 JSON 接口保留，作为兼容路径和逐字段校验参考。

- ANM 插值掩码直接遍历现有轨道，不再为展示复制完整诊断数据。
- 每个不可变展示端点复用 owner/激光索引；未改变的动画标量复用原始外观对象。
- 未锁帧时，普通60Hz或负载导致的慢帧直接展示逻辑端点；连续4个快于逻辑步长的回调恢复中间帧插值。rAF、逻辑累加器及游戏时间步长不变，75/90/120/144Hz仍可插值。
- 背景截图纹理首次创建、验证后复用存储，后续帧使用 copyTexSubImage2D，移除逐帧重分配和同步错误查询。上下文丢失仍由现有错误处理接管。

## Extra + 连续 Bomb 压力场景

实测工具 `tools/ports/th12-byakuren-profile.mjs` 支持 stage、section、机体、Bomb、展示节奏和新旧接口逐字段校验。资源为实际 Extra section69，固定种子0x1234，早苗B，持续开火，在300、900帧开B，运行1200帧，最高783颗敌弹、1186个展示对象。测试启用玩家/敌人无敌及无限B，以保留固定压力场景。

桌面 Chromium/NVIDIA GPU、CPU限速4倍，未锁帧；每帧处理耗时包含逻辑、展示准备、插值及绘制提交：

| 场景 | 上轮 test | 本轮高刷插值路径 | 本轮实际60Hz/慢帧路径 |
| --- | ---: | ---: | ---: |
| 普通窗口平均 | 28.18ms | 18.99ms | 11.02ms |
| 开B窗口平均 | 38.61ms | 24.81ms | 14.21ms |
| 开B窗口P95 | 45.90ms | 31.30ms | 18.50ms |

两条新路径与原实现的1200帧完整核心状态、RNG、对象数量及绘制调用数一致。六机体分别运行1200帧，每30帧对比二进制与JSON的所有字段，并验证读取展示数据不会改变核心状态。浮点数按float32精度比较。

## 验证与发布范围

- 77项 JS/运行时回归通过，覆盖二进制边界检查、端点独立性、刷新节奏、背景纹理复用、输入、判定点及六机体低速标记。
- 10项实际 C++ ANM 原版对照测试通过；每次采样额外核对新掩码与完整诊断数据推导值。
- 正式普通 TH12 Runtime 包含55个代码文件；资源包、多人实现、其他游戏和 UI 不变。
- 发布到 test 并保留上一版回滚，主站和 beta 不变。

表中数值是可重复的浏览器 CPU 压力测试，不是手机真机帧率；实际手机的 GPU、温度和浏览器调度仍需回归。
