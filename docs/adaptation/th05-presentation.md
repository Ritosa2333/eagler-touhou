# TH05 判定点与多人配色

普通版和多人版的可选判定点使用居中的 2×2 原生像素方点。坐标取整后覆盖中心左上方到中心位置的四个像素，低速淡入与常驻显示沿用各自开关；显示不修改实际碰撞范围。

多人按同角色出现顺序选择审定 ZIP 的原色、替代色一、替代色二。自机、幽灵、16 帧射弹及右侧机型标记共用对应席位的纹理。原火力槽和数字火力布局都直接复用该席射弹第一帧，精灵图集保留其原始颜色。

多人自机身体沿用原版的弹幕遮挡顺序，位于敌弹、激光和弹幕效果下方。本机身体在队友身体之后绘制，判定点在弹幕之后绘制；队友近距离透明度继续作用于身体和射弹。

`ports/th05-mp/tests/player-art-browser.mjs` 对比审定素材的 240 张纹理哈希。`ports/th05-mp/tests/player-pixels-browser.mjs` 读取实际 WebGL 输出，检查四角色在整数／小数位置的四像素判定点、192 个射弹帧以及两种侧栏的 24 个机型标记。
