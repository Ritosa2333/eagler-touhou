# 语言与练习

[适配流程](README.md) · [文档目录](../README.md)

翻译包、字体和练习功能各自检查。产品声明、实际构建与界面显示保持一致。

## 准备

选择一个已提供的翻译语言，准备对应字体。构建启用练习的变体后，分别测试普通开局、Practice、Restart 和 Replay。

字段、文件目标和实践接口见[语言与 thprac 接口](../../launcher/integrations/RUNTIME_CONTRACT.md)。

## 逐项检查

| 编号 | 操作 | 通过时应看到 |
| --- | --- | --- |
| <a id="practice-01"></a>PRACTICE-01 · 发布包中的练习能力 | 核对产品能力、构建选项与 Runtime Release。 | 发布信息反映实际编入的练习功能。 |
| <a id="practice-02"></a>PRACTICE-02 · 开局前启用与语言 | 选择语言和练习开关后启动。 | 游戏在开局前收到 `thpracEnabled` 与 `thpracLocale`。 |
| <a id="practice-03"></a>PRACTICE-03 · 游戏内练习状态 | 练习、重开、回放、普通开局之间切换。 | 练习状态由游戏管理，并随场景正确创建与清理。 |
| <a id="practice-04"></a>PRACTICE-04 · 关卡与资源参数 | 设置关卡、阶段、帧数、资源和分数参数。 | 界面列出的参数实际作用于本作逻辑。 |
| <a id="practice-05"></a>PRACTICE-05 · 练习 Replay 元数据 | 保存含练习设置的 Replay，再独立导入回放。 | 必要参数随 Replay 保存并可还原。 |
| <a id="practice-06"></a>PRACTICE-06 · 触控功能键与指针 | 用触控功能键、原生指针操作练习菜单。 | 按键与指针走本作练习入口。 |
| <a id="practice-07"></a>PRACTICE-07 · 练习语言跟随设置 | 切换启动器语言，再打开练习菜单。 | 练习界面采用对应语言和字体。 |
| <a id="practice-08"></a>PRACTICE-08 · 练习界面的可用功能 | 逐项操作界面列出的练习功能。 | 显示的功能均有对应实现。 |
| <a id="lang-01"></a>LANG-01 · 内置日语原文 | 选择日语并离线启动。 | 使用内置原文资源。 |
| <a id="lang-02"></a>LANG-02 · 语言包身份与发布清单 | 准备翻译包，核对清单、字节数与哈希。 | 只有已打包的语言出现在选择中。 |
| <a id="lang-03"></a>LANG-03 · 开局前挂载翻译与字体 | 在启动前切换翻译，查看资源和字体挂载。 | 游戏首帧使用所选翻译资源。 |
| <a id="lang-04"></a>LANG-04 · 语言包失败时回到原文 | 使可选语言包暂时获取失败。 | 本次回到原文，保存的语言偏好仍可下次使用。 |
| <a id="lang-05"></a>LANG-05 · 字体字符覆盖 | 检查菜单、对话、结算、练习界面的实际字符。 | 当前语言所需字形完整。 |
| <a id="lang-06"></a>LANG-06 · 缺译资源使用原文 | 提供只翻译部分资源的包。 | 缺少的翻译使用本作原资源。 |
