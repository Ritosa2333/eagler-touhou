# TH12 手机低速、判定点及无敌收符修复

## 行为

- 暂停/暂停确认界面和恢复时保留触屏“切换式低速”，但释放拖动目标、方向和 Bomb 脉冲。按住式低速、双指低速不保留；返回标题、重试、新局和禁用触屏仍重置。
- 常显判定点不再固定采样 ANM77 刚出现的缩小帧。使用原始77→76完整、稳定大小的双层标记，按原版 layer16 绘制，不创建逻辑 VM，不改变移动速度或游戏 RNG。
- Purple 无敌撞弹仍保留音效、六帧碰撞保护且不扣资源，但先执行原版438370的符卡资格判定；无敌补丁43837f不应跳过该判定。普通无敌时间内的碰撞仍被忽略。

## 展示负载

锁定60Hz时不导出/解析高刷新率插值所需的 owner/lineage 图。高刷新率保留原有权威图，但不再重复构建旧核心兼容图。旧核心仍使用兼容路径。四边形顶点提交改为固定 RGB 字段，避免逐顶点展开临时迭代器。未删减弹幕或改变逻辑帧率。

实测工具：`tools/ports/th12-byakuren-profile.mjs`。加载实际六面资源、THPrac section45（白莲三非）、Easy、早苗B、固定种子0x1234，禁用玩家/敌人死亡，运行1800帧，最高799颗弹。浏览器使用桌面 NVIDIA GPU，CDP CPU 限速4倍；这是可重复的 CPU 压力对比，不是手机真机结果，也不包含完整启动器和音频开销。

| 模式 | 逻辑平均耗时 | 展示准备平均耗时 | 绘制提交平均耗时 |
| --- | ---: | ---: | ---: |
| 原实现 | 2.12ms | 18.43ms | 8.37ms |
| 修复后锁定60Hz | 1.70ms | 4.09ms | 4.95ms |
| 修复后高刷新率 | 1.87ms | 13.73ms | 4.88ms |

三次完整1800帧的核心状态（含 RNG、弹幕及 ANM）严格相等。数字有环境波动，不承诺所有设备或白莲所有攻击都达到60fps。用户截图所示攻击还需真机回归。
