# TH128: launcher-style touch UI and Core119

The standalone page follows the structure of Eagler Touhou's PlayerControls, TouchHelp, OptionsPanel and TouchLayoutEditor at commit 886952931e30e672253ea3abc8464d74ad662531. The parent launcher still owns a managed embedded runtime. The same touch model, input source leases and launch commands are used across the browser boundary. These changes don't add a second launcher catalog or send an upstream pull request.

- Touch defaults to capped original movement. Unlimited direct touch is labeled as assisted and uses the existing score/qualification policy; previously saved controls stay in place. The practice window receives real pointer events in front of the gesture plane. An active World uses a background hold distinct from manual pause; verified at a controlled blur/focus boundary with a real in-stage route choice and native Down gesture. The nested browser's actual tab switch did not deliver child focus events in the two earlier attempts.
- A centered 4:3 surface, fullscreen or browser-viewport fallback, Help and independent Music/SFX settings share the in-game rail. The existing touch layout editor remains available in fullscreen. The standalone launch drawer covers resources, replay export/import, language, refresh rate, pixel display, local keyboard and standard gamepad settings, music and touch. Standard pad mapping has an automated device boundary test; physical hardware wasn't used.
- The launch header uses the Fairy Wars cover supplied by the user (450×445; original PNG bytes, SHA-256 763c5ab8677999b020b635dd53e59d577be6ebf940543f814a735dbcf4d0d6ad). This asset is used as cover art only, not a game backdrop. Launcher/THPRAC notices and required sources stay in the local package.
- Core119 dispatches the original third-stage portrait scripts from the verified stage/card table. The exact zero-depth portrait geometry is accepted by the Web renderer. Actual Fairy Overdrive advanced past the repaired cut-in and no longer submitted the stray small draw at the upper-left.
