# th12 菜单音效 | Edge A/B | 2026-10-24

同一份零售 WAV 在本机 Edge 中进行菜单音效 A/B：原采样率 PCM 缓冲路径的听感更接近清晰的原版。两条路径使用相同文件、默认音效音量和无 BGM 输出；比较了选择、确认、取消三种菜单音。

| 路径 | WAV 处理 |
| --- | --- |
| A | `decodeAudioData` 在加载时转换为 Edge 的 48 kHz `AudioBuffer` |
| B | 读取 PCM，按 WAV 的 22.05 kHz 创建 `AudioBuffer`，播放时由 WebAudio 输出 |

用户在 A/B 对照后选择 B。适配播放器采用 B 路径，并保留原有音效编号、音量、声像和播放时序。

资源包中的 48 个 WAV 均为 8/16 位 PCM，采样率为 22.05/44.1 kHz，声道数为 1/2；其中 5 个含 `JUNK` 块。Edge 中的播放器成功预载全部 48 个文件，三种菜单音的离线输出与 B 路径逐样本一致。PCM 解析及音乐相邻测试共 10 项通过。
