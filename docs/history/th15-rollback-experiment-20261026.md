# TH15 多人回滚实验

实验分支 `experiment/th15-rollback-20261026` 使用独立工作区，逐帧状态恢复与章节重试分别维护。游戏状态包含计时器的小数与前值、动画句柄和父子关系、实体与 ECL 脚本、随机数、各席位输入边沿及共享资源。

验收覆盖迟到且不同的输入触发恢复与重演；完整十二帧校正后继续推进新逻辑帧；校正结果与按时收到输入的基准一致；逐帧快照复用存储；音效、录像和观战只提交确认帧；相同停滞画面的重复绘制不增加游戏 FPS。

模式入口在完整状态恢复通过验证后接入。来源沿既有 TH15 多人原仓库祖先建立独立连接；普通开发和投影提交去除继承的子树控制标记，标准子树导出验证源码树与上游祖先。
