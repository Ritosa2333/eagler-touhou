# 原生分数文件与只读导出826–831

当前页面能从已验证的网页原生档案导出真正的T821分数容器，包含全部52232字节档案字段。此前Replay文件桥保留。不存在档案时返回errno44，不创建默认档案、姓名或数据库。

`scoreth128.dat`是本适配器定义的导出名，尚未证明它是原作文件名。接口支持list/read，拒绝write/remove。配置JSON没有改名为原生cfg，外部文件没有伪装成当前World捕获的档案；完整fileBridge仍为false。

## 格式与字段

独立模块`site/runtime/native-score-file.mjs`处理24字节T821头、16字节分块/ac/35加密、8192字节环形LZSS和块校验。内存顺序为8CR/ST/CD，文件顺序为8CR/CD/ST。按现有NativeScoreProfile::assemble重算校验及路线序号，其余字段保持。编码使用有效的确定性literal流，解码支持生产压缩器的匹配及有限隐式尾零；不承诺与原压缩器逐字节相同。

导出从实际OwnedNativeTitleRecordStore.observe读取并验证既有来源及完整profile SHA，再生成文件及完整文件SHA。profileSHA256表示来源内存档案，文件sha256表示导出容器，两者含义不同。档案缺失或损坏不会变成默认档案。解码导出文件时，最多72字节的校验及路线序号可与来源内存不同；完整语义字段保持。来源SHA不是导出解码档案的SHA，也不是不可伪造的身份认证。没有修改任何真实个人存档。

sync沿用已有Replay专用收据，files/verifiedFiles仅包括已提交Replay，不列分数文件，也不表示正在运行游戏或所有档案已flush。分数导出没有加入新的持久写入或sync承诺。
