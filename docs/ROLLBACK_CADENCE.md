# 多人回滚与可见帧率

每轮原生更新先完成旧帧纠正，再运行当前时刻的新游戏帧。13 帧预算同时容纳最多 12 帧回滚重算和一帧新进度。真实输入、提交边界和存档世界保持相同的确定性规则。

回滚使旧插值端点失效，按贴图、脚本、参数与年龄确定的动画采样缓存继续复用。单条采样请求回退时，该轨道独立重建；切换资源、重新启动和关卡装载重新建立完整采样器。等待输入期间直接复用静止端点。

HUD 和宿主帧率报告统计实际推进的可见画面。插值子帧计入高刷帧率，同一世界的重复提交不计入；停止推进显示 0.0 FPS。暂停菜单继续按实际绘制频率计数。浏览器回调和游戏逻辑推进分别承担调度和呈现职责。

纯回滚时钟使用共享的 0.98～1.02 倍同伴进度校准。缺少远端输入时使用约定的回滚窗口，并在窗口边界等待后续输入。

回归覆盖一帧和完整 12 帧纠正后的新帧推进、按时输入的世界哈希、静止画面与高刷计数、动画缓存重用和采样回退。真实 WASM 浏览器测试覆盖两人、三人、75 毫秒中继延迟、25 毫秒抖动、持续射击、往返移动和 Bomb。
