# TH02 来源子树与主项目适配

`ports/th02` 将 DOSBox-X 封魔录运行时接入主启动器与合作房间。Package Store 提供原版游戏资源，主项目文件服务保存 `HUUHI.DAT` 与 `HUUMA.CFG`；两人、三人房间继续使用原有游戏同步内核与主项目 Relay/WebRTC 传输。

在 monorepo 根目录运行 `node ports/th02/scripts/dev.mjs` 启动本地适配。入口包括单人游戏、独立存档空间和主大厅合作模式；测试脚本列于 [适配说明](../../ports/th02/README.md)。

## 来源与维护

原仓库 [`th02-coop-lab`](https://github.com/IxinorTyan/th02-coop-lab) 的 `main` 提交 `5b5d583faddfd837b423cbeb705c3e0504f18c1f` 及该分支截至此点的全部 36 个原始提交均保留为当前仓库的祖先；作者、时间、说明与原始提交 ID 均保留。主站适配提交的目录投影与原仓库通过合并连接，当前目录由标准 Git subtree 导出。

首次连接提交为 `268bf9b9688a1581b8c4ce3e01205dc7f8d27e21`，导出基点为 `1d5b0bf8a21d7b205a58b9dcd4571f57f8de3a25`。原仓库 README 保存在 [README-UPSTREAM.md](../../ports/th02/README-UPSTREAM.md)。源文件与运行资源的划分记录在 [source-import.json](../../ports/th02/source-import.json)。

在 monorepo 根目录运行 `node ports/th02/scripts/build-eagler.mjs --assets=../th02-coop-lab/web`，从本目录代码和外部资源生成 Runtime 与 DATA。`--source=<完整原仓库>` 保留独立来源对照构建入口。开发脚本默认读取相邻原仓库的资源目录，也可通过 `PC98_ASSETS_DIR` 指定。

历史查询、subtree 导出、后续同步与 PR 合并步骤见 [TH01–TH04 子树维护](pc98-subtree-20261026.md)。
