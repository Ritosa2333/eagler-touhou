# TH02 来源子树与主项目适配

`ports/th02` 将 SoEW Native 接入 Eagler 书库、大厅和观战。Runtime 提供 SoEW WASM，Package Store 提供原版素材、字形和音源。构建与验收见 [TH02 开发入口](../../ports/th02/README.md)。

## SoEW Native 来源

`ports/th02/native-solo` 来自 [Hydrangea-Z/SoEW-native](https://github.com/Hydrangea-Z/SoEW-native) 的本地开发分支 `codex/soew-smooth-scroll`。原始提交兼初始导出基点为 `6011dc7ea386683d0c4e9816f769eb3a29b49b40`，子树连接点为 `d068098ae29350a6b363ce3dac5b893a399fb129`。浏览器宿主和 Win32 版共用游戏核心，包括原生标题、菜单、各关、Extra、练习、录像、结局和音乐室。

独立公开源码位于 [IxinorTyan/SoEW-native](https://github.com/IxinorTyan/SoEW-native) 的 `main`。首次公开导出提交为 [`a1d8aec`](https://github.com/IxinorTyan/SoEW-native/commit/a1d8aec3b2f3095f8808fcf9cf7a2d5f3380f64d)，其源码树与 monorepo 提交 `5d99d423a` 的原生目录相同，并保留 Hydrangea-Z 上游 `af31bee47e1dd96c85a4fed4d3b577c34c779390` 和原始导入基点的祖先关系。同步独立源码时，以 `ports/th02/native-solo` 为子树范围；外围 Eagler 宿主保留在主项目内。

[`th02-coop-lab`](https://github.com/IxinorTyan/th02-coop-lab) 的 `main` 提交 `5b5d583faddfd837b423cbeb705c3e0504f18c1f` 及之前的 36 个原始提交均保留为当前仓库的祖先。首次连接提交为 `268bf9b9688a1581b8c4ce3e01205dc7f8d27e21`，导出基点为 `1d5b0bf8a21d7b205a58b9dcd4571f57f8de3a25`。[来源登记](../../ports/th02/source-import.json)记录初始导入；DOS 运行时不再属于 TH02 构建输入。
