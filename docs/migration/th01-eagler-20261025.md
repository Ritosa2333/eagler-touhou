# TH01 来源子树与主项目适配

`ports/th01` 将 TH01 原生 WebAssembly 核心接入主启动器与多人房间。单人使用独立主项目存档空间；合作局由主项目管理成员和时序，游戏核心继续运行原有同步与确认逻辑。构建器为每个上游输入保存字节数与 SHA-256，DATA 资源在安装和运行时校验完整性。

在 monorepo 根目录运行 `node ports/th01/scripts/dev.mjs` 启动本地适配。入口包含单人安装、存档和多人 Runtime；测试脚本列于 [适配说明](../../ports/th01/README.md)。

## 来源与维护

原仓库 [`th01-multiorb-lab`](https://github.com/IxinorTyan/th01-multiorb-lab) 的 `main` 提交 `0fdb5febf1236af61754ea41566a913d14a4b39a` 及该分支截至此点的全部 29 个原始提交均保留为当前仓库的祖先；作者、时间、说明与原始提交 ID 均保留。主站适配提交的目录投影与原仓库通过合并连接，当前目录由标准 Git subtree 导出。

首次连接提交为 `1d57be08848aa0d036f06107aabf57cf065b112b`，导出基点为 `c9501d90358664ca333753c3dac51f4b693324f4`。原仓库 README 保存在 [README-UPSTREAM.md](../../ports/th01/README-UPSTREAM.md)。源文件与运行资源的划分记录在 [source-import.json](../../ports/th01/source-import.json)。

在 monorepo 根目录运行 `node ports/th01/scripts/build-eagler.mjs --assets=../th01-multiorb-lab/web`，从本目录代码和外部资源生成 Runtime 与 DATA。`--source=<完整原仓库>` 保留独立来源对照构建入口。开发脚本默认读取相邻原仓库的资源目录，也可通过 `PC98_ASSETS_DIR` 指定。

历史查询、subtree 导出、后续同步与 PR 合并步骤见 [TH01–TH04 子树维护](pc98-subtree-20261026.md)。
