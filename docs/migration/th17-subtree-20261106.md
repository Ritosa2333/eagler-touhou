# TH17 普通版与多人版目录历史

`ports/th17` 维护普通版，`ports/th17-mp` 维护双人和三人合作版。两侧拥有独立编译输入、运行包和目录历史，启动器通过 `th17` 与 `th17mp` 工作区映射分别选择源码。

TH17 的开发交付身份由 [2026-10-30 原交付清单](th17-eagler-20261030.json)和归档校验表保留。Git 来源从真实的 monorepo 导入提交 `4f310d73b648c9e4a75fb18efd461eccb3b5d8fa` 开始，27 个目录提交按原作者、时间、内容树和相关父链投影，逐提交生成 `Monorepo-Source` 与 `Source-Prefix`。初始目录来源提交为 `ca7f023250303110577978aaf717787b674d3aee`，分目录前的导出基点为 `cd3e5490abe8a04e35a2b588dd3ec13c5844c85d`。

普通版连接提交为 `b49f2b9969497fdf61dc2ea8637fbb13699fa5c6`。多人版在 `1ebf8232da0a16910c96cca571f0a60060e95691` 复制完整源码树，通过 `e164e472b1ccc6fecde6984cc4d45fdeae5abf2e` 继承同一来源基点。复制时两侧 Git 内容树逐位相同，随后按模式设置构建入口、源码归属和开发文档。多人版来源登记见 [th17mp](th17mp-eagler-20261106.json)。

从仓库根目录导出并检查源码树。

```sh
git subtree split --prefix=ports/th17 --branch th17-subtree
git subtree split --prefix=ports/th17-mp --branch th17mp-subtree
git merge-base --is-ancestor ca7f023250303110577978aaf717787b674d3aee th17-subtree
git merge-base --is-ancestor ca7f023250303110577978aaf717787b674d3aee th17mp-subtree
git rev-parse HEAD:ports/th17 th17-subtree^{tree}
git rev-parse HEAD:ports/th17-mp th17mp-subtree^{tree}
```
