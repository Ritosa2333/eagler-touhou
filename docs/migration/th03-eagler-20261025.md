# TH03 来源子树与主项目适配

`ports/th03` 将梦时空 DOSBox-X Runtime 接入主启动器、Package Store 和两人对战房间。主项目负责文件空间、房间成员与开局；原生游戏继续负责角色选择和对战，运行时保留其确定性输入同步与状态校验路径。

在 monorepo 根目录运行 `node ports/th03/scripts/dev.mjs` 启动本地适配。入口包括单人存档、原生双人选人和主大厅；测试脚本列于 [适配说明](../../ports/th03/README.md)。

## 来源与维护

原仓库 [`th03-netplay-lab`](https://github.com/IxinorTyan/th03-netplay-lab) 的 `main` 提交 `63d8c211c131ab52a43e706f8b5ad7718ba7858f` 及该分支截至此点的全部 42 个原始提交均保留为当前仓库的祖先；作者、时间、说明与原始提交 ID 均保留。主站适配提交的目录投影与原仓库通过合并连接，当前目录由标准 Git subtree 导出。

首次连接提交为 `7f5d3efcf2135d5c5593b954c3bdc63cf45a9027`，导出基点为 `eb1c09111b1f08e068a679fb97f76f5d8ad10599`。原仓库 README 保存在 [README-UPSTREAM.md](../../ports/th03/README-UPSTREAM.md)。源文件与运行资源的划分记录在 [source-import.json](../../ports/th03/source-import.json)。

在 monorepo 根目录运行 `node ports/th03/scripts/build-eagler.mjs --assets=../th03-netplay-lab/web`，从本目录代码和外部资源生成 Runtime 与 DATA。`--source=<完整原仓库>` 保留独立来源对照构建入口。开发脚本默认读取相邻原仓库的资源目录，也可通过 `PC98_ASSETS_DIR` 指定。

历史查询、subtree 导出、后续同步与 PR 合并步骤见 [TH01–TH04 子树维护](pc98-subtree-20261026.md)。
