# EX 终局存储等待后的身份复核（2026-11-16）

本项属于移植阶段的异步生命周期修复。EX 终局档案写入过程中，原生场景或记录器身份若发生变化，前端现在会在发送原生保存确认之前拒绝继续，避免先确认、后在退休阶段发现身份错误。

## 原因与修改

`OriginalExtraRunController.retire()` 原先在异步摘要、打开存储和严格读回之前检查终局身份，等待结束后只检查页面归属和档案字节。原生保存确认检查 phase4/pending16，但完整终局身份检查在后续退休调用才发生。

修复只在原有整包读回和字节比较之后、原生确认之前重新读取 state、driver、record，检查帧数、会话代次、原生场景、终局计数及记录器身份。时钟序号仍精确要求 serial+2。没有改变原生代码、辅助模式、输入、游戏计时、资源或通关历史。
