# Practice medals, LEVEL MAX, dense presentation and Retry

- The original spell end (`0x40e350`) marks bronze when a live card ends, silver when capture survives, and gold when both original capture flags hold. The original `ascii.anm` sprites continue to read the per-card grades at the next spell start. Ordinary score profiles stay on their existing owner; practice keeps a separate medal history and reads existing ordinary medals without writing the original score table. Starting or abandoning a card does not earn a new medal. Playback only reads presentation history.
- A fresh or carried World starting in native shot group 15 now loads `pl00.anm` script 71 (sprite 78, x576/y400), without a level-up sound or burst. A live level-up still uses the original transition. The existing thresholds select the group; e.g. Lunatic at 2999% is below MAX and 3000% selects MAX.
- Both refresh modes use bounded native state projections instead of repeatedly building diagnostic arrays. Stable draw priority buckets, batch reuse, and same-state title text reuse preserve native ordering and pixels. The full diagnostic and replay/logic APIs remain separate. Cases 1248/1254 compared 4 actual Lunatic Three Fairies frames, and case 1257 compared exact vertex/texture/blend submissions on both a 509-record barrage and an 8236-record freeze. Those CPU numbers are not display refresh claims.
- The first original Game Over action in live practice directly restarts the initially selected card or stage. The canceled pre-update clock does not count as a replay frame; a fresh recording starts with the new World. Ordinary Continue retains its own behavior.

Native actual cases: 1252 (Petit Comet completion and fresh entry), 1253 (A2-3 Game Over and completed RPY boundary), 1254 (compact-state and exact draw parity). Core121 contains four new exports for the presentation/input/medal data. Older package and replay core identities stay available.
