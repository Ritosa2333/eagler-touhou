# Web 触控与输入归属

2026-11-17新增触控层接入当前core112前端：方向拖动、低速、射击/确认、完美冻结、暂停和返回使用现有键盘消费者，模块不直接调用World或推进逻辑帧。仅粗指针媒体条件显示，桌面鼠标操作保持原键盘路径。

每个触点单独持有按键；同一动作多指按住到最后一指松开才释放。键盘和触控交叠时只释放自己的来源。左右Shift同原生低速位的别名通过首个实际贡献按键桥接，避免触控与右Shift交叠误释放或留下按键。拖动使用1280×960内容框、letterbox与原数字方向，不改移动速度。捕获和release监听在同一个DOM目标。

标题、暂停、结算、结局仍由现有按键处理；切换owner清掉触点，失焦/隐藏/关页清理与原释放流程配合。模块dispose删除自己的精确监听器和层。无触点时syncContext立即返回，不逐显示帧构造状态快照。
