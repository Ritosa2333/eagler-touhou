# TH128 — 妖精大战争行为还原与 Web 移植

《妖精大戦争 ～ 東方三月精》独立行为还原工程，使用 C++/WebAssembly 核心与 JavaScript 浏览器宿主。

本仓库保存截至 **2026-11-15** 的开发源码快照。原生核心对应 private99，前端包含 case554 已通过组件验收的变更，供版本管理、代码审阅及后续开发使用。浏览器端集成验收仍在进行中。

## 当前进度

| 范围 | 状态 |
|---|---|
| 六条普通路线 A1/A2/B1/B2/C1/C2 | CPU 端流程验收通过（THPrac 式练习辅助） |
| 六线通关资格累计与 EX 解锁 | 已通过完整档案累计及资格校验 |

上述测试覆盖实际 World/ECL/MSG 执行、输入记录、关卡交接及原生对象生命周期。本文的 **THPrac 式练习辅助**指由 WASM 原生接口提供的持续免伤等测试能力；本轮未运行 Windows THPrac，也未实施进程注入。IndexedDB、音频设备输出、渲染及图像加载使用明确标记的模拟实现，其浏览器实机验证仍待完成。

验收汇总见 [docs/acceptance-20261115.json](docs/acceptance-20261115.json)，已知问题见 [docs/STATUS.md](docs/STATUS.md)。

## 源码内容

- `src/`：private99 的 226 个原生源文件，编译清单含 83 个翻译单元、205 个导出符号。
- `site/`：前端源码及 case554 的 14 个已核对文件；浏览器 EX 流程与新 API 的完整集成仍待完成。
- `tools/`：资源准备、研究和开发工具源码。
- `tests/`：历史测试源码；部分测试依赖未随仓库分发的本地资源、黄金记录或编译产物。
- `build/private99.rsp`：从成功构建记录转换出的相对路径编译参数。
- `docs/native-source-manifest.json`：原生文件摘要、编译清单和参考产物摘要。
- `docs/research/`：历史研究说明，其当时进度不替代本页当前状态。
- `licenses/`：保留的第三方许可文本。

本仓库不包含原作 EXE/DAT、贴图、音乐、录像、个人存档、浏览器用户数据、工具链或生成的 WASM。资源准备需要自行持有原作，详见 [docs/BUILD.md](docs/BUILD.md)。

## 开发与验证

参考工具链为 Emscripten 4.0.22、Node.js 22+ 和 Python 3.11+。已逐项核对源码与成功构建记录中的文件摘要；本次归档复用现有验收证据，未重新编译核心或重复执行路线测试。

独立检出环境的完整构建与浏览器启动仍待验证，运行时产物及原作资源需另行准备。`tools/build-runtime.mjs` 为保留的历史构建脚本，其导出清单早于 private99；当前构建参数以 `build/private99.rsp` 为准。
