# 東方怪綺談 · 原生多人版

`ports/th05-mp` 独立开发 uth05win 原生两人／三人合作，直接编译为 WebAssembly／WebGL 并接入 Eagler 房间、资源、触控、语言和存档协议。

- 四角色自由混选，各席独立生命、Bomb、Power，团队计分与借命救援。
- PR #143 的像素侧栏布局，血条与显示辅助由多人启动器配置。
- 原版 SE 音效，PR 原版 BGM 与“幺乐团专辑版”，日文／简体中文。
- 单人修复经目录历史合并接收，合作玩法与输入同步在本目录维护。
