# TH128 — 妖精大战争行为还原与 Web 移植

《妖精大戦争 ～ 東方三月精》独立行为还原工程，使用 C++/WebAssembly 核心与 JavaScript 浏览器宿主。

本仓库保存截至 **2026-11-16** 的开发源码快照。原生核心对应private102，新增录像累计擦弹数的写入、恢复和绑定校验修复；首次编译及实际零帧恢复检查通过。续关后完整终局、浏览器端完整流程与兼容性验收仍在进行中。

## 源码内容

- `src/`：private102 的 226 个原生源文件，编译清单含 83 个翻译单元、205 个导出符号。
- `site/`：最新前端候选，包含 EX 记录、呈现、严格存储与终局交接控制器。
- `tools/`：资源准备、研究和开发工具源码。
- `tests/`：历史测试源码；部分测试依赖未随仓库分发的本地资源、黄金记录或编译产物。
- `build/private102.rsp`：从首次成功构建记录转换出的相对路径编译参数；private100/101配方作为历史资料保留。
- `docs/native-source-manifest.json`：原生文件摘要、编译清单和参考产物摘要。
- `docs/research/`：历史研究说明，其当时进度不替代本页当前状态。
- `licenses/`：保留的第三方许可文本。

本仓库不包含原作 EXE/DAT、贴图、音乐、录像、个人存档、浏览器用户数据、工具链或生成的 WASM。资源准备需要自行持有原作，详见 [docs/BUILD.md](docs/BUILD.md)。

## 开发与验证

参考工具链为 Emscripten 4.0.22、Node.js 22+ 和 Python 3.11+。private102在录像字段修复、13项组件检查和3个完整生产翻译单元检查后首次构建成功；实际WASM初始化1个World且不运行游戏帧，恢复2529次擦弹并拒绝不一致的绑定包，205个导出接口检查通过。该检查不代表完整录像兼容通过。详见[621–627验证记录](docs/native-replay-graze621-627.md)。此前成功核心保持不变，没有重复执行六线或EX完整路线。

独立检出环境的完整构建与部署仍待验证，运行时产物及原作资源需另行准备。`tools/build-runtime.mjs` 为保留的历史构建脚本，当前构建参数以 `build/private102.rsp` 为准。
