# TH128 — 妖精大战争行为还原与 Web 移植

《妖精大戦争 ～ 東方三月精》独立行为还原工程，使用 C++/WebAssembly 核心与 JavaScript 浏览器宿主。

这是截至 **2026-11-15** 的开发源码快照：原生源码对应 private99，前端包含经过组件验收的 case554 改动。当前用于备份、阅读和继续开发，不是已经完成浏览器验收的游戏发行包。

## 当前进度

| 范围 | 状态 |
|---|---|
| 六条普通路线 A1/A2/B1/B2/C1/C2 | 已通过无敌辅助 CPU 功能链路验收 |
| 六线资格累计后进入 EX | 已通过真实累计档案资格检查 |
| EX 终局、成绩、姓名、录像、返回 Main | 已通过无敌辅助 CPU 功能链路验收 |
| 真实浏览器存储、声音输出、GPU 与焦点切换 | 尚未完成验收 |
| 完整原版录像兼容性、所有失败/续关分支 | 尚未完成验收 |
| 整体还原、整体移植、Web 发布 | 开发中，未声明整体 100% |

这些路线使用实际 World/ECL/MSG、输入记录、关卡交接和原生对象生命周期；测试开启了原生无敌辅助。IndexedDB、音频设备输出、渲染和图像加载仍使用明确标记的测试替身。没有执行或注入 Windows thprac EXE。

验收汇总见 [docs/acceptance-20261115.json](docs/acceptance-20261115.json)，已知问题见 [docs/STATUS.md](docs/STATUS.md)。

## 源码内容

- `src/`：private99 的 226 个原生源文件，编译清单含 83 个翻译单元、205 个导出符号。
- `site/`：前端源码及 case554 的 14 个已核对文件；完整浏览器 EX 接线仍需继续整合。
- `tools/`：资源准备、研究和开发工具源码。
- `tests/`：历史测试源码；部分测试依赖未随仓库分发的本地资源、黄金记录或编译产物。
- `build/private99.rsp`：从成功构建记录转换出的相对路径编译参数。
- `docs/native-source-manifest.json`：原生文件摘要、编译清单和参考产物摘要。
- `docs/research/`：历史研究说明，其当时进度不替代本页当前状态。
- `licenses/`：保留的第三方许可文本。

本仓库不包含原作 EXE/DAT、贴图、音乐、录像、个人存档、浏览器用户数据、工具链或生成的 WASM。资源准备需要自行持有原作，详见 [docs/BUILD.md](docs/BUILD.md)。

## 开发与验证

参考工具链为 Emscripten 4.0.22、Node.js 22+ 和 Python 3.11+。源码与已有成功构建的哈希逐项核对过；本次整理没有重新构建成功核心或重新运行已完成路线。

完整构建与浏览器启动尚未在这个独立源码目录内重新验收。不要将“源码已备份”解释为“克隆后可以立即完整游玩”。`tools/build-runtime.mjs` 是保留的历史构建脚本，其导出清单早于 private99；当前构建参数以 `build/private99.rsp` 为准。
