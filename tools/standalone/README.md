# 妖精大战争 · DAT + OGG 网页版

当前为 v5 性能与弹幕修复版（core109）：减少碎冰特效创建的重复全场扫描、完整状态格式化及前端顶点/插值开销，恢复遗漏的反弹坐标提交。继承v4.1启动修复；同输入保持粒子、RNG与绘制记录。逻辑仍为60Hz，原93.3MB资源包继续使用。具体设备帧率仍取决于浏览器与硬件。

从旧版升级：先在旧服务窗口按 Ctrl+C，再在本目录运行 Start.ps1，浏览器使用原来相同地址后刷新。保留该地址的已安装资源与存档，不需要清浏览器数据。命令行可使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1`。

1. 解压 Runtime ZIP，运行 Start.ps1；需要本机 Python 3。
2. 打开窗口显示的本地地址，默认 http://127.0.0.1:8138/play.html。
3. 在页面选择 th128-dat-ogg-5e3bcbd5ebb8b171.zip，等待资源校验后点击“开始游戏”。
4. 资源包保存在这个地址的浏览器存储中。以后使用相同地址启动会读取已安装资源；运行时文件与资源均在本机，无须连接外网。

如默认端口被占用，可运行 Start.ps1 -Port 8148。不同端口使用各自的浏览器存储。关闭终端可结束本地服务。

资源包为 eagler-touhou/package/1，包含原 th128.dat、10 首 OGG 音乐和中文/渲染补充包。配套核心为已完成六线＋EX功能验证的 private108。原生核心没有重新编译。资源 ZIP 另附完全匹配的解压目录。

本次代码和资源测试包括原 DAT 两版本各199文件精确还原、738个网页资源绑定、OGG循环与结局PCM处理、安装失败保留旧包和配套HTTP服务。浏览器完整终局、物理听感与设备验收仍单独记录。
