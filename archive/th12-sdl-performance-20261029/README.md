# TH12 SDL 迁移版性能验证

动画轨道复用缓存节点，静止 HUD 绑定直接推进年龄，背景裁剪复用临时缓冲，减少普通和多人前端的分配与重算。优化保留世界逻辑、回滚协议、裁剪数学及绘制顺序。

## 对比方法

基线为 `96815b816bea184affaf5c13008d2062bb19803a`。同一 Windows 主机、MSVC 19.51、`/MD /O2 /fp:strict /std:c++20` 编译前后两个原生程序，交替运行五轮，统计中位数和分配次数。`performance.json` 保存每轮原始值、汇总、源码哈希和构建身份。数据衡量 CPU 呈现组件，整场游戏帧率由逻辑、网络、GPU 和浏览器共同决定。

| CPU 工作负载 | 优化前耗时 | 优化后耗时 | 临时分配次数变化 |
| --- | ---: | ---: | ---: |
| 512 条持续轨道 × 600 帧 | 49.728 ms | 22.294 ms | 307,200 → 0 |
| 60 条静止轨道绑定到年龄 10000 | 13.385 ms | 0.015 ms | — |
| 七关背景合计 1680 次捕获 | 106.311 ms | 20.999 ms | 1,864,800 → 5,280 |

五轮动画输出哈希均为 `1bcb50759f709017`，背景顶点流哈希均为 `fffe625f4b211fa4`，前后完全一致。

动画程序：`ports/th12/tests/native/sdl-animation-performance.cpp`，链接该版本的 `Animation.cpp`、`Anm.cpp`。传入自行提取的资源目录，可核对 33 个 ANM、1393 段脚本的普通及中断采样；每段与逐帧执行参考比较稀疏年龄、倒退和显示随机数。持续采样基准为 512 条轨道 × 600 帧，另测 60 条静止轨道绑定到年龄 10000。回归检查还覆盖停止后仍运动／插值／更新子节点、年龄快进后中断、外部状态修改、未使用轨道回收与缓存重置。

背景程序：`ports/th12/tests/native/sdl-background-performance.cpp`，包含同版本 `Scene.cpp` 并链接桌面构建的 `th12_sdl_host`、`th12_runtime` 及依赖；传入同一资源目录。七关各执行 600 个逻辑帧，在六个时间点及额外相机偏移处比较裁剪后的顶点、颜色、雾和排序哈希；随后各重复捕获 240 次，合计 1680 次。测试读取捕获结果，不创建图形上下文。

## 运行时验证

`tests.log`：38 项回归通过。补充的 `sampler-tests.log` 覆盖年龄快进后中断、停止后 UV 逐帧归一化及基于显示随机数计数的轨道回收检查。

`normal-browser.json`：正式 WASM 的单人流程、THPrac、全屏切换、保存原版录像、暂停、定位和继续回放通过。`multiplayer-browser.json`：双人及三人、延迟模式、回滚模式和自动延迟通过；25ms RTC 输入延迟下实际执行回滚，暂停后的权威状态及录像重建一致，双人用例包含观战定位。两侧源码门禁与 Web／Windows 构建通过。浏览器音乐设为静音，Windows 记录编译结果。

源码导出和目录投影的核对记录与功能提交一同登记。
