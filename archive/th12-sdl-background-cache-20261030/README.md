# TH12 SDL 背景图元复用

同一 STD 图元的多个实例共用一次旋转计算。四个局部角点在每次场景捕获时生成，实例继续按原顺序执行位置变换、近远面裁剪、透视投影和雾计算。普通版与多人版使用相同实现。

| 七关合计 1680 次背景捕获 | 基线 | 图元复用 |
| --- | ---: | ---: |
| CPU 耗时中位数 | 19.321 ms | 15.173 ms |
| 稳定阶段临时分配 | 0 | 0 |

基线为 `50084901cd28ab2342d295874afcef8abb6cd82e`。同一 Windows 主机以 MSVC 19.51、`/MD /O2 /fp:strict /std:c++20` 构建，七轮交替运行；[完整测量](performance.json)保留各轮结果。该测量针对背景捕获组件。

缓存按每次捕获更新，支持同帧回滚恢复、VM 自定义更新和资源替换。七关原版背景的时间序列、近远面边界、三轴旋转、缩放、透明度、贴图尺寸替换和 VM 移除逐顶点输出一致，合并哈希为 `260ce8c066cecfaa`。跨关卡更换几何时按新图元数量复用存储。

原生验证入口为两侧 `tests/native/sdl-background-performance.cpp`，传入原版资源目录即可执行。它同时输出顶点哈希、CPU 耗时和分配次数。

[验证记录](verification.json)包含 63 项 SDL 检查、单人 10/10 与多人 9/9 适配检查、两侧 Windows／Web 构建和标准子树导出。浏览器回归覆盖触控、THPrac、全屏、单人录像、双人／三人真实 RTC 回滚及确认录像重建；双人同时核对三次观战定位和返回房间。

输入释放检查先核对每端角色实际移动及发送端持键，再核对 pagehide 后释放。暂停时的权威状态哈希与录像重建比较保持一致，避免将各端不同预测帧的瞬时按键字段当成同帧状态比较。该取样问题在基线构建中同样复现。

开发基线已对齐 `c7a2be6b1`，保留主线触控连续性与即时音效实现。性能比较基线及测量口径保持上述记录；新基线的两侧源码树、构建身份、音效输出及回滚浏览器验证见验证记录。
