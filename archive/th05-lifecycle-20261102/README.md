# TH05 幽灵过面状态一致性

新关卡初始化寻敌存在标记和目标坐标，使第一帧自机弹在敌人扫描前读取确定状态。此时序覆盖携带幽灵和满火力进入第五面的多人流程。

[修复前复现](before.txt)在两端使用不同的新关卡内存填充值，保留同一组跨面资源和输入：有玩家以幽灵状态进入五面后，已确认状态校验发生分歧。修正版通过[20 组幽灵过面验收](ghost-matrix.json)，覆盖两人、三人、四组角色组合、每个幽灵席位及延迟重排输入，并逐一比较第 120、240、360 帧的房间校验值。

[完整边界验收](boundaries.json)覆盖真实击破梦月／雪剩余 Boss 后的结算进五面、幽灵跨面、最后残机耗尽、全员死亡和重开。幽灵过面后的残机与幽灵标记均保留。[观战验收](spectator.json)验证当前关卡重建与回滚流仍保持一致。

发布范围为 TH05 多人的 `th05.wasm`。寻敌状态初始化在首次敌人扫描前执行，游戏输入、残机规则和弹幕流程保持现有实现。

[主站入口验收](public.json)覆盖简体中文两人回滚、观战与返回房间后二次开局。[发布记录](published.json)和[构建输入](build-input.json)记录当前主站运行组件。
