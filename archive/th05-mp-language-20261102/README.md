# TH05 多人语言保持

启动器把游戏语言写入准备完成的配置，房间预览、同步开局与返回房间沿用同一语言。中文包只在准备阶段装载，后续配置通过语言字段保持中文资源、字体和菜单选择；语言包获取失败时明确使用本次日文回退。

[旧版复现](before.json)读取实际 test 站双人房间的原生状态：预览为中文编码 936，开局变成日文编码 932，练习菜单由“无敌”变成“無敵”。[检查](checks.json)覆盖 95 项资源准备／运行流程、17 项设置失效处理、前端与工具类型检查，以及生产前端构建。

[发布身份](publication.json)登记 test 站前端更新，游戏运行组件 generation 与导入包保持现有身份。

[公网房间验收](rooms.json)覆盖双人中文直连、三人日文中继，均开启回滚并运行至少 600 帧。中文双人房继续通过原生暂停菜单返回房间，在同一个运行组件中再次开局至少 180 帧，四个阶段均保持中文编码 936；日文三个席位均保持编码 932。[暂停菜单截图](chinese-pause.png)核对“继续游戏／重新开始／返回房间”的简体显示。[公开文件校验](public-assets.json)核对 144 个文件的字节、散列与 WASM MIME。
