## 改动范围

`GameplayHostPlatform::call` 去掉三次 `memory.reconcile()`，纯绘制走 `pixel_drawing`。`CrtSse2Trig` 删除大参数／指数检查，`GameAtan2` 删除归约指数检查；`WebHost` 参数访问由 `.at()` 改为直接下标；高刷关闭时跳过 `draw_identity()`。`GameStartEntryMemory` 与 `IndexedGameMemory` 删除 `range()` 和读写处的整体覆盖校验，改用页／span 索引。

保存菜单扫描空录像槽时会用空文件名指针调用 `create_file`。`WebHost::create_file` 对空路径直接返回无效句柄，保持旧 `range()` 抛出故障后被原有 `try/catch` 捕获的行为。
