# TH19 统一生命与固定对局规则

TH19 默认双方各 5 条命，生命设置可统一选择 1–5，双方使用同一初始生命数。时间限制固定关闭，屏障固定通过手动蓄力恢复。Launcher 和独立游戏的对局设置都移除时间、屏障及独立 P2 生命选项。

原生对局默认规则索引为 [0,1,1,4,4,1,1]，联机传输保留九个索引以记录能力卡选择。Relay、Runtime JavaScript 和原生入口分别拒绝不同生命数、非零计时和非手动屏障参数；旧版保存的无效规则不会恢复为新房间设置。

[原生报告](native-report.json)验证默认双方 5 命，四档难度对局使用相同的双方生命，计时上限为 0，手动屏障模式为 1；违规规则均返回拒绝。X 蓄力、C Bomb 与回滚重放同时通过。

[完整启动器双人报告](launcher-room-report.json)：两端默认生命选项均为 5，时间、屏障和 P2 独立生命控件均不存在。房主统一改为 4 后，两端原生初始生命均为 4；计时上限为 0，屏障恢复索引为 1。RTC 120、240、360 帧哈希一致，浏览器 errors 为空。

[源码检查](source-checks.json)：普通版 10/10、多人版 9/9。5 项专属配置单元测试、Relay 默认值和拒绝无效规则验证、UI 与工具类型检查均通过。
