# TH05 多人雷保护与弹幕图层验收

成功放雷为全部存活玩家提供施放角色的原生无敌时长，保留更长的复活无敌，只扣除施放者的 Bomb。空雷、挑战模式和正在运行的 Bomb 沿用原有准入；幽灵和离线席位保持各自状态。

自机和幽灵身体位于敌弹、激光和弹幕效果之下，本机身体在队友身体之后绘制，本地判定点继续显示在弹幕上方。

- [规则与图层](native.json)：两人／三人、四角色、每个施放席位共 20 组规则检查，覆盖保护时长、到期碰撞、长无敌保留、库存、空雷、挑战和幽灵；36 组实际敌弹与本机／队友身体重叠画面逐像素一致，并确认交换遮挡顺序会改变结果。
- [回滚](rollback.json)：40 组全世界内存与音频 oracle 通过，含迟到的远端放雷输入和 1–7 次回调乱序抵达。
- [目录历史](history.json)：保留普通版祖先，改动归属多人版目录。
- [发布输入](build-input.json)：TH05 多人运行组件只替换 `th05.wasm`。发布基于当前主站的 TH12 符卡历史版本，保留其线上内容。
- [发布校验](assembled.json)和[主站切换](published.json)：`th05-team-bomb-20261102` 保留 8,199 个原有文件，更新多人运行组件 generation。
- [正式站验收](public.json)：中文两人回滚、迟入观战、暂停／返回直播及退出观战后玩家继续运行通过。
- [公网文件](public-assets.json)：主站和国内镜像的多人 WASM 下载哈希与发布输入一致，海外与国内镜像均已切换到该版本。

源码提交 `1f2d4de6f08689f6fd39e63d993c2e1bc134d7d1`。浏览器验证使用原生游戏类、实际 DAT、真实敌弹绘制和 WebGL 输出。
