# 海惠堂网页单机显示验收

本版本保留 640×480 逻辑画布和 60 Hz 游戏逻辑。全屏时按 4:3 放大到浏览器区域，并按设备像素对齐；系统桌面保持现有分辨率。贴图采用原双线性过滤，修正了默认图像解码造成的透明度重复相乘；菜单按本机原游戏实测使用微软雅黑及原粗细、描边字距，其他系统使用字体后备，Unifont 保留完整字形。

已对照原游戏九种机体的 27 张同帧画面。敌弹区域的平均 RGB 差从 13.15 降到 0.65，自机从 4.56 降到 2.81，判定点从 2.21 降到 0.14。游标、随机数、逻辑计时和选定对象摘要保持一致，WASM 和 DATA 的字节保持原值。

实际使用 Windows、Edge 158.0.4370.33、RTX 4060 Ti / ANGLE D3D11；副屏原生 DPI 为 1.5。通过 18 个 GPU RGBA 样本、7 组 DPI 与横竖屏、真实全屏、约 180 FPS 高刷新呈现、60 Hz 逻辑、视频与声音、暂停、关卡与机体、改键、手柄、触控、资源释放及断网重载检查。
