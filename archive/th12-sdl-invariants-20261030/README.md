# th12 SDL 输入与音乐错误验证

PR #163 的普通版与 MP 在页面隐藏时释放键盘、触点和瞬时输入，返回后可重新操作。音乐解码失败通过共用 `audio-resource` 错误事件报告，同一曲目的一次失败报告一次，安装替换资源后在原实例恢复播放。

| 检查 | 结果 |
| --- | --- |
| 普通版与 MP SDL 测试 | 27 项与 43 项通过，包含损坏音频、替换重试与暂停保持 |
| 普通版 OGG | 流式与完整解码均报告损坏文件，替换后实际 PCM 峰值分别为 0.8115 与 0.8237 |
| 页面隐藏与返回 | 实际游戏接收合成的 pagehide/pageshow，清除键盘与触点，旧触点移动无效，新按键可操作 |
| MP 音乐恢复 | 两名玩家与预加载观众分别收到错误，替换后实际 PCM 峰值为 0.8237 |
| MP 生命周期 | 本地页面隐藏后，各端继续演算，持有的移动已释放，各端不产生独立暂停 |
| MP 回归 | 双人锁步、回滚两场景通过，后者实际发生 20／25 次回滚，包含旁观三次往返、暂停、定位与 Replay 状态重建 |
| 共有源码与模块检查 | 19 个构建目标通过 |
| 来源与同步历史 | 13 个来源祖先及三处标准子树导出通过，th12 普通版已合入 MP，待同步提交为 0 |

[机器记录](verification.json)保存运行时、驱动、素材身份与声音样本。操作使用真实游戏资源和正式 Web Runtime，浏览器验证程序及 Wasm 的实际交付字节。

对应 RUNTIME-04、INPUT-06、TOUCH-16 和 AUDIO-05。新增 AUDIO-07 与扩展后的 TOUCH-09 已登记到共有契约及各作适配表，逐作验收状态为待核对。

运行入口为各作 `test:sdl`、普通版 `scripts/check-sdl-browser.mjs` 和 MP `scripts/check-sdl-multiplayer-browser.mjs`。普通版分别设置 `TH12_TEST_OGG_DECODE_MODE=stream`、`full`，音乐使用 `TH12_TEST_MUSIC=ogg`。MP 本轮选择双人锁步和回滚场景，输入延迟 25 毫秒。素材与字体通过 `TH12_ASSETS`、`TH12_FONTS` 提供。
