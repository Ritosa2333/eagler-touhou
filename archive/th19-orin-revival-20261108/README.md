# 阿燐死灵妖精复活

原版 `th19.exe` SHA-256：`8918fb39d511c9906ef769c6dd2761e7cb44ded5b7c4c1cd99c8992d12c078e9`。

`pl07.ecl` 的 `BossGirlFunc` 用 ECL550 注册 `BossGirlDead`。EXE 0x502d92 写入死亡回调名；0x50c4ca 在死亡奖励与特效之后执行回调，清除一次性回调名，并用 0x08000000 决定是否保留实体。网页端在伤害遍历结束处执行回调，避免脚本生成对象导致遍历引用失效。

`BossGirlDead` 将 HP 设为100，使用角色动画45进入死亡状态，等待30帧后检测 -9942。该变量由 EXE 0x4fdc22 读取 Boss 槽0的第二个宿主整数。Boss 在原版符卡脚本中设置该信号；妖精随后进入 BossGirlFunc，使用动画38，等待60帧，切换方向动画46并恢复受击/接触判定。等待与运动均由原版 ECL 执行。死亡闪光来自 ECL323(0,262)，file0 对应 bullet.anm。

验证范围：四个难度使用原始 pl07.ecl，每只妖精连续死亡与复活两次，检查同一对象ID、HP、动画、Boss信号等待及回调重新注册。浏览器使用原始 BossAttack 初始化阿燐符卡，对10只妖精通过正常伤害函数逐帧施加伤害；截图显示死亡、复活特效、恢复行动。检查点重复推进300帧哈希相同。浏览器没有页面异常；原有未实现指令计数为2，此测试不等于完整符卡所有指令的原版一致性验证。
