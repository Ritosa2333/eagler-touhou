# TH15 多人：共享碎片与 Boss 入场输入

共享残机碎片逐人使用原版 `ItemCollection` 规则：未满残的玩家积累自己的残机碎片，满残玩家获得炸弹碎片，残机和炸弹同时满额时遵守原版上限。一次共享事件对每名玩家执行一次，Extra 的 Extend 档位和幽灵储备分别保存在各自状态中。

连续 Focus 的给残进度使用字母字体显示 `L 3/5`、`L 4/5`。数字图集继续承担纯数字提示。原作 ASCII 素材验证逐字核对实际精灵，确保给残提示绘制正常大小的字形。

Boss 音乐、对话和场景工厂需要已确认输入。预测尝试触及边界时暂停该帧，确认后重试；成功推进同一帧随即清除等待标记，输入采样回到战斗时钟。菜单／对话期间已经采样的输入按原序排空，再采集新的战斗输入。

确定性规则版本为 23。验证覆盖真实素材下的双人／三人满残混合奖励、Ghost 储备、原作字形、边界解除后的采样队列，以及现有回滚状态恢复与重演检查。改动进入 TH15 多人实验分支。

原生回归 15/15 通过，并单独核对混合 Extra 档位。浏览器对照复用同一组生产对象，在修复前后两份帧循环中触发相同的 Boss 音乐边界请求。双人和三人均验证边界仅执行一次；在相同 60 ms 接收延时及 650 ms 接收暂停下，旧循环在确认边界后继续保留标记，采样超前达到 8 帧；新循环清除标记，超前保持为 1 帧的当前采样槽。两侧随后恢复正常输入交付并继续推进。

已登记的规则 20 录像继续使用其录制时的换面、兔机盾与共享碎片计数规则；当前对局使用规则 23。
