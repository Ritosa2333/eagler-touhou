# TH08 Extra 雷保护与 Last Spell 生命周期

多人敌机的原生雷保护标志按全队有效席位查询。Extra 关底任意队员的 Bomb 仍在持续时，保护同时阻断全部队员的射击与雷伤害；查询直接读取 Bomb 生命周期，不依赖本帧是否存在命中区域。未启用该保护的敌机沿用当前伤害规则。

死亡窗口跨入 Last Spell 时，尚未结算的死亡转入原生自动解除。普通与挑战规则都允许这条自动解除完成；启动时释放此前死亡窗口留下的共享暂停和视觉状态，保持残机与 Bomb 库存。已经结算的死亡及幽灵不被重新算作本次被弹。

原生 ECL 回调 22 的“复活”公告通过 `th08 Spell Resurrection` 查询语言包；普通版与多人版同步接入。无翻译时保持原始 CP932 日文，公告标志与效果沿原回调推进。

## 验证

基线为 `c37d3cb76`。WASI 检查编译实际敌机、PlayerLife 和 PlayerBomb 实现，覆盖双人／三人各席位的雷保护、全部 12 个机体的正常被弹与死亡窗口重叠，以及普通／挑战规则。旧版在新增重叠用例中继续普通死亡流程，修复版本进入自动解除；原有生命和合作规则检查一并执行。

`portable/multiplayer/check-last-spell-lifecycle.py` 使用原始 ECL 和实际原生拥有者，覆盖蓬莱之药、永夜返、普通／挑战、正常流程规则／Spell Practice 规则、全部席位，以及 P1 已死亡、幽灵与尚在死亡窗口的条件。检查手动雷禁用、被弹触发自动解除、库存保持与暂停位清除。诊断初始条件与运行后的关卡推进分别记录，网络传输由独立用例验证。

结构化结果、产物身份和正式包诊断导出检查见 [verification.json](verification.json)。所有诊断入口只进入 fixture 构建。
