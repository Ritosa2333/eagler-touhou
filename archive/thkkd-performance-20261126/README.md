# 海惠堂 Web 性能与完整录像验收

本版本在独立 Web 后台优化地址索引、别名存储及 GPU 顶点缓冲。Windows 基线为 `64d48dc366f2d57210dbdac25be82e0e71b2641d`，网页起点为 `a1da2e1e23a5d853d0ed06e195b9b91d6eb6656a`，主要实现提交为 `5030dc51dc1c0cb12b7c4196482b2284a005d8b8`。570 个核心文件和 13 个生成显示文件保持原字节，沿用原 24 位有效数、随机顺序、碰撞、伤害及回放规则。

CPU 调用栈定位到 HUD 的反复地址扫描、临时上下文映射封存和别名核对；呈现侧反复创建顶点、颜色数组和批次字符串。Web 后台改用区间索引、最多 32 份完整布局缓存和连续别名段，保留注册顺序、复制边界、冲突处理及随机数同步。渲染器复用按需扩容的 Float32 缓冲，按原贴图、混合和裁剪边界提交。固定 Emscripten 6.0.9，编译继续使用 `-O2 -fno-fast-math -ffp-contract=off`。

## 同场景性能

实际环境为 Windows 11、Intel Core Ultra 7 155H、32 GB 内存、Edge 158.0.4370.33、RTX 4060 Ti / ANGLE D3D11，浏览器视口为 1280×900，游戏缓冲为 640×480。默认限制 60 Hz 呈现，每种条件测量 900 个逻辑步；实战游标为 120→1020，密集 EX 为 50120→51020。CPU 4 倍限速由 DevTools 施加，iframe 内整数工作量测得倍率 4.24。正式测量时无并行构建、回归或调用栈采样。

FPS 为每秒实际 WebGL 呈现次数，逻辑 Hz 为每秒实际完成的固定逻辑步数。旧版数据复用[显示交付的同场景记录](../thkkd-rendering-20261126/performance.json)，新版详见 [performance-after.json](performance-after.json)。

## 兼容与实际浏览器检查

原映射与 Web 映射完成 30082 次逐操作差分，覆盖别名冲突、注册优先级、随机数游标、边界错误、重复及中途失败的封存，并检查 80 份布局实例及缓存淘汰。原有全部 17 份录像、42 组 Omniverse 和 EX 返回共 60 个用例、835289 个逻辑步重新通过，状态流字节数和 SHA-256 与既有不可变结果一致，见 [numeric-regression.json](numeric-regression.json)。

正式启动器的原生录像接口完整执行全部 17 份录像。优化前后 648824 个输入、643 个检查点及全部结束状态一致，比较游戏状态、随机数、计时、自机、敌人、敌弹和武器字段；平台资源句柄排除在状态摘要外。每份输入及检查点身份见 [replay-comparison.json](replay-comparison.json)。原始授权录像保存在本机验证目录。

九种机体的 27 张同帧画面逐像素一致。1800 条绘图命令在七个插值参数下的 GPU 调用与 Float32 顶点流一致，覆盖缓冲扩容、逐顶点颜色、透视、裁剪、混合及身份边界。18 个贴图 RGBA 样本、七组 DPI/横竖屏尺寸、全屏、120 次只读额外呈现及离线重载通过。副屏 180 Hz 实测标题、难度、游戏和暂停均约 180 FPS，逻辑约 60 Hz。

正式界面中的默认按键、WASD、自定义改键、虚拟标准手柄映射与断开、DevTools 触控移动及取消、布局、横竖屏、放大、失焦释放、独立音量和全屏通过。从 r5 更新到本版后，原生存档配置与 Replay 保留；关闭 HTTP 服务并设为离线后刷新、启动通过。相关记录见 [browser-checks.json](browser-checks.json) 和 [high-refresh.json](high-refresh.json)。单机扩展模块的 18 项局部检查通过，源码契约为 10/10。
