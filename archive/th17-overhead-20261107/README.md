# TH17 动画查找与符卡记录复用 · 2026-11-07

动画对象通过有序页地址索引和最近访问页缓存查找。普通版和多人版共同使用该路径。多人快照按原注册顺序保存动画节点，恢复时直接重建两个调度组。帧调度快照按实际回调数量一次分配。

符卡历史在统计更新时生成只读副本，相邻快照共用当前版本。开始符卡、结算符卡和读入存档时更新缓存，回滚恢复所有机体与汇总记录。独立 Wasm 测试在 24,000 次快照中每 600 帧更新一次统计，同时测试单帧与 12 帧保留窗口。该部分累计申请内存从约 159 MB 降至 1.55 MB，分配次数从约 504,000 次降至 24,850 次。

正式多人运行包通过启动器预览连接本地 Relay，在 Intel 核显上以 1280×960 运行三个独立页面。下表使用 145 ms 注入延迟和 4 倍 CPU 限速，帧率按实际画面提交计算。

| 场景 | 基线三席 FPS | 更新后三席 FPS |
| --- | ---: | ---: |
| 一面 Boss 非符 | 48.19 / 48.95 / 48.74 | 54.58 / 55.44 / 55.00 |
| 一面 Boss 符卡 | 55.23 / 54.53 / 55.36 | 58.26 / 57.17 / 58.32 |
| 一面至二面全程 | 54.96 / 55.13 / 55.23 | 55.46 / 55.50 / 55.58 |

更新后 9,019 个确认帧在三端一致，包含 1,420 帧 Boss 非符、998 帧符卡和 242 帧二面。每次抓取快照的平均耗时为 2.474 / 2.507 / 2.481 ms，基线为 2.502 / 2.528 / 2.491 ms。更新后三席的最大呈现间隔为 1038.02 / 1057.53 / 1012.89 ms，覆盖同步换面。

110 ms 注入延迟、2 倍 CPU 限速的开场验证中，双人平均呈现 57.65 / 57.97 FPS，三人平均呈现 59.62 / 59.67 / 59.73 FPS。两种房间均有超过 1,050 个确认帧一致，并验证指定队友收取赠送残机。

原生回归覆盖多页查找、双队列前插与后插顺序、动画复用、跨机体符卡记录、重叠快照和分支恢复。普通版浏览器回归覆盖启动、音频、存档重载和原版录像。多人构建的 233 个源码和 302 个头文件与当前输入逐项匹配，普通版与多人版目录历史通过真实合并接收。
