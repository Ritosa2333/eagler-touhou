## 复验入口

从仓库根目录运行两侧构建和 `test:sdl`。真实素材的本地路径通过 `TH12_ASSETS`、`TH12_FONTS` 提供，普通版使用 `TH12_TEST_MUSIC=ogg` 和 `TH12_TEST_OGG_DECODE_MODE=stream`／`full` 分别运行浏览器检查。

共用驱动使用私有输入清单，选择 `--game=th12`。普通版执行 `ports:runtime -- --game=th12 --gamepad`；多人普通局执行 `ports:mp -- --game=th12 --challenge=normal --frames=600 --lifecycle --restart=both --recover --wait-end`；三人挑战执行 `--challenge=challenge --players=3 --route=relay --frames=600 --recover --stop-stream`。清单格式、报告目录参数与网络开关见[验证指南](../../docs/adaptation/validation.md)。
