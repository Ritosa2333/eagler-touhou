# TH19 专属输入与对局设置验收

TH19 使用独立键盘与手柄存储，默认 X 蓄力、C Bomb。原生按键表、Launcher 按键表、联机语义和触控 Bomb 保持一致。其他作品继续读取原有配置，TH19 普通版与多人版共享该作品输入方案。

房间提供时间限制、取胜局数、能力卡模式、双方初始生命和双方屏障恢复规则；指定能力卡时分别记录双方卡片选择。Relay 校验作品范围与索引，修改规则后取消双方准备。九个参数参与 Runtime 配置和双端版本握手。双方卡片库存、附加射击与被动效果分别生效，并进入回滚状态。

- [原生验证](native-report.json)：四档难度分别映射到原生选择、双方 ECL 与 CPU 的 0–3。验证时间、取胜局数、双方生命和屏障，四种能力卡模式，双方蓄力卡效果及回滚重放。实际键盘 X 进入蓄力、C 将 Bomb 从 3 扣到 2。
- [完整启动器双人验证](launcher-room-report.json)：两端通过 UI 同步九个参数，在 Lunatic 启动 RTC 对局，120/240/360 帧哈希一致，浏览器 errors 为空。
- [单机验证](launcher-gameplay-report.json)：启动器下载安装 DAT/OGG，剧情选难度、选角、对话、进入战斗、移动和暂停通过。
- [源码检查](source-checks.json)：普通版 10/10、多人版 9/9。

验证环境为 Windows Edge 软件图形、同机两个浏览器上下文和本地 Relay。长流程全角色通关与物理手柄实机体验不属于本次验收范围。

- [重复音效验证](sfx-report.json)：四次原生菜单操作均产生非零 PCM，播放游标均从 0 开始。

旧版全作品静态协议测试会遍历尚未登记本地源码路径的 opt-in TH13，报 unknown workspace repository: th13。该测试和 TH13 工作区登记不在本次改动中；TH19 两种模式各自的 Runtime 协议检查均通过。
