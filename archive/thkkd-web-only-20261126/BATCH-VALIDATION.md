# 東方海恵堂批量导入与运行验证

本构建支持一次选择原版 `dat.dxa`、`bgm.dxa`，或导入包含两者的 ZIP。原版资源由使用者在本机导入；首次导入后，刷新及断网运行均通过检查。

存档支持同时选择五份原版 DAT 与 `config.txt`，也可选择存档 ZIP。整批检查文件名和目标冲突后统一确认覆盖，写入后重启并逐份校验。录像支持多选 `.rpy`、`.thkkdr` 与录像 ZIP，同名文件自动分配空闲名称；从工作台导入、播放、导出、重命名、删除及刷新保留均通过实际浏览器检查。

17 份原版录像连续播放至最后输入，共执行 648807 个逻辑步；标准速度暂停续播与扩展坐标录像两个补充用例通过，合计 649645 个逻辑步。逐步检查游标连续递增，最后一帧显示播放结束并停止推进。普通与高帧率下的暂停、进度定位也通过。

游戏检查覆盖九种机体组合的射击与 Bomb、六面与 EX、Omniverse 资源显示、暂停重开、原生录像保存、Z 键及触控对话、音乐和音效音量、退出释放与再次启动。额外绘制 100 次后，完整 WASM 内存、随机状态、文件与音频状态保持一致。网页清理后的 WASM 与此前构建相同；本次批量导入修改位于启动器。

文件服务与录像格式测试共 34 项通过，三语 2646 条提示核对通过。桌面游戏后台、DxLib 和旧桌面构建入口已移除，网页需要的共享显示表保留。

画布侧边白线来自浏览器在键盘操作时绘制的默认焦点轮廓。游戏画布设置 `outline:0`，保留键盘焦点与输入；1280×900、1003×751、900×1280、1813×1271 四种窗口尺寸及 100%、125%、150% 像素缩放下，画布外侧取样均无白线，实际选人输入正常。此修正只调整画布样式，WASM 文件保持相同。
