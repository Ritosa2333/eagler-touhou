# 東方海恵堂网页工程整理

资源导入接受同时选择的原版 `dat.dxa`、`bgm.dxa`，或包含两份文件的 ZIP。文件选择器支持多选，手动导入和首次启动提示与实际格式一致。真实浏览器双文件导入、301 项运行资源加载、进入游戏、刷新与断网复用均通过。

网页工程移除 38 个旧文件，包括桌面后台、DxLib 库、CMake 配置、桌面构建打包入口、桌面使用说明和重复的阶段说明。网页仍需使用的 79 字节显示索引表迁入网页后台。核心与显示计算保持原内容；清理后重新编译的 WASM 哈希与清理前一致。

项目登记补齐显示、文字模块和四份第三方许可文件。站点直接使用已有 WOFF2 字体，移除无用的 OTF/TTC 转换步骤及对应 Python 依赖；README、架构、开发和打包说明统一描述当前网页流程。

启动器导入检查 55 项、资源解析检查 8 项、源码包检查 2 项和项目接口检查 10 项通过，三语提示与文档索引检查通过。原始游戏资源、用户数据和本机测试录像继续保留在忽略目录。
