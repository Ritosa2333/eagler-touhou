# TH05 主站接入

主站 https://touhouonline.com/ 接入 TH05 原生单人和独立多人，沿用 test 站验收的运行组件与游戏包。多人包含八帧回滚、三席颜色、数字火力、初始残机/Bomb，以及中文在预览、开局、返回房间和重开时的保持。

[发布身份](publication.json)以当天 TH12 PR168 主站发布为基线，保留其他十部作品的运行组件、包声明和配置。[产品策略比对](registry-preservation.json)逐项确认已有作品策略一致。[前端来源](source-deltas.json)和[补丁](frontend-source.patch)记录在主站前端源码基线上增补 TH05 的范围，并保留已发布的桌面房间自动全屏。发布变更九个前端文件、TH05 资源和必要的站点清单；7,712 个既有文件逐字节保留。

[单人验收](singleplayer.json)使用主站启动器选择中文、thprac 和无音乐，进入实际关卡；原生文本编码为 936、练习开启、逻辑帧长为 1/56 秒，启动器提供幺乐团专辑选项。[画面](singleplayer.png)记录原生关卡。

[房间验收](rooms.json)使用公网启动器与原生游戏：中文双人直连和日文三人中继均开启回滚，连续运行至少 600 帧；双人通过原生暂停菜单返回房间后再次运行至少 180 帧，三个阶段保持中文。三人同步初始剩余残机 5、Bomb 0，三个原生席位的初始生命/Bomb 均为 6/0。[中文暂停菜单](chinese-pause.png)核对简体显示。

[联机服务补丁](relay-patch.json)在现有主站服务中增加 TH05 产品、初始库存和认证来源标记，并单独允许 TH05 的中继回退；其他作品延续主站策略。[本地服务检查](relay-local.json)确认 TH05 库存修改清除准备状态，其他作品拒绝 TH05 专属字段且保持准备状态。[资源规则](nginx-th05.json)只增加 `/games/th05/` 的本地文件读取；[统计登记](telemetry-published.json)只增补 TH05 产品。

[检查汇总](checks.json)包含 112 项准备／运行流程、主站前端类型检查与生产构建、产品登记、旧版入口和转发流控。[公网文件](public-assets.json)校验 204 个文件的字节、SHA-256 与 WASM MIME，覆盖约 189 MB。资源发现服务尚无 TH05 媒体节点时返回 503，启动器使用同源资源；房间验收单独保留这些可恢复的发现请求，全部实际游戏资源验证成功。
