# TH19 旁观、录像与容量验证

本次验证覆盖兽王园共享 C++ 源码及 normal / multiplayer Runtime，使用 Windows Edge 与软件 WebGL2、本地 Relay。对应实现见[旁观与扩展录像](../../ports/th19/docs/REPLAY.md)。

| 验证 | 结果 |
| --- | --- |
| 原生发弹饱和与回收 | 4096 发尝试保留 2000 发；重复饱和不增长；死弹回收后可再次发射 |
| 原生敌机注销 | 累计 15000 个失效敌机回收，并通过 checkpoint 恢复 |
| 输入 RLE | 120 tick 压成一条，再加载后逐帧还原；非法 direct 标志被拒绝 |
| 未开打的录像 | 菜单、选人、剧情和对局初始化不保存；正式战斗后生成 `.rpy`，支持导出再导入 |
| 普通录像 | 从实际菜单到战斗记录 1415 帧；播放终态与连续两次回退重播状态一致 |
| 原生 Quit | 选择标题菜单 Quit 后发送启动器 exit，退出标志为 1 |
| RTC / Relay 旁观 | 晚加入历史与后续实时帧均可接收；观众上行被关闭，玩家保持连接 |
| 三端启动器 | 两个玩家从房间启动 RTC 对战，第三端晚加入，连接就绪与暂停／返回实时正常 |
| 观众浏览器 | 追上 180 帧历史，实时接收到 360 帧，保存并回放录像，回退重播状态一致 |
| 浏览器容量压力 | 双方各 2000 发，12060 tick，8 个滚动 checkpoint；预热后 WASM heap 保持 902496256 字节 |

执行脚本与断言保留在 `ports/th19/tests` 和 `services/relay/tests`。完整 JSON 随本地交付提供；此记录说明本次验证的构建和范围，不替代物理移动设备、TURN 网络及全角色通关验收。
