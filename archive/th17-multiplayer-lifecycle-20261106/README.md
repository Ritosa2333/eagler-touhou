# TH17 多人标题、录像与旁观 · 2026-11-06

原生房间标题持续播放动画并开放 Options，对局结束经过确认帧退役后进入各端的本地结果菜单，退出沿用同一运行实例返回房间。多人 Replay 在确认时提交全席位输入，按独立存档目录保存并接入启动器录像管理器。

旁观采用共用的分关历史与时间轴，关头包含三席资源、位置、共享动物灵、构造前后 RNG 和输入边沿。房主发布关头、确认输入与 Boss 节点，旁观接收和快进均使用有界预算。Boss 平衡沿用 TH15，双人承受原伤害的 3/4、三人承受 2/3，临时死亡保留人数，残机耗尽后重新计算倍率，除法余量随敌机回滚。

[构建与静态接口记录](build-contracts.json)覆盖普通版 THPrac 与多人版正式编译、两种运行包的 14 个文件、多人录像和旁观接口导出。记录范围为构建、打包与静态接口。
