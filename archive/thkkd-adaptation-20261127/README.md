## 功能与修复

详情页直接读取原生本地存档，展示九种机体和五种难度。输入补齐拖动与双击 Bomb 的区分、触点取消、原生复活后的同触点继续移动；真实触控保存流程保留扩展坐标和处理落率。

录像显示使用独立的显示时钟，在相邻逻辑步之间平滑位置。显示对象标识覆盖自机、敌机、弹幕、效果、自机子弹、武器、附属物和道具，辅助绘图调用沿显示栈取得所属对象。贴图、透明状态与裁剪切换使用当前快照。额外绘制保持完整 WASM 内存不变。

音乐加载错误保持可见，成功播放后恢复正常状态；缺失音乐时继续处理游戏与音效。Windows PowerShell 5.1 通过 UTF-8 BOM 读取构建脚本。

### Omniverse 收取结算

成功收取后的第 511 个结算帧先把关卡场景设为主菜单，再调用原生返回流程。普通游玩进入保存录像询问时，最终场景改为录像菜单；宿主先同步前一次写入，再处理下一次切换。修复前自动用例复现 `Game start callback aliases disagree`，修复后三角色、八挑战、普通游玩／录像返回共 48 个组合通过。符卡、得分、随机数及保存询问沿用原逻辑。

## 验证结果

[结构化结果](validation.json)汇总浏览器功能、编译选项、字体、固定原版采样与 Omniverse 结算结果。运行原始输出保存在本作被忽略的 `build/adaptation-20261127` 中。

固定原版采样覆盖 60 个用例、835289 个逻辑步、23163 个采样帧和 1637293 个状态区域。校验器逐项核对原程序、资源、录像及采样哈希，并重建原始状态流。差异注入在第 1 帧的残机字段被准确定位；预期基准保持固定。

软件测试使用 Edge 158 后台进程，独立浏览器数据与站点。实体设备和原版重新采样按清单中的后续范围维护。
