## 缓存峰值

字体缓存达到容量时逐个回收冷字形，复用字形节点和位图存储；命中记录使用一个引用位。缓存上限为 4,096 项，替代整表清空。

[测量与验证](verification.json)使用真实 FreeType 字体，交替执行基线／优化／优化／基线。8,192 次变化的字号缩放与粗体请求之间持续绘制 94 个常用字符。常用字符的额外栅格化由 188 次降到 0，单次突发重建由 94 个降到 0；四轮像素哈希均为 `68e12230b2366483`。该指标验证字体缓存工作集切换时的重建峰值。
