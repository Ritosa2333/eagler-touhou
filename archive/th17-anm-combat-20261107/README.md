# TH17 普通关动画与绘制开销 · 2026-11-07

普通版与多人版共享本轮 ANM 和 WebGL 优化。静态精灵每帧仍推进脚本和计时器，按当前属性进入插值与条带更新。精灵四边形复用各轴坐标和旋转乘积，条带的两条边共用同一角度的正余弦，保留各自的浮点舍入。WebGL 复用相邻绘制的着色器选择，预编译变体使用自身的材质常量。

独立 Wasm 基准每轮对 2,048 个混合 ANM 实例执行 360 帧更新，包含静态精灵、插值、旋转与条带。八组交替采样的中位耗时从 12.06 降至 10.34 ms，下降约 14%，校验和一致。[ANM 更新基准](anm-advance-benchmark.json)

## 双人实战

两席使用独立 Chromium 页面经本地 Relay 开房，普通难度，OGG，1280×960。房测包从指定关卡开局并保护残机。两席用键盘移动和射击，按确认帧核对双方战斗状态。画布 FPS 来自浏览器视频帧计数，推进 FPS 来自提交且进入新逻辑帧的次数。回滚场景每方向注入 60 ms 延迟与最多 15 ms 抖动。锁步与回滚结果分别统计。

| 场景 | 画布 FPS（P1／P2） | 游戏更新 P95（ms） | 一致确认帧 |
| --- | ---: | ---: | ---: |
| [四面锁步基线](room-lockstep-before.json)，CPU 限速六倍 | 59.81／59.81 | 11.89／11.74 | 1,276 |
| [四面锁步优化](room-lockstep-after.json)，CPU 限速六倍 | 59.53／59.53 | 13.88／13.37 | 1,276 |
| [四面回滚基线](room-rollback-before.json)，CPU 限速六倍 | 55.17／54.79 | 13.07／12.29 | 2,352 |
| [四面回滚优化](room-rollback-after.json)，CPU 限速六倍 | 53.47／53.15 | 15.38／14.84 | 2,353 |
| [六面道中至 Boss 符卡](room-stage6.json)，CPU 限速四倍 | 55.61／55.62 | 10.13／10.05 | 7,685 |

四面回滚房两席自机弹峰值为 101／31，击破 114 个杂鱼，场上最多 253 发敌弹与 929 个 ANM 节点。两席推进 51.01／50.67 FPS。六面非符峰值 720 发敌弹，符卡峰值 3,890 个 ANM 节点。六面整段推进 53.42／53.35 FPS，画布相邻呈现间隔超过 25 ms 的次数为 362／378。六面符卡采集 180 个一致确认帧。

六面优化前，带符号的双人房基线游戏循环共采样约 58,000 ms，快照采集占约 19,400 ms，场景绘制占约 16,900 ms，其中绘制提交约 5,900 ms。ANM 脚本更新约 4,900 ms。函数采样权重用于定位热点。[六面 CPU 采样](stage6-profile.json)

## 普通版录像与原版对照

同一份原版录像进入三至六面，每关采样 900 帧。1280×960，CPU 限速四倍，Chromium ANGLE D3D11。三面游戏回调 P95 从 5.57 降至 4.60 ms，四面从 9.26 降至 8.51 ms。五面为 4.07／5.05 ms，六面为 3.47／4.34 ms。四关画布采集约 60 FPS。[前一构建](../th17-story-combat-pressure-20261107/normal-final.json) · [本轮构建](normal-replay.json)

原版对照覆盖 4,096 组普通精灵、4,096 组投影精灵、2,304 组几何图形、1,024 组世界精灵和网格，以及脚本、插值与敌弹动画。五种条带绘制模式另用前一构建的几何算法逐字节核对 4,096 组顶点。四面与六面各取连续 27 帧，1280×960 下战斗区的像素哈希逐帧一致。[原版对照](animation-parity.json) · [WebGL 像素对照](playfield-pixel-parity.json)

## 复测

普通版使用 `ports/th17/web/tests/story-render-browser.mjs`。多人版使用带 `--room-benchmark` 的运行包及 `ports/th17-mp/web/tests/multiplayer/room-browser.mjs`。资源和延迟设置沿用[普通关实战房测](../th17-story-combat-pressure-20261107/README.md#复测)。四面锁步按 `--lockstep --trace-phases` 采样，覆盖至少 240 个有 192 发敌弹的确认帧。六面回滚覆盖至少 180 帧符卡战斗。
