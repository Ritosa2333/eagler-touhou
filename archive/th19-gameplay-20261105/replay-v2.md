# 联机录像与旁观重写验证

新版记录器按对局持有独立的开局配置、确认输入、文件路径和异步写入队列。暂停旁观时继续保存收到的确认帧。结束保存会更新完整或中断标记。断线保留收到的历史，可继续播放。

录像播放器与旁观共用 ConfirmedTimeline 和 VersusReplayRunner。倒带恢复开局规则、角色、难度和种子，从头逐帧重演。每 120 帧核对游戏状态。快进定位会抑制批量音效。

第二版 .rpy 为双方各保存 held、pressed、released 三个 16 位值，依据 EXE 0x430340 的边沿关系逐帧验证。原版 0x550750 的顺序输入读取、0x550dd0 的状态与种子恢复提供了重演生命周期依据。双人文件封装、触屏扩展和网页旁观传输采用移植层实现。原版 EXE 双人录像互读仍未验证，文件使用网页第二版标记。第一版联机与旧版单机文件保留读取路径。单机录制入口保持关闭。

验证包括 16 项记录器与 Relay 测试、L 难度 1200 帧中途旁观与录像重演、正常启动器两名 RTC 玩家加一名观众的完整房间操作。三端测试覆盖创建、加入、就座、准备、开始、旁观暂停和返回实时。长录像含蓄力、Bomb 与触屏位移输入，保存后两次重演均通过状态校验。

源码整理后的构建 ID 为 `d9cdd7c570a6493ff1f7d6659299b2b176e707a86d1d2cb63d6d4db371b4a8c7`。WASM 与 Story 修复版本一致。浏览器报告对应同一逻辑的整理前构建，最终格式整理后重新运行记录器与 Relay 测试。证据文件为 replay-v2-browser.json、replay-v2-launcher.json 与 replay-v2-tests.txt。
