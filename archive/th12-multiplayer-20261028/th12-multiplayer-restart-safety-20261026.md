# TH12 多人重开确认

多人局的整局重开必须经过暂停菜单的“重来 → 是”。暂停菜单和确认框打开后，所有玩家先松开方向、射击、确认和取消键，菜单才接收新的操作；确认框按新的方向键边沿切换选项。多人 R／Retry 在浏览器输入、原生采集、网络解码和游戏菜单四层禁用。

原生新回归在修改前复现了完全不输入 R 的整局重开：玩家持续按下方向键，另一玩家暂停，方向连发跨入菜单和确认框，两次确认便触发重来。修改后，同一输入序列保持在暂停菜单；双人、三人，一面、三面、六面，每个座位均通过。回归还覆盖暂停／确认状态的快照恢复、R 在游戏／暂停／确认框中无效，以及主动选择“重来 → 是”仍能正常结束当前局。

浏览器在读取第一面资源前、原生会话在建立下一局前，分别核对已完成的重开确认。保存录像和加载资源期间只轮询网络。重开来源的关卡、网络帧、会话代数和按住确认键的座位会保留在后续运行信息中，供错误报告追查。菜单规则版本升至 6，旧规则录像使用其原始 Runtime 播放。
