# TH12 飞钵轮廓与展示性能

基于 PR #135 的 `b0df3204896708d554cf029b47df2b5afd867922`，
本轮同时更新 `ports/th12` 与 `ports/th12-mp` 的共用展示实现。

- 飞钵回调同步原版 VM+58 的宽度与半径语义，轮廓跟随弹幕环扩展。
- 相邻逻辑帧的所有者、动画外观、激光拓扑与父子链匹配缓存到展示端点，
  高刷新率画面复用匹配结果。端点改变、回滚或定位后按新端点重新建立匹配。
- 动画遍历追加到可复用缓冲，保留 Primary、Secondary、Embedded 的注册链顺序。
- 子弹绘制顺序与朝向共用一个索引，每个动画节点查询一次。
- 背景每个面的四个角共用六个三角函数结果，保留旋转、裁剪和投影的计算顺序。

飞钵字段修复来自 `Tweet-META/th12` 的 `9504ada`。
普通版与多人版沿同一补丁同步，多人节点的席位作用域保留。
同步基线及来源提交登记在 `docs/adaptation/port-sync.json`。
