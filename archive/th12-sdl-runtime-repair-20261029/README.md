# TH12 SDL 多人启动与故障恢复

SDL 入口向主站提供同一份 `window.Module` 与 `eaglerOptions`。主站沿现有联机状态读取、真实输入通道检查和房间流程揭开启动遮罩，保持实际通道就绪条件。普通版同步保留同一模块诊断入口。

多人连接失败冻结后续网络 tick、输入采样和周期更新，保存第一个错误并向主站提供停止状态。已确认的会话继续供录像保存与返回房间使用，回房后清理停止状态并恢复可见页面的音频，再次开局复用现有原生实例。

Runtime Service Worker 在清单、长度与 SHA-256 校验通过后，根据声明的文件扩展名提供脚本、Wasm、HTML、CSS 与字体类型。缓存与 HTTP 路径共用该规则；旧缓存的二进制响应头可离线恢复，不改变程序字节、代次或存档。

SDL 原版录像解码先检查关卡头的剩余长度，避免无符号减法下溢。录像 FPS 按既有原版读取证据的游标时机显示；普通版和多人目录的共用代码同步更新。
