普通版和多人版接入与 TH11 相同的同步输入通道。触点按下、移动、释放和取消在浏览器输入回调中送达游戏；战斗仍按原有逻辑帧采样和回滚。画布坐标在整段手势中复用，视口、画布尺寸和滚动变化时更新。浏览器回归覆盖会话身份、坐标换算、跨帧复用、取消手势及 Bomb 序号的单次传递。
