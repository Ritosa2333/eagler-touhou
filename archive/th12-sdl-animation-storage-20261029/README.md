# TH12 SDL 动画存储复用

复杂 ANM 特效持续更新时，插值参数和嵌套显示帧共用已有存储。512 个动画根节点各带附着、脱离和多级子动画，连续 600 帧触发位置、颜色、透明度与缩放插值：临时分配从 11,366,400 次降为 0，CPU 组件耗时中位数从 895.688 ms 降为 147.976 ms，减少 83.5%。普通版与多人版使用同一实现。

## 行为一致性

- 33 个本地原作 ANM、1393 个脚本分别检查连续采样、跳帧、倒退重建和中断。使用同一扩展夹具编译前后版本，输出哈希均为 `77d66f194d49c273`。
- 新夹具包含三层子动画、附着与脱离、父级缩放旋转、子节点销毁后替换、1／2／3 字段插值持续重设。显示顺序、稀疏采样与显示随机数保持一致。
- 音乐已存在和异步请求中的两条路径均按曲目缓存；600 次绘制只查询一次文件路径，下载完成后只安装和刷新一次。关闭音乐时不查询文件。左右 Shift 独立持有与键盘／手柄方向合并通过边界检查。

## 测量口径

基线为 `5dedae93683af160e8c8abba935c9eebec23cfbc`。同一 MSVC Release 编译参数、同一扩展夹具，执行五组前后配对，交替运行顺序；每组均为 512 个根节点、600 帧。原始配对值和原作输出身份见 [comparison.json](comparison.json)。

| 动画负载 | 修改前中位数 | 修改后中位数 | 修改后临时分配 |
| --- | ---: | ---: | ---: |
| 嵌套子动画与反复插值 | 895.688 ms | 147.976 ms | 0 |
| 无中断静止根节点 | 20.179 ms | 21.945 ms | 0 |
| 三中断静止根节点 | 26.119 ms | 25.447 ms | 0 |

无中断静止路径的这组差值折合每帧约 0.003 ms。计时覆盖动画 CPU 组件；游戏整体帧率还取决于逻辑、回滚、渲染和设备，组件比例不换算为整体 FPS 倍率。

## 验证入口

`tests/sdl-animation.test.mjs` 编译实际动画实现，检查稳定根节点、三中断和嵌套动画的零分配。`tests/sdl-hot-path.test.mjs` 执行实际浏览器入口并检查音乐及输入边界。普通版与多人目录分别保留相同用例。

单人、多人 Wasm 与 Windows 构建通过；Windows 产物完成编译。6 项原生动画／排序／时钟检查、19 项浏览器边界检查通过。原作素材浏览器用例覆盖单人触控、全屏、THPrac、录像保存与定位，以及双人和三人实际回滚。双人发生 19／20 次恢复，三人发生 20／20／32 次恢复；共享暂停时世界哈希一致，暂停重复绘制复用捕获，录像重建保持相同状态。双人用例同时验证观战。产物身份与结构化结果见 [validation.json](validation.json)。
