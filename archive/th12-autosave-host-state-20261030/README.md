# 星莲船录像保存与逐帧状态读取

基线为 Goan114 改进分支的 `2010c70ffd72be121af88c656ea0f4d6d91aedd6`，保留其子动画存储、插值、音乐缓存和输入采样优化。

## 有界录像保存

多人录像保留一条 15 秒自动保存调度，5 秒文件同步继续服务成绩与配置。按浏览器运行代次、原生会话代次、确认帧和已提交录像帧数判断是否需要编码。慢存储期间的普通请求合并，待写入完成后再生成最新录像；写入或数据库同步失败不更新保存水位。退出、后台同步和重开强制捕获原生记录清理前的完整字节。

慢存储用例在一次写入期间连续提出 100 次保存请求，最终生成和写入两份录像：首份和最新提交进度。相同进度的重复请求不编码；确认帧未变但补算提交进度增加时继续保存。调用强制保存后立即清空原生记录，存储仍收到调用时的完整结尾数据。

保存继续使用现有完整录像编码器与格式，提交内容来自原生确认输出。该优化合并重复工作；每次真正保存仍完整编码，不进行二进制尾部拼接。

## 固定布局状态

普通版与多人版使用相同的版本 1、27 项 double 浏览器状态接口。逐帧读取直接取得菜单、坐标、速度、录像和音乐信息；`th12_host_state()` 保留 JSON 诊断和旧构建兼容入口。内存增长后重建读取视图，不保存跨帧 Wasm 指针视图；返回的浏览器对象与前帧独立。

实际 C++ 的无窗口夹具逐字段对照数值接口与 JSON，覆盖菜单、游玩、对话、录像、暂停、读盘、多人本地席位及退出存储。大整数保持完整数值，浮点 JSON 比较遵循旧格式有效数字。夹具不调用 SDL 初始化、游戏启动或逻辑 tick。

## 验证入口

- `tests/multiplayer-autosave.test.mjs`：队列合并、失败重试、代次、确认／提交水位和停止前保存。
- 两侧 `tests/sdl-host-state.test.mjs`：字段布局、内存增长、旧运行包兼容和越界检查。
- 两侧 `tests/sdl-hot-path.test.mjs`：维护者音乐缓存与键盘边界。
- 多人 `tests/sdl-main-site.test.mjs`：5 秒同步独立于录像编码，显式同步与回房保留强制保存。
- `TH12_BUILD_HOST_STATE_TEST=ON`：两侧 `th12_host_state_test` 编译并执行无窗口原生夹具。

定向浏览器边界检查共 40 项通过，两侧原生状态夹具通过。交付构建与适配指纹由正式构建／打包入口验证。性能结论限定为去除逐帧 JSON 工作、重复编码和存储积压，不将其换算为整体游戏 FPS 提升；实际在线多人体验由新版运行包验收。
