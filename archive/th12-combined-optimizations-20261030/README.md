# TH12 综合性能优化

自动保存调度、数值状态接口、背景图元旋转复用和多人回滚存储复用汇入同一开发历史。自动保存按确认／提交进度合并请求，数值接口保留 JSON 兼容入口，回滚继续保留快照所有权和模拟顺序。

合并保留两侧来源父链及主线的房间返回、启动取消、观战结束和输入释放处理。普通版与多人版目录投影再次合并，写回完整多人源码树；独立来源连接登记新基点，标准 `git subtree split` 实际导出两侧目录并核对源码树及上游祖先。

[验证记录](verification.json)包含 64/64 项 SDL 与自动保存检查、普通版 10/10 和多人版 9/9 适配检查，以及两侧生产 Web 构建。普通版浏览器回归覆盖触控、全屏、THPrac、保存及录像；多人使用 25 ms 输入延迟触发双人／三人真实 RTC 回滚，核对确认暂停的权威哈希与录像重建，并验证双人观战定位和返回房间。

组件测量分别见[背景图元复用](../th12-sdl-background-cache-20261030/README.md)、[回滚存储复用](../th12-mp-rollback-storage-20261030/README.md)；自动保存与数值接口见[接口记录](../th12-autosave-host-state-20261030/README.md)。
