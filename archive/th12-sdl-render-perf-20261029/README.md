# TH12 SDL 呈现工作复用

单人和多人共用绘制优先级分桶、帧代次查找表和场景缓冲。分桶接收 Web 适配器已有的排序策略，先保留顺序正确的绘制链，再排序发生逆序的桶。身份查找保留首次登记规则，背景并列深度保留原插入顺序。

| CPU 组件 | 优化前 | 优化后 | 临时分配 |
| --- | ---: | ---: | ---: |
| 12000 个绘制对象 × 1000 次排序 | 1538.888 ms | 520.103 ms | 0 → 0 |
| 512 条三中断绑定 × 600 帧 | 58.738 ms | 25.949 ms | 614400 → 0 |
| 七关背景合计 1680 次捕获 | 22.303 ms | 18.172 ms | 5280 → 0 |

同一 Windows 主机以 MSVC 19.51、`/MD /O2 /fp:strict /std:c++20` 构建，五轮交替执行，表中为中位数。[performance.json](performance.json)保留完整测量、普通绑定对照和输出哈希。数据衡量 CPU 组件，整场帧率由逻辑、网络、绘制和设备共同决定。

33 个原版 ANM、1393 段脚本的稀疏采样、倒退、中断及显示随机数输出一致；七关背景顶点流、场景排序顺序与基线一致。菜单、加载、结局和圆形特效复用容器，常用三指令中断序列内联存储，长序列保留全部指令。

多人暂停、等待输入和额外高刷呈现沿用当前场景捕获。世界帧、关卡或回滚恢复序号变化会使捕获失效，恢复次数覆盖回滚后落在相同帧的情况；FPS 文本在绘制时独立更新。浏览器回归核对暂停后捕获序号稳定，并继续验证回滚、观战与确认录像重建。

58 项针对性检查和两侧 Web／Windows 构建通过。单人回归覆盖竖屏滑动、触控暂停、THPrac 鼠标、全屏与录像。双人回滚用例验证观战定位和确认录像；三人回滚执行 21／22／36 次真实恢复，暂停后的权威状态与录像重建一致，暂停重绘期间捕获序号保持不变。
