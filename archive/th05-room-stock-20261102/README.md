# TH05 资源侧栏与房间设置

“火力以数字显示”切换为两行紧凑侧栏：P1／P2／P3 席位编号、机型射弹标记、`当前火力/128` 与原版 P／残机／Bomb 图标。机型标记直接使用对应角色与配色的射弹贴图；[12 种标记像素核对](marker-pixels.json)与审定素材包完全一致。[实际运行画面](numeric-hud.png)展示混合角色与不同火力值。

房间／难度设置提供全队初始残机 0–5 和 Bomb 0–3，沿用 PR #143 的 `lan.html`、`launch-config.js` 规则（提交 `659e65658d4cd1bcfee1670f4c5cc63d79d2819f`）。残机不含当前自机，默认 2 残、3 Bomb；设置由房主修改、向全员同步并清除准备状态，开局后固定。

[原生资源验收](native-stock.json)覆盖普通／Extra、两人／三人、零资源与上界组合共 16 组，并逐席核对重开后的资源。[自定义资源回滚](rollback-stock.json)在 5 残、0 Bomb 下执行两人／三人七关共 40 组、每组 360 帧，世界字节和音频事件与完整真实输入一致。[生产直连](network.json)验证输入抖动、触控暂停、返回房间与再次开局。

共享契约与房间服务测试覆盖 24 种资源组合、输入范围、房主权限、队友同步、准备失效与开局锁定；启动器类型检查与房间服务／界面回归验证沿真实模型执行。
