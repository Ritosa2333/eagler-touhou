# TH17 1280×960 回滚呈现与快照 · 2026-11-06

多人快照直接构造活动弹幕、动画和玩家状态记录。道具池沿原版槽位顺序遍历已用索引，回滚时移除废弃时间线的道具。补算保留影响游戏状态的动画变换和精灵几何，跳过材质提交、轨迹顶点和其他呈现操作。

跳过对话键作为战斗中的持续输入参与预测。进入对话、暂停或其他场景边界时，继续等待确认输入。

## 正式运行包

桌面 Chromium 为每席建立独立浏览器上下文，WebGL2 使用 RTX 5080 Laptop GPU 的 ANGLE D3D11 后端。游戏输出固定 1280×960，CPU 限速 2 倍，客端输入注入 110 ms 延迟。FPS 按实际窗口提交计数。

快照优化构建另以 Easy 双人房跑过一面道中、关底非符和符卡，再进入二面。两端有 11060 个确认帧一致，其中二面 244 帧，房主平均呈现 59.54 FPS。这轮使用同一 GPU、110 ms 延迟与原速 CPU。普通版的浏览器验证覆盖启动、音频、存档和原版录像。

## Extra 关底三人房

两轮使用原版 Extra ECL、固定输入和碰撞保护，在独立浏览器上下文运行三席。第二席向同伴发送的输入额外延迟 145 ms，并注入 0–20 ms 抖动。从第 9000 个确认帧起应用 2 倍 CPU 限速。两轮各有 34847 个一致确认帧，十张关底符卡的起止帧、弹量峰值和最终状态一致。第 32442 帧达到 1945 颗敌弹，第 34967 帧退出最终符。

## 软件渲染

同页 SwiftShader 测试将多席放在同一浏览器主线程，输出保持 1280×960，CPU 限速 2 倍，客端输入延迟 110 ms。新版房主的平均呈现分别为普通关 2P 21.29 FPS、3P 14.24 FPS，Extra 2P 20.71 FPS、3P 13.85 FPS。四房均通过确认帧比对，弹幕中均发生回滚。
