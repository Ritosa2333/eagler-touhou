# TH12 静态 HUD 采样优化

TH12 普通版、多人版共用的 HUD 采样器现在可以跳过已经完全静止的动画补算。按第 18000 帧重建整套 HUD，本机采样均值由 161.35 ms 降到 0.99 ms；按第 60000 帧重建，由 502.56 ms 降到 0.82 ms。Boss 和苗 B 放雷场景的完整呈现状态、采样像素保持一致。

## 开销来源与行为

采样轨道的键包含动画及中断参数。残机、雷数、碎片、飞碟槽变化会选择新轨道；呈现重置也可能重建底框及其子动画。旧采样器为新轨道逐帧执行到目标年龄，因此已经停止的 HUD 动画也会补算成千上万次；开销会随游玩时间增长。

新路径要求轨道已经生成至少一帧，且满足：指令已停止或结束、全部速度为零、没有插值、角度和 UV 已完成归一化、所有子动画也已静止。满足条件时，只推进根轨道及子轨道的年龄计数。运动、等待未来指令、插值和移动子动画继续逐帧执行；向过去跳转时仍重新建立对应年龄的轨道。

共用绘制路径另有两处减分配：把原生顺序直接写入本次采集的新姿态对象，避免每个姿态再创建一份顺序对象；复用排序桶，并使用同一个结果数组完成分桶和输出。导出的旧帧保持独立，排序仍使用原生优先级、顺序和稳定索引。

## 实测

基线为上轮优化提交 `a2bd40233110a8c035d5b80695ee48bd4621abe8`，候选为本次修改。HUD 采样使用真实 `front` 动画、5 轮交替顺序，比较两套返回姿态与诊断值；20 个场景共 100 组配对全部一致。它衡量 JS HUD 采样，不包含游戏模拟或 GPU 绘制。

| 目标年龄／场景 | 普通版：基线 → 候选 | 多人版：基线 → 候选 |
| --- | ---: | ---: |
| 18000，底框重新绑定 | 72.25 → 0.52 ms | 78.68 → 0.56 ms |
| 18000，整套 HUD 重置 | 161.35 → 0.99 ms | 146.69 → 0.96 ms |
| 60000，底框重新绑定 | 259.15 → 0.41 ms | 259.44 → 0.35 ms |
| 60000，整套 HUD 重置 | 502.56 → 0.82 ms | 496.37 → 0.88 ms |

生产普通版 Wasm（SHA-256 `657298724c0a2b9d49209e79021206c8a3ff5ece3d59b07eecdd236247505d66`）、真实六面分段 45、苗 B 的浏览器配对采样中，Boss 采集均值由 0.579 降到 0.531 ms，射击加放雷由 0.741 降到 0.687 ms，相比上轮版本分别下降约 8.2% 和 7.3%。两场景各四个采样点的呈现状态结构一致，RGBA 像素差异均为 0；结构核对允许对象字段的插入顺序不同。

浏览器为 Chromium 153.0.8010.12，以上为本机测量。浏览器配对同时绘制基线及候选，用于比较路径成本；实际 FPS 和网络回滚成本分别由游戏运行决定。本轮不改变模拟、碰撞、快照或网络调度。

## 验证与复现

- 普通／多人渲染套件，覆盖绘制顺序、图层、插值、原生像素取整、背景和状态内存增长。
- 静态动画与显式逐帧执行对照，检查姿态、父子时钟、随机数、反向查找，以及持续旋转、缩放、滚动、插值、未来指令和移动子动画。
- 在两侧的 `test:renderer` 加入静态采样回归。
- [HUD 配对数据](hud-sampling.json)、[浏览器呈现配对数据](renderer-comparison.json)。

HUD 复现入口为 `tools/ports/th12-hud-sampling-profile.mjs`。设置 `TH12_PROFILE_ASSETS` 指向本地提取资源，`TH12_PROFILE_BASELINE_REF=a2bd40233110a8c035d5b80695ee48bd4621abe8`，再执行脚本。默认输出到 `artifacts/th12-hud-sampling/report.json`。

浏览器入口为 `tools/ports/th12-byakuren-profile.mjs`：沿用上述基线，设置 `TH12_PROFILE_COMPARE=1`、`TH12_PROFILE_FRAMES=600`，并指定生产 Runtime 和提取资源目录；`TH12_PROFILE_BOMB=1` 使用射击和放雷场景。基线 renderer、动画采样器、顺序器及插值模块均从指定提交读取。
