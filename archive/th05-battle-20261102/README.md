# TH05 多人战斗与双 Boss 转场

四面双 Boss 击倒一人的 0xfd / 0xfe 爆炸阶段使用固定内存状态，现纳入已有八帧回滚窗口。0xff 对话安装和 Boss 替换继续执行确认屏障。双方击倒路线分别通过两人、三人的完整世界字节与音频顺序核对。

[延迟比较](comparison.json)覆盖两条击倒路线：150 个确认帧中，两人停等由 600 次降至 4 次，三人由 1050 次降至 68 次。[十三组边界检查](boundaries.json)覆盖爆炸、对话、替换 Boss、换面与重开；[四十组回滚检查](dense-rollback.json)覆盖各面起点。

多人绘制路径将每张四边形的四个顶点各变换一次，再按原顺序输出两个三角形；单位矩阵下的正交投影直接使用结果，减少逐张贴图重复的矩阵乘法。[三轮配对采样](render-comparison.json)在同一桌面浏览器 4 倍 CPU 限速下测得三面绘制平均耗时下降约 18%，四面约 15%。这些数据衡量 CPU 提交开销。

[56 组画面对比](pixels.json)验证游戏区域 RGB 像素一致，比较范围排除右下角实时 FPS 数值；[激光对比](laser-pixels.json)验证水平、斜向与竖向激光像素完全一致。[观战验收](spectator.json)覆盖回滚流接收、时间轴和阶段重建。

发布范围为独立多人运行组件中的 `th05.wasm`，普通版和其他作品保留当前版本。

[正式入口验收](public.json)使用主站简体中文三人仅回滚房间，覆盖观战加入、暂停、回看、返回直播与退出后玩家继续运行。[发布记录](published.json)记录主站运行组件与文件保留范围；两处镜像已同步。
