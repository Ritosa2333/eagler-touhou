# 東方海恵堂 Omniverse 录像选关

r9 在 r8 的高刷显示基础上补齐 Omniverse 录像选关。原生录像记录 Boss 编号，共用载入流程在初始化前将有效编号恢复到挑战选择，游戏内 Replay 菜单与网页工作台均进入录制时的挑战，后三项按录制角色选择对应符卡。

恢复限定于录像难度 5、关卡 7、Boss 编号 0～7。普通游戏、Practice、EX 和原格式继续使用各自流程，Practice 返回后原有的残机与 Bomb 行为保留。

## 验证范围

`replay-entry-browser.mjs` 使用正式 normal WASM、现有测试 DATA 和独立后台 Edge。合成录像通过正式文件接口写入，游戏内入口使用菜单按键进入 Replay；网页入口通过正式播放命令载入。

| 项目 | 结果 |
| --- | --- |
| 修复前复现 | 要求第二项挑战时仍进入第一项，选关断言失败 |
| 两个入口 | 八挑战、三角色共 48 个组合，初始化选择、实际 Boss 和符卡编号正确 |
| 菜单残留状态 | 先进入 Practice 第六项再返回，游戏内 Replay 按录像恢复挑战，同时保留原残机与 Bomb 数量 |
| 其他关卡 | 普通、Practice、EX 在两个入口的六个载入检查通过 |
| 格式与编号边界 | 扩展录像恢复挑战；两个越界编号保持原菜单选择，共三个用例通过 |
| 实际原生录像 | 第六项灵梦 B 录像进入「Birthday Eve」，两个入口连续推进到原生末帧，游戏内进入 EOF 暂停且游标停止；网页定位重开和结束停止通过 |

本轮另运行功能模块、源码清单、文档和本作接口检查，并重新编译 WASM、构建站点。结构化结果及构建身份见 [validation.json](validation.json)，复现入口见[开发指南](../../ports/thkkd/docs/DEVELOPMENT.md)。

## 结果复用

改动位于读取录像并完成校验之后、游戏初始化之前，补齐有效 Omniverse 录像的菜单选择。关卡内数学、RNG、对象布局、按键重放、逻辑调度和绘图代码保持原有实现；固定 60 用例、835289 逻辑步、48 个 Omniverse 成功返回，以及资源导入、存档与高刷显示沿用 [r7 适配验收](../thkkd-adaptation-20261127/README.md)和 [r8 高刷验收](../thkkd-high-refresh-20261127/README.md)的对应结果。本轮专门覆盖实际录像文件的载入与选关。
