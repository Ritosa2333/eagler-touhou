# TH17 普通关高清回滚 · 2026-11-06

普通关的 STD 背景物件在场景初始化时按图层和原始顺序编排。每组图层共用相机矩阵和裁剪参数。裁剪保留原版的距离门限、16 点投影和浮点顺序，包围盒覆盖播放区域时即可完成可见性判断。多人普通关在场景稳定时由背景绘制统一清除播放区域，换面继续使用原有的清除顺序。

一至六面的原始背景资源共提供 334 个物件实例。在 256 组相机和距离参数下，85,504 次对照的可见性与输出投影坐标逐位一致。相同 WASI 裁剪循环对 2,736,128 个实例判定的耗时从 307.23 ms 降至 227.18 ms，约减少 26%。该计时覆盖背景裁剪，整房帧率见下表。

## 房间复测

正式多人运行包经启动器预览入口连接本地 Relay，画面固定 1280×960，Chromium CPU 限速 2 倍，第二席输入额外延迟 110 ms。硬件渲染使用独立浏览器上下文和 RTX 5080 Laptop，软件压力档在同页使用 SwiftShader 运行全部席位。帧率按浏览器实际画面提交计数。

Normal 三人加压档使用 4 倍 CPU 限速、145 ms 延迟和 0–20 ms 抖动，从一面 Boss 的非符和符卡推进至二面。8897 个确认帧在三端一致，包含 1376 帧 Boss 非符、915 帧符卡和 240 帧二面，敌弹峰值为 138。三席的全程平均呈现帧率为 58.24 / 58.40 / 58.36，符卡段为 59.81 / 58.95 / 59.60。纠错回调耗时 P95 为 14.17 / 14.38 / 14.29 ms。换面附近的最大呈现间隔为 737.41 / 699.55 / 730.71 ms。

普通版和多人版使用同一份场景绘制源码并分别生成正式运行包。原生回归覆盖会话、动物灵、碎片、激光回滚和 HUD，普通版浏览器验证覆盖启动、音频、存档与原版录像。六面背景的裁剪对照与房间的一面到二面推进分别记录验证范围。
