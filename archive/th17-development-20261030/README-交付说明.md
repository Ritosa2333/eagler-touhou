# 鬼形兽 WEB 1.0.14 完整开发交付 · 2026-10-27

沿用永夜抄、风神录、绀珠传测试组的完整开发包形式：可运行网站、完整 C++ 与前端源码、共享 SDL3/WebGL2 渲染／输入源码、原版素材、测试与原版对照工具，以及 Windows x64 编译工具链。

完整解压到较短可写目录（例如 E:/TH17），双击根目录“启动鬼形兽网页版.cmd”，打开 http://127.0.0.1:8117/ ，保持窗口开启。不要在 ZIP 内运行或只解压 th17_web。本地测试端口避免与现有公网 3007 服务冲突。

当前版本 1.0.14，默认 1280×960，可在启动器切换 640×480。方向键移动、Z 开火／确认、X 符卡、Shift 低速、Esc 暂停；手机使用连续触控、低速、开火、BOMB、ESC。录像通过前端“录像／管理”导入。本包保留用户提供的 Th17_ud0134.rpy 和网页版保存的 th17_01.rpy 作为回归样本。

完整更新记录见 CHANGELOG.txt。游戏逻辑和网页版素材为日文 1.00b；附带汉化 EXE 供原版对照，不代表网页版已支持中文。当前手机六面密集弹幕／消弹的性能仍需测试组复测；包内验收记录未将“实体手机全程至少 55 FPS”标为通过。不得把桌面手机视口或平均帧率当作真机最低帧率。

双击“重新编译鬼形兽.cmd”用包内 Python、Node、Emscripten／SDL3 缓存及 TypeScript 重建网站。已附 WASI SDK、Unicorn、Playwright Chromium、Ghidra/JDK、Capstone 和音频转换依赖。原版字体重新采样需要 Windows 原日文字体；常规构建直接使用附带的测量字形。命令见 handoff/BUILD-AND-TEST.md。

保持完整目录结构。th08_web、th09_web、th10_web 是共享工具与依赖路径，不是其他游戏的完整开发包。Windows x64 可离线构建；Linux 部署已构建网站只需 Node，重新编译需配置 Linux 工具链。

部署说明见 deploy/部署说明.md。当前发布身份见 th17_web/reference/release-acceptance.json。“验证开发包.cmd”检查发布文件、源码及部署入口，FILE-SHA256.json 校验全部交付文件。verification 记录本交付在独立目录内启动、重建与回归的实际结果；历史报告保留原构建身份，不代表每个补丁重跑所有路线。

保留原版素材、已授权的录像样本、分析和性能记录；未附维护者浏览器存档、个人配置、隧道令牌或进程记录。没有保留全部历史候选网站／编译对象；依赖这些候选的历史比较脚本需按对应文档重新生成输入。一开始复制共享启动器和跨游戏函数匹配的脚本属于历史构建步骤，当前源码已完整提供，常规重建不需要其他游戏的原版目录。
