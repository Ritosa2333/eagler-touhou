# 鬼形兽 C++ 重建状态

更新：2026 年 10 月 27 日。目标为本地日文原版 1.00b，EXE 的 SHA256 固定在 `target.json`。

最新进展：WEB 1.0.14 已部署，公网完整 Wasm 哈希与实际手机视口的加载、游玩、暂停、返回检查已通过（桌面 Chromium，非手机性能）。六面消弹仍大量绘制全透明精灵边缘，并在战斗中逐个分配动画节点；现裁剪经过验证的透明外围、预分配连续动画池并复用溢出节点，缓存未变化的旋转和活动插值器，避免纯 2D 目标的无用深度附件。15 项组件与复用测试、6 组深度清空语义对照通过；四五六面 86,874 次更新的 1,450 个状态点及 Extra 81,228 次保护输入全部一致。47 个图像点通过预设舍入差范围，最大通道差 4/255，不属于逐像素完全一致。同段六面四倍 CPU 压力均值 55.57→58.56 FPS，CPU 均值 12.56→9.62 毫秒、GPU 5.71→4.28 毫秒；剩余 2 个低帧窗口，最差滚动一秒 34.43 FPS。7 种刷新相位测试均提交 600/600 帧，但不能宣称手机持续 50 帧已解决或全程最低 55 帧达标。详见《2026-10-27-六面消弹透明填充与动画池》。

普通六面、Extra、九种机体、Stage Practice、Spell Practice、结局、Music Room、战绩、设置、存档和原版录像已接入完整 C++ 应用。正式 WEB 1.0.14 已发布到 https://api.steinsgateon.com/ ，源服务端口为 3007。功能回归、本地生产包与公网实际游戏启动通过记录中的样本检查；手机全程最低 55 帧未取得物理设备验收。

1.0.10 修复 1.0.9 在超过 1 毫秒刷新相位偏移下仍会产生 50 次/秒画面提交的漏项，并复用消弹合批的临时内存。新构建完成六面录像 135,033 次更新、2,254 个完整状态检查点、Extra 81,228 次保护输入更新及 182 个像素检查。桌面四、五面 CPU 耗时有所下降，六面尚不能认定有明确速度提升；所有耗时尖峰保留在报告中，详见《2026-10-26-持续50帧复查》。

已完成对照的组件包括资源解码、ANM 动画与 CPU 绘制数据、ECL 解释器、标题选择、自机移动及射击、敌人脚本及伤害处理、弹幕、激光、道具、动物灵体、暴走系统，以及七关背景脚本、镜头、可见性和背景绘制数据。关卡波纹与径向扭曲已对比 CPU 网格、动画归属、随机数和时钟。敌人伤害查询已接入真实的自机伤害池，水獭屏障伤害回调亦有原版对照。

每份测试报告单独注明样本、比较范围和仍被截获的服务边界，索引见 `reference/reconstruction-status.json`。早先构建的报告保留各自的构建哈希，不能视为最新构建已全量回归。

后续组件对照已覆盖九种机体炸弹、符卡开始与结算、HUD 数值和提示动画、63 种关卡与机体组合的对话、关卡推进及主场景回调。战斗模块已用受控脚本联合对照自机、敌人、子弹、道具、动物灵体、暴走、炸弹、符卡、HUD 和实际对话；这些检查仍不等于真实关卡或完整录像同步验收。

三份原版演示已通过共 20,461 帧逐帧状态对照，完整网页应用也完成了三份演示的逐帧回归。225 组关卡、机体和难度组合完成 8,006,077 帧实际脚本检查；全脚本检查启用了自机保护，不能等同于原版无修改长录像同步。

桌面应用模式、录像保存重载、原版录像 Z/Ctrl 加速、音频、设置和数据库持久化已通过。Android 与 iOS UA 的触控路径完成浏览器模拟检查；手机真机 GPU 性能和 Safari 兼容性需另行实测。

连续六面和 Extra 的完整更新、GPU 绘制、音频与通关出口验收已完成。187 项 C++ 测试中的一项夹具字段错误已修正并重跑通过，组合回归记录没有未解决失败，保留初次运行的失败日志以便审计。已修复真实屏幕偏移下自机射击被提前裁剪，以及跨关时录像最后一帧的符卡计时写入下一关快照的问题。组件数量和脚本帧数不作为穷尽全部可能输入的证明。
