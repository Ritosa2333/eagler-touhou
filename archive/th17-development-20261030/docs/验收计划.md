# 鬼形兽还原与发布验收

目标为本地日文原版 1.00b，原版 EXE 的 SHA256 固定在 `target.json`。生产程序为具名 C++ 游戏模块，经 Emscripten 编译为 Wasm。开发用原版执行对照器、原版 EXE、D3DX DLL 不编入生产程序，也不放入网站清单。

## 原版行为与录像

`tests/cpp` 独立对照资源、ANM、ECL、数值与随机数、自机、九种射击和炸弹、敌人、弹幕、激光、道具、动物灵、暴走、计分、Boss 阶段、对话、HUD、暂停、关卡推进、结局、解锁、音乐命令、设置、存档和录像。每份报告保留自身的原版身份、构建哈希与比较边界，不能将历史哈希改成最新值。

三份原版演示使用真实 ECL、STD、MSG、ANM、SHT 与统一 StageGameplay 调度逐帧对照：

| 样本 | 关卡 | 帧数 | 报告 |
| --- | --- | ---: | --- |
| demo1.rpy | 三面 | 6,360 | `stage-gameplay-replay-demo1-3.json` |
| demo2.rpy | 四面 | 8,409 | `stage-gameplay-replay-demo2-4.json` |
| demo3.rpy | 二面 | 5,692 | `stage-gameplay-replay-demo3-2.json` |

合计 20,461 帧，比较双方随机流与自机、敌人、子弹、道具、动物灵、暴走、符卡、HUD、背景等状态。完整 SDL 应用还将三份演示的每帧状态与已对照核心的轨迹比较，见 `sdl-application-replays.json`。

225 组全脚本检查覆盖普通六面 × 九种机体 × 四档难度，以及 Extra × 九种机体，共 8,006,077 帧，见 `stage-gameplay-all-loadouts.json`。该测试明确启用自机无敌以到达所有后段脚本；它检查实际脚本和出口能运行，不能代替原版无修改长录像的同步证明。

2026-10-24 新增用户提供的原版 `Th17_ud0134.rpy` 和用户确认由早期网页版录制的 `th17_01.rpy`。两份文件分开验收，不能把后者写成原版录像。原版长录像的逐帧区间、实际录制与导出回放、旧网页兼容规则及单面恢复限制见 `2026-10-24-录像与六面修复.md` 和本轮报告。

## 完整应用和图像

`application-full-stages-browser.test.mjs` 让普通六面连续通关，另跑 Extra，包含实际更新、绘图、音频、Boss 和场景出口。测试保护自机以覆盖后段，每帧都绘制，只将窗口呈现合并到每 120 帧一次。报告为 `sdl-application-full-stages.json`，截图在 `artifacts/browser/application-full-stage-*.png`。

其他应用测试覆盖普通与 Extra 选择、练习残机、Spell Practice、结局与职员表、战绩和名字输入、Music Room 返回、暂停与重开、录像保存与再播放，以及设置和浏览器数据库重载。原版字体使用测量后的 RGB 覆盖纹理；默认 1280×960，启动器可选 640×480。

共享渲染源码为固定哈希的 `portable/sdl/Renderer.cpp`。具名游戏模块生成 CPU 顶点与语义绘图状态，由 SDL3 / WebGL2 绘制，网页使用批量 glBufferData 上传及缓存顶点布局。`architecture-baseline.json` 与 `shared-architecture-extensions.json` 核对共享源码；各作保留自己的游戏逻辑。

## 音频和触控

`sdl-audio.json` 检查实际 SDL3 / miniaudio / Vorbis 混音：80 个原版音效、18 首 OGG 的 PCM 长度及原版循环位置、左右声道、停止与恢复、暂停、淡出、标题及关卡命令和实际 SDL 队列。场景音频事件另由完整应用测试覆盖。

`launcher-mobile-browser.test.mjs` 使用 Chromium 手机视口、DPR 和 CDP 触摸事件测试 Android 与 iOS UA 两条启动器路径，检查任意角度连续移动、松手、低速、开火、BOMB、暂停恢复、竖屏布局和两档缓冲分辨率。连续触控另记入录像扩展，导入原版录像仍读取原版键盘流。

iOS UA 测试运行在 Chromium，不能代替 Safari/WebKit 或安卓/iPhone 真机 GPU 驱动和帧率测试。软件 GPU 的测试批次耗时不作为手机 60 FPS 的承诺。

## 正式构建与公网

完整功能验收后才设置 `target.json.completeGame` 并正式构建：

```powershell
.\th10_web\tools\node.exe th17_web/scripts/build-sdl-application.mjs --release
.\th10_web\tools\node.exe th17_web/scripts/package-release.mjs
.\th10_web\tools\node.exe th17_web/scripts/verify-release.mjs
.\th10_web\tools\node.exe --test th17_web/tests/sdl/production-launcher-browser.test.mjs
```

`verify-release.mjs` 核对当前源码、头文件、共享架构、所有资源长度及 SHA256、生产导出接口、测试入口缺席、实际服务器的 Range、ETag、跨源隔离、CSP、只读方法和私有路径 404。正式浏览器测试使用实际 RAF 检查桌面和手机视口的启动、选择、游戏、PCM 队列、暂停恢复、返回标题音乐及玩家文件，不依赖开发探针。

`start-public.ps1` 使用已授权的 3007 端口及既有 Cloudflare 隧道。本地与公网的游戏 ID、网页版本、清单身份和 Wasm SHA256 一致，并实际进入游戏后，才记录为已发布。最终记录为 `reference/release-acceptance.json`。

通过已列明的原版样本和自动化检查，不等于穷尽所有输入和浏览器环境。报告保留具体覆盖范围，测试组发现偏差时应保留录像和首次异常位置以便确定性对照。
