# 鬼形兽 WEB 1.0.4：加载画面恢复

对应反馈：开始游戏和重新开始缺少原版“少女祈祷中 / Now Loading”，以及紫色纹理背景。使用原版日文 1.00b 的 ANM 图像与动画脚本，不用网页文字或仿制图片替代。

## 原因与修复

- 原先只创建了 `effect.anm` 的空等待控制脚本，漏掉原版描述符 0 的初始化。现在调用已有的具名效果接口，创建四块切换遮罩和脚本 194 的紫色滚动背景；普通开始和关卡练习补齐原版 interrupt 7。
- WebAssembly 在同一帧中同步创建游戏，浏览器来不及显示加载画面。现在先呈现原版关闭动画，再创建目标场景；加载期间暂停游戏逻辑、输入采样、录制和回放时钟，并隔离加载动画使用的随机数。
- 原版展开后的切换控制器由场景保留。重开时必须创建新的关闭动画，不能重复使用已经展开的遮罩。保持原版动画解释器和控制器生命周期，只修正应用层对关闭／展开状态的判断。
- 全屏目标含 alpha，按原版启用目标 alpha 遮罩合成。加载标志保留原版半比例坐标 `(960, 784)`，实际位置在逻辑画面 `(480, 392)` 附近。

普通游戏、Extra、关卡练习、符卡练习、原版录像、录像重播及游戏返回标题使用同一入口处理。下一关仍沿用已有的上一关背景过渡；结局脚本内部请求资源仍沿用原来的加载指示接口。

共用 `portable/sdl/Renderer.cpp`、SDL3 / WebGL2 后端及最终版启动器继续使用。版本号和更新日志为 WEB 1.0.4，日期 2026-10-25。
