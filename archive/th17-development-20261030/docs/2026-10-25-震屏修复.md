# 鬼形兽 WEB 1.0.3：符卡及关卡震屏

发布日期：2026-10-25。原版基准：日文 1.00b。

## 原因与影响范围

`BombMarisa`、`BombYoumu`、灵梦宝珠爆炸和 ECL 关卡指令已经向 `ScreenEffects` 创建对应效果，幅度、计时与随机数计算也已经实现。缺失的是游戏绘制入口到摄像机的连接：`GameDraw` 没有把效果产生的偏移写入 `ScreenViews`。因此并非只有魔理沙的符卡受到影响。

原版的 `0x4646c0` 和 `0x4644e0` 分别更新持续震屏及短促震屏。其输出位置 `0x4b6198`、`0x4b5f40` 分别就是 Playfield、Interface 摄像机的偏移字段；它们不是额外的一次整体页面位移。原版绘制收尾 `0x4431a0` 清零这两组偏移。

另一个相关问题是暂停门控：持续震屏回调遇到暂停或不存在游戏时会返回成功，但不写偏移。旧的效果所有者在这种情况下仍复制上一帧结果，一旦接通绘制，就会导致暂停时重复使用旧位移，甚至覆盖同帧另一个效果。

## 修复

- `GameDraw` 在原有绘制调度之前写入 Playfield 和 Interface 的独立偏移，由原有摄像机选择、动画层和离屏合成顺序应用震屏。
- 绘制结束后清零效果所有者的偏移，配合原有 `ScreenCompositor` 的摄像机偏移清零；清理效果时也清零，防止过期或返回场景后残留。
- 持续震屏被暂停门控拦住时不再重复提交旧样本。短促震屏保留原版自己的门控和时序。
- 原版的随机数来源、回调优先级、同优先级顺序、震幅渐入／保持／渐出不变。两种偏移分别传递，保留原版短促震屏中不同的符号规则。
- 最终全屏与暂停文字叠层保持原来的坐标；使用逻辑分辨率的偏移，由既有渲染缩放处理 1280×960，没有重复乘以渲染倍率。

本次没有更改共用 `portable/sdl/Renderer.cpp`、纹理、着色器或顶点上传策略，仍使用最终版 SDL3 / WebGL2 后端。生产版本不包含开发探针或原版可执行文件运行器。每帧新增的是固定数量的偏移复制及清零，没有新增每帧动态分配或 GPU 读回。

## 本轮验证

| 检查 | 结果与边界 |
| --- | --- |
| `screen-shake.test.mjs` | 256 个原版对照样本、46,080 帧，检查持续／短促震屏的计时、幅度、符号、随机数、暂停门控与分辨率缩放。 |
| `screen-effects-frame.test.mjs` | 48 个原版对照场景、8,640 次更新、6,480 次绘制收尾、75,600 项检查；覆盖重叠效果、暂停／游戏缺失／关闭、三档速率与缩放、连续更新后再绘制、结束清零。 |
| `screen-compositor.test.mjs` | 原版十个合成回调的目标、清理顺序、摄像机偏移及完整顶点流对照通过。 |
| `draw-schedule.test.mjs` | 四档原版摄像机初始化及动画绘制层顺序对照通过。 |
| `game-battle.test.mjs` 的炸弹集成组 | 九种角色／动物组合各 600 帧，共 5,400 帧原版战斗对照通过，包含真实伤害、清弹、震屏请求和两组随机数。 |
| `application-screen-shake-browser.test.mjs` | 实际 SDL3 / WebGL2 应用共观察 7,386 帧。1280×960 覆盖全部九种组合，640×480 覆盖魔理沙＋野狼；观察实际绘制过程中游戏区域／界面摄像机的偏移，检查全屏叠层、暂停恢复、自然结束、共用关卡短震路径和每帧清零，图形错误为零。 |

浏览器测试里的临时回调只读取真实渲染器状态，不修改摄像机。关卡短震通过同一个生产 `ScreenEffects::nudge` 入口触发；炸弹通过正常游戏按键触发。相关报告位于 `artifacts/cpp/verification/`，记录各自实际运行的构建身份。上述检查没有覆盖全部关卡震屏出现时刻，也不等同于手机真机 GPU 性能验证。
