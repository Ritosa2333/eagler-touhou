# TH17 普通关联机快照 · 2026-11-07

战斗快照保存关卡记录、主座机体和动物组合的符卡记录、全机体符卡汇总、音乐解锁和成就。存档编码缓冲、排行榜和符卡难度表退出逐帧复制，每份快照少复制约 204 KiB 的固定字段。动画子节点在一块连续内存中按原顺序保存。子弹池沿原空闲链保存并恢复槽位和复用数据。

## 普通关房间复测

正式多人运行包经启动器预览入口连接本地 Relay。Chromium 使用 Intel 核显，独立页面运行各席位，画面为 1280×960。帧率按实际画面提交计算，快照时间按每席的抓取次数平均。

| Normal 一面开场 | 基线平均呈现 FPS | 更新后平均呈现 FPS |
| --- | ---: | ---: |
| 2 倍 CPU 限速，110 ms，双人，两轮 | 58.69–59.57 | 58.40–59.73 |
| 2 倍 CPU 限速，110 ms，三人，两轮 | 58.74–59.67 | 58.17–59.31 |
| 4 倍 CPU 限速，145 ms，三人 | 55.79–56.25 | 54.90–55.46 |

三人加压开场的单次抓取从 2.38–2.43 ms 缩到 2.10–2.16 ms，最大呈现间隔从 181.5–191.8 ms 缩到 160.2–162.5 ms。双人与三人的开场验证包含超过 1,050 个确认帧和指定队友收取赠送残机。

加压房继续推进至二面，共比对 8,913 个确认帧，其中有 1,395 帧 Boss 非符、992 帧符卡和 244 帧二面。三席全程平均呈现 38.82–39.24 FPS，包含 Boss 非符和符卡的迟到输入纠错。原生测试同时核对了动画子节点关系、子弹槽位复用顺序、会话回滚、动物灵、碎片和激光状态。
