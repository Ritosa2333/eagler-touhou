# TH17 双席滑动长帧 · 2026-11-07

普通难度一面在独立 Chromium 页面通过本地 Relay 开房。两位玩家同时滑动，画布为 1280×960，使用 WebGL2 和 OGG。每方向注入 60 ms 延迟与最多 15 ms 抖动。P2 使用六倍 CPU 限速，其余席位使用正常速度。

## 长帧分段

[上次双人房](../th17-render-release-pressure-20261107/2p-both-window.json)的 49.74 ms 间隔属于一面道中。旧探针从 50 ms 开始保留逐帧回调，所以该间隔有时长、阶段和画布采集峰值。该轮 P1 在滑动期间有 9 次触及 12 帧预测上限的未出画回调。新探针记录超过 25 ms 的间隔，保存间隔内每次回调的耗时、补算帧数、等待状态和提交标记。

- [双人旧包分段](2p-baseline-trace.json)记录 P1 道中 33.14 ms 间隔。一次晚到的回调补算 4 帧，下一次补算剩下 7 帧后提交。两个游戏回调共占 3.84 ms。
- [双人旧包分段复跑](2p-baseline-trace-repeat.json)记录 P2 道中 40.46 ms 间隔。该次游戏回调 6.86 ms，补算为零，确认处理 0.98 ms。同轮的开场长帧另有一次恢复快照耗时 12.48 ms。
- [三人旧包](3p-baseline-clean.json)记录 P1 道中 55.49 ms 间隔。前两次回调处在预测上限，第三次收到输入后补算并提交。三个回调共占 6.64 ms。

画面调度从每次实际绘制采样成本，包括补算的最后一帧。晚到的刷新有一个很短的预算，可用于一次做完剩余补算并提交画面。
