# TH05 数位笔输入

单人和独立多人将 `pointerType=pen` 的笔尖接触交给已有触控路径。鼠标继续走界面路径，手机手势使用原有处理。运行组件差异只包含两个 `shell.mjs` 的同一处类型判断，WASM 与游戏资源逐字节保留。

旧版在 Chromium CDP 数位笔拖动后，两个多人席位的自机 X 均保持 2560；[修复后](multiplayer.json)两端均变为 3280，悬停与抬笔后不再移动，并通过手机滑动、暂停触控和返回房间。[单人验收](singleplayer.json)从 X=224 移到 269，验证悬停、抬笔与普通鼠标隔离。测试使用浏览器笔事件，实物数位板由设备端确认；触控开关继续生效。

[构建输入](build-input.json)记录两个原生运行组件的 generation 和文件差异。[接收历史](history-accepted.json)保持普通版修改进入多人祖先，多人保留自己的双端测试，单人夹具沿单人目录维护。
