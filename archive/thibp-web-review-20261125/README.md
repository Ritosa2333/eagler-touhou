# 东方鬼葬剑 1.10b Web 单机验收

环境为 Windows、Emscripten 6.0.9、Edge 和 Chrome。使用本地汉化 1.10b 离线包，运行时为 `kizousen-hud-fps`。测试用录像和工作目录由测试者提供。[复测说明](../../tools/ports/thibp/README.md)

| 范围 | 结果 |
| --- | --- |
| 游戏启动与音频 | 从启动器导入离线包，进入标题和第一关，游戏音乐、音效和场景正常。 |
| 输入与退出 | 方向键、射击、特殊攻击、符卡和左 Ctrl 加速通过回归。Esc 暂停、再挑战及标题的 Quit 使用原游戏菜单。 |
| 显示 | 640×480 画面按最近邻放大。模拟 120／144 Hz 时，分别得到 120／144 次呈现每秒，游戏逻辑约 60 Hz。游戏内 FPS 显示实测呈现率，锁 60 时显示约 60 FPS。 |
| Replay | 从原游戏菜单命名保存，退出并重开启动器后，可在原游戏 Replay 菜单回放。第六关 Lunatic 原版录像的 70 个检查点与 Windows 原版一致。 |
| 内置练习 | 场面演习进入第一关，弹幕特训打开第一关列表。练习解锁沿用原游戏记录。 |

触控协议已接通，真机触控验收待补。此记录覆盖游戏内 Replay。
