# TH17 独立普通版与多人版 · 2026-11-06

TH17 普通版由 `ports/th17` 构建，多人版由 `ports/th17-mp` 构建。启动器的工作区映射、构建配方和开发站地址分别指向对应目录。普通版拥有 thprac，联机会话、战斗回滚、旁观与多人录像测试归入多人版。

目录来源继承拆分前的 27 个真实源码提交，原交付校验清单保留开发包身份。普通版与多人版通过标准子树导出核对初始来源祖先和当前目录树，后续通用修复使用 Git 历史合并与同步基线登记。来源连接与维护命令见 [TH17 目录历史](../../docs/migration/th17-subtree-20261106.md)。

普通版与多人版分别完成正式编译和打包。普通版 Wasm 与拆分前逐字节一致，多人版 Wasm 为 `4fa929a9450ca3f26f5cdce32287e9efda216de66737ec546a39e1bd23a8e736`。普通版通过 11 项源码与模块检查，多人版通过 10 项，启动器工作区、来源选择和开发站清单的 5 项回归全部通过。

多人原生测试覆盖会话、动物灵、碎片、激光回滚和 HUD，并使用原始 `beast.anm` 核验动画。新 MP 运行包通过启动器预览进入本地 Relay 的双人和三人房，分别获得 1052 和 1051 个各端一致的确认帧。房测使用 1280×960、2 倍 CPU 限速和 110 ms 输入延迟。普通版浏览器验收覆盖启动、音频、存档与原版录像。

目录历史合并先在临时克隆验证，再通过完整 MP 子树和两个父提交写回。同步后，`port-history/th17mp` 跟踪 `port-history/th17`，普通版待接收提交数为 0，MP 专属提交数为 4。普通版构建脚本固定普通模式，MP 目录默认构建多人模式。
