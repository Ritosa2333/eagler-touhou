## 如何取得真实 hidden

已安装的 Playwright Core 1.62.0 默认给其页面控制会话开启焦点模拟。先前在另一个 CDP 会话发送关闭命令，没有移除该默认覆盖；实际标签已切换，但两个页面仍都显示 visible。新的空白页控制先确认同一原生窗口内真实 `visible → hidden → visible`，再运行游戏。

使用自建 Chrome 的独立目录与静音参数，连接时选择受支持的选项，并使用默认上下文：

```js
const browser = await chromium.connectOverCDP(ownedLoopbackEndpoint, {noDefaults: true});
const context = browser.contexts()[0];
```

新建 BrowserContext 不在该选项的作用范围。测试仅监听和读取实际 visibility／blur 事件，没有覆盖 document.hidden、visibilityState 或派发合成事件。

`th11_input` 是上次实际游戏更新的输入快照。停止更新时它仍可为 128；这不表示物理键仍按下。初版断言错误地要求隐藏时立即为 0，已保留失败记录；当前在返回后的首个真实更新检查为 0，再发送 keyup。后台启动的首个断言也错误地要求已出现交互标题，已改为核验原生启动消息与第 0 帧保持，随后检查前台标题和退出。
