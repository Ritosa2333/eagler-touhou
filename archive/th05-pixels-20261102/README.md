# TH05 四像素判定点与多人配色验收

普通版与多人版将白色圆心和三层外圈替换为居中的 2×2 白色方点，覆盖四个原生像素。低速淡入和常驻显示继续使用原开关，碰撞逻辑保持原有范围。

多人继续采用 `th05-four-player-colors.zip` 的审定素材。素材哈希与实际渲染一同核对，覆盖四角色、三种同角色配色和两种火力侧栏布局。

- [像素输出](pixels.json)：四角色的整数与小数位置各四像素，关闭后无可见点；192 个射弹帧、24 个右侧机型标记与原纹理 RGB 逐像素哈希一致。
- [素材核对](art.json)：240 张已载入纹理与审定 PNG 的 RGBA 哈希一致，并验证近距离透明度和幽灵固定位置。
- [历史写回](writeback.json)与[目录投影](history.json)：普通版修正通过真实历史合并进入多人版，普通版是多人版祖先。
- [发布输入](build-input.json)：普通版和多人版各替换 `th05.wasm`，运行组件文件清单保持原有范围。
- [发布校验](assembled.json)与[主站切换](published.json)：主站发布 `th05-pixels-20261102`，保留 8,123 个原有文件的内容；其他作品和前端沿用原发布。
- [正式站联机](public.json)：中文两人回滚、迟入观战、暂停与恢复直播、退出观战后玩家继续运行通过；海外与国内镜像完成同步。[公网文件](public-assets.json)核对主站与国内镜像的两版 WASM 实际下载哈希。
