# TH05 多人观战接入

TH05 独立多人沿用合作作品的认证旁观席与阶段转播通道。房主上传已确认输入，中继保存当前关卡的标量检查点与输入前缀，观众在独立运行组件中重建游戏。观战可中途加入、暂停、回看当前关卡并返回直播。

[两人直连](two-player.json)、[三人中继](three-player.json)和[开启回滚](rollback.json)验证中途加入后的同帧状态一致、暂停后继续接收、回看重建及观众键盘隔离。换面检查点为 360 字节，覆盖连续三个关卡入口及每关 180 帧的确定性核对。[检查范围](checks.json)和[目录历史](history.json)分别记录测试及独立多人投影。

主站发布同时更新 TH05 多人运行组件、启动器能力和中继的 TH05 标记；单人运行组件与其他作品文件通过发布清单校验保留。

[启动器视角槽位验收](launcher-slot.json)使用正式启动器的 0 号观战视角，并验证本地回看与只读输入。[主站发布](published.json)记录当前运行组件与保留范围。

[只读连接状态](launcher-status.json)同时验证接收连接已打开、没有玩家输入席位，并保留同帧校验、时间轴操作与换面结果。

[主站验收](public.json)使用正式启动器创建简体中文两人回滚房间，中途加入观众，验证加载遮罩消失、暂停接收、回看、返回直播与离开旁观后玩家继续运行。[观战界面](spectator-live.png)展示实际主站画面与共享时间轴。
