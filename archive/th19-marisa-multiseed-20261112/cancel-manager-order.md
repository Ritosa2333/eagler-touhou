# 消弹管理器调用顺序

种子 1 的原版与 Web 在第 1 至 650 帧的主副随机流、CPU 输入、自机与敌弹精确坐标一致。构建为 `e77c20b282cf0dd72225ec99380f91668b9350a21dfc8ead545b86d46271f74f`。

第 406 帧，原版在左场消弹根脚本 173 更新之后初始化右场效果。Web 将两场效果初始化完成后再更新全部消弹根，导致相同数量的副随机调用分配给不同脚本。分场更新后双随机流一致至第 620 帧。

第 621 帧，原版根脚本 176 初始化时的随机延迟为零，第一组子脚本执行后的延迟为一。初始化与当帧管理器更新各执行一次，第二组子脚本在同帧执行。独立消弹根使用帧末递增时钟，并在创建帧参加管理器更新，复现这一执行顺序。

独立消弹根及其子脚本携带时钟模式。已有嵌入式 VM 调用约定沿用各自初始化入口。
