# TH14 上游触控与练习统计修复

候选源码合入上游 `feaa624c6d2110cecf9e4e71139651421ab30bd4` 的 TH14 修复：对话期间保留触控拖动，Miss、Bomb 和五档收集统计随整个游戏会话保留，练习周期写入特殊掉落计数而不覆盖已奖励残机数。合并提交 `0a73dd6d658638d12de621bf3c32a34cc1f1dcab` 保留候选与上游两个父提交；13 个来源锚点和 TH14 子树导出检查通过。子树导出为 `e317b83fcc3b60cf589211753ac9a737500b5550`。

实际 C++ Application 的魔理沙 B Lunatic 普通六关自然通关、结果保存及资源回收通过，五次换关的七类统计保持原值。末段统计为 Miss 43、Bomb 123、五档收集 21／19／18／16／139；每类都由实际玩法触发，观察接口只读。会话结束后统计清零。120,192 个玩法回调及最终成绩 1,508,072,320 与先前声明样本保持，未输入来源录像中的位置、库存、成绩或 RNG 状态。该检查构建了 146 个全新核心单元，统计界面的 ImGui 部分不在此构建范围。

对话触控有九组组件检查，包括游戏与对话切换时保留拖动、释放、轻触、拖出后返回、长按跳过及菜单／录像隔离。周期设置覆盖 200 组周期与已有奖励组合。相同检查均能拒绝旧实现。原有九组触控 Bomb 检查也通过。这些输入组件结果不替代真实触屏设备验收。

浏览器候选全量重编 153 个单元，Wasm 为 `48f552bf04b43bf9b641f88c49973a064e57d5dda601f0e721de505f6ec37646`。前端类型检查、录像模型测试及完整构建通过；私有预览的 32 个运行文件逐文件哈希、COOP／COEP 及 no-transform 通过。实际 WebGL2 中，灵梦 A Normal 完成开局、射击移动、Bomb 消耗、暂停恢复与返回标题，音乐和音效均为零，运行模式为流式 OGG。预览使用写时复制复用游戏资产。

第一轮跨关检查在六关结束、回到标题时将正常清零误判成换关重置。失败报告及其哈希保留；第二轮限定有效关卡并另行检查结束清零后通过，未修改游戏实现以绕过检查。返回标题确认框默认选取消，选择确认后正常返回。

本次范围是声明构建和样本。真实触屏操作、可选统计 UI 的跨关显示以及其余玩法、完整音画、存档和公开入口缺口继续。生产版本保持，整作目标仍在进行中。详见[机器证据](upstream-touch-stats-nov14.json)与[核心验收说明](https://github.com/AdingApkgg/thp/blob/fb7560ef9ae860abb5d9f2932df4519930145cc0/docs/porting/TH14_UPSTREAM_TOUCH_STATS_NOV14.md)。
