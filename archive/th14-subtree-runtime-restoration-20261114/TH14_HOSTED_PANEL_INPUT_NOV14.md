# TH14 托管录像练习面板输入修复候选

状态：进行中；生产未替换，整作目标 active。验收标准为可观察行为级对齐，测试和预览静音。

## 缺口与候选

托管录像的 sample_and_tick_once 在处理 SDL 事件前直接进入录像更新，导致鼠标、焦点与关闭事件被跳过。候选将托管分支移至平台事件泵后，玩法输入仍传 0。实际生产函数体的 WASI 组件检查：144 项候选通过，旧托管分支拒绝 24 项，120 项普通／其他作品对照保持；SDL 与游戏端口为模拟，不计实际玩法通过。

浏览器随后确认独立阻断：录像工作区 iframe 的 pointer-events 为 none。首版接到触控服务，32 项服务检查通过，但实际工作区未启用该服务，F12 打开面板后鼠标仍未放行。该接入已撤回，失败记录保留，不把组件通过代替浏览器通过。

新接入由 PlayerSurface 在录像工作区绑定实际 iframe 文档的 eagler-thprac-menu 事件，仅当前 TH14 原生文档的布尔 open 事件授予鼠标。面板关闭、iframe 重新加载、离开工作区与清理时撤销；其他作品保持原有屏蔽。实际 authored helper 的 7 项模拟文档生命周期检查及前端类型检查、完整构建通过；第二版真实浏览器仍失败：常驻 iframe 的 src 属性为空，运行实例通过内部导航加载，src-based 识别没有绑定事件。修正为当前 document.URL 后，新增空 src 生命周期反例；旧判断 2 项失败，候选 7 项通过，再次类型检查和构建通过。最终实际静音浏览器已通过播放中面板交互：F12 打开后 pointer-events 为 auto，真实鼠标勾选、再取消按键监视器均生效；F12 关闭后恢复 none。原始灵梦 B Normal 第一关、1 倍速、无定位，仅有限片段；在累计 1,706 帧暂停，不计完整录像或暂停面板通过。候选运行代 c44584c6，Wasm 3baf232e。

## 尚未关闭

父查看器暂停会停止整个原生循环，练习面板因而无法刷新。修复必须保持录像帧、玩法时钟和输入不推进，不能直接调用游戏 tick。GameSession::draw 还涉及关卡加载，不能未经验证当成纯界面刷新。此项仍未实现／验收，不计本候选完成。

本轮使用已有录像的有限交互片段，不是新增完整六关验收。音乐和音效均为 0。候选运行文件已独立组装和校验，生产保持既有版本。
