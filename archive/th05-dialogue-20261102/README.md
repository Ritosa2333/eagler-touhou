# TH05 多人对话与切面同步

TH05 多人允许对话文字、对话淡入淡出、开场标志和关卡结束淡出在原有八帧窗口内预测。图片加载、对话资源指令、Boss 创建和场景销毁继续在完整输入前缀确认后执行。纯动画不再逐帧串行等待网络往返。

[同延迟对比](comparison.json)使用一致的 1–7 次调度后到达输入及重排方式，每组运行 720 个确认帧：对话所需调度从 1650 次降至 1101 次，开场从 1512 次降至 731 次，切面淡出从 1789 次降至 738 次。这个指标衡量网络等待，不代表设备帧率。

[六组完整内存与音频校验](transitions.json)覆盖两人、三人的文字、开场和结束淡出，确认回滚后与逐帧确认运行一致，音频顺序与次数相同。[十一组边界验收](boundaries.json)覆盖对话资源指令、Boss 分支、换面、暂停重开和死亡；[四十组战斗校验](dense.json)覆盖各关卡与起点。[观战验收](spectator.json)确认改动后回滚观战、时间轴和换面检查点继续工作。

运行组件发布只替换 TH05 多人的 `th05.wasm`。

[主站验收](public.json)覆盖简体中文两人回滚、观战退出、继续菜单返回房间和同一运行组件二次开局。主站及两处镜像已同步新版本。[发布记录](published.json)与[构建输入](build-input.json)记录当前 generation 和文件差异。
