# TH12 多人激光回滚存储复用

激光快照捕获与恢复按原链表顺序复用同类型对象及曲线节点容量。类型变化时创建对应的 Moving、Timed 或 Curve 实现，数量变化时补齐或移除尾部；完整状态、虚函数行为和序列号一起恢复。该路径只存在于多人版的可复制激光管理器，普通版没有对应的快照复制入口。

| 临时分配 | 448,000 | 0 |
| 复制 CPU 耗时中位数 | 207.120 ms | 15.980 ms |

基线为 `41a13765`，保留已接入的敌人、ECL 上下文和动画资源注册表复用。同一 Windows 主机以 MinGW GCC 16.2.0、CMake Release（`-O3 -DNDEBUG`）构建，七轮交替执行；曲线激光各有 192 个节点。旧版和新版使用同一夹具与其余运行库，旧版链接基线的完整 `Laser.cpp`。[performance.json](performance.json)保留逐轮数据。测量范围为激光管理器复制，不换算为整场游戏帧率。

原生夹具 `ports/th12-mp/tests/native/multiplayer-laser-storage.cpp` 比较所有标量、扩展指令及曲线节点，七轮输出哈希均为 `65bddb9c5a97dbde`。覆盖三类激光互换、0～256 条数量变化、曲线长度变化、自赋值、独立快照、后续更新、碰撞查询、圆形消弹、回调与随机数，以及双人／三人世界恢复和持有快照跨缓存清理。稳定复制检查同时断言对象／曲线容量复用和零分配。

本轮资产无关原生检查 4/4、浏览器接口检查 23/23 通过；多人生产 SDL Web 构建通过。游戏逻辑、12 帧回滚窗口、输入采样、纠正调度和确认输出规则沿用现有实现。实际联网对局与整场帧率留待新版部署验收。
