# TH17 密集弹幕快照与长帧 · 2026-11-06

弹幕、道具和动画注册表的快照将插值数据与动画状态分开保存。已经停止的插值在内容完全相同时共享副本，活跃插值继续逐帧保存。回滚立刻废弃旧时间线，并在补算覆盖对应槽位时释放快照，沿原有回滚窗口分摊释放工作。

原生回归覆盖静止插值复用、活跃插值、几何数据和分支切换。普通版浏览器验证覆盖启动、音频、存档与原版录像。

## 正式运行包

Chromium 的每席使用独立上下文与 ANGLE D3D11，GPU 为 RTX 5080 Laptop。画面固定 1280×960，CPU 限速 2 倍，客端输入额外延迟 110 ms。窗口提交由运行包计数。

## Extra 全程

三人房使用原版 ECL、固定输入和碰撞保护，第二席输入注入 145 ms 延迟与 0–20 ms 抖动，第 9000 个确认帧起开启 2 倍 CPU 限速。两轮各有 34847 个确认帧在三端一致，跨构建的符卡起止、弹量峰值和终点一致。敌弹峰值为 1945，最终符在第 34967 个确认帧退出。

房主密集段 8713 个回调中，199 个超过 16.7 ms，其中 50 个执行了补算。超预算回调的快照捕获中位数为 8.34 ms，实际绘制为 4.00 ms，快照释放为 1.66 ms。上一版的前段有同机测试并行，后半密集段为单独运行。本轮房测顺序执行。
