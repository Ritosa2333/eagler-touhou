# 19 名角色普通射击检查

范围：高速/低速普通射击。原版依据为本地 th19.exe 命中回调、pl00..pl18.sht 的普通射击组0..9，以及对应 ANM 命中段和子动画。网页版每种模式记录第24、48、80帧。测试靶为扩大碰撞范围的耐久敌人，用于覆盖散射弹；不是正式关卡截图。

结果：38组均命中且命中结束状态无残留直接伤害；逐个查看四张总览后，未确认有某个角色的普通射击命中特效整项缺失。猯藏主动画命中后4帧删除，但独立子粒子仍在，因此采样时主命中动画计数为0不代表漏特效。

本次没有修改游戏运行时代码。此结论限于回调/资源覆盖和网页版显示，尚未进行原版与网页版相同输入下的同步逐帧画面对照，不能据此断言像素、位置、随机序列完全一致。
