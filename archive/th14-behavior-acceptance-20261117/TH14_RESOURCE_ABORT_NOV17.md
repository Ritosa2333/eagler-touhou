# TH14 资源安装取消信号 · 2026-11-17

修复启动取消信号在资源安装阶段断开的问题。归档复制及 manifest 请求已有 AbortSignal，但字体／音乐资源 fetch 没有接收它，下载／解压／哈希结束后也没有写盘前检查，页面离开后仍可能继续写入旧运行时文件系统。

## 改动

- installResources 接收并传递信号，在安装开始、每个资源、请求完成和写入前检查取消。压缩字体在解压／SHA 结束后也必须通过检查，才能创建路径和写入。
- mountManagedData 在父页请求前后、归档接管后及 manifest 解析后检查；已接管的归档保持 C++ 所有权，不因后续取消而由 JS 再次释放。
- 原生 shell 的后续配置资源安装也接入同一个 startupAbort。缓存进入不取消、真正离开才取消的既有生命周期逻辑保留。
