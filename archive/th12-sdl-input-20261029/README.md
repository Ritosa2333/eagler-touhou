# TH12 SDL 输入、菜单与呈现

多人房间标题保留上下选择，仅确认设置菜单；标题 Esc 不再退出原生应用。原生初始化和对局首帧分别记录，退出报告保存退出码、退出来源和销毁前场景，正常启动日志作为诊断数据。多人首帧附带本次 launchSerial，让启动器按房间身份接收呈现事件。

触控坐标先从 iframe 归一化坐标还原为 CSS 像素，再按画布实际边界转为 640×480。THPrac 鼠标使用既有 CSS 像素协议。触控 Esc 的 0x100 位进入 SDL 输入与按下信号，ImGui 绘制按命令启用裁剪；菜单切换和对话输入沿用原适配器的语义。正式入口内嵌样式，启动器和观战布局随入口文档一起就绪。

Web 离屏目标采用原适配器的 640×480；桌面保留 2 倍。背景纹理首次复制校验后复用存储，不再每帧等待 WebGL 错误查询。第一面 120 次采样期间进行了 786 次纹理复制，同步 getError 为 0；具体帧率与测试环境见 [validation.json](validation.json)。

[浏览器单人记录](single-browser.log)验证竖屏上滑、触控暂停、THPrac 设置点击、全屏切换和录像操作。[多人记录](multiplayer-browser.log)覆盖双人回滚、三人延迟同步、观战和确认录像。两侧 Web 与 Windows 构建完成，52 项输入、生命周期、菜单和适配器回归通过。Windows 可执行文件完成编译校验。
