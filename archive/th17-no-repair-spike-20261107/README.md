## 长帧分段

旧包加装分段计时后，6 倍限速的 P3 有一帧回调用时 68.48 ms，确认处理占 36.88 ms，快照采集占 20.92 ms，补算为零。P1 和 P2 各出现约 49 ms 的无补算回调，其中绘制各占约 22 ms。4 倍限速的另一次 55.01 ms 间隔里，游戏回调只占 9.50 ms。定时保存录像也单独计时，旧包加压采样中最长一次同步录像保存调用为 33.69 ms。[常规分段](trace-120ms.json) · [加压分段](trace-120ms-6x.json)

确认快照释放的首版对照中，三席最大的确认处理尖峰从 36.88 ms 变为 18.62 ms。该对照把释放安排到同一刷新末尾有余量时，6 倍限速滑动段为 50.989／48.859／51.894 FPS。最终测试包在同一次刷新已清理确认快照时保留余量给浏览器。[首版加压对照](optimized-120ms-6x.json)

## 复测

运行资产沿用[滑动复测入口](../th17-touch-rollback-20261107/README.md#复测入口)。设置 `TH17_ROOM_SEATS=3`、`TH17_ROOM_RENDER_SCALE=2`、`TH17_ROOM_DELAY_MS=60` 和 `TH17_ROOM_JITTER_MS=15`。用 `--trace-gaps` 记录长帧，追加 `--trace-phases` 记录更新、绘制、快照、确认、输入收发、画面提交和音频时间。`imageRelease` 为快照释放耗时，可能包含在采集、恢复或确认阶段内。
