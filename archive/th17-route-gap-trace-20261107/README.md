
`gameCallbacksMs` 累计该间隔内所有游戏回调的耗时，`betweenCallbacksMs` 记录两者的差值。每条回调的 `waitState` 按位标记补算、显式确认边界、当前场景暂停预测和对话。符卡开场对照记录在 `spellEntryGaps`。
