# 海惠堂网页单机验证

来源基线为 thkkd `64d48dc366f2d57210dbdac25be82e0e71b2641d`。Emscripten 6.0.9、Node.js 24.19.0 的完整无绘图迁移回归通过 60 用例，原有 835289 逻辑步的状态输出字节数与 SHA-256 全部相同，见 `wasm-regression.json`。

`browser-startup.json` 汇总正式 Runtime 的实际文件哈希与本次浏览器验收。环境为 Windows x64、Microsoft Edge 158.0.4370.33，使用键盘、DevTools 触控事件及启动器生产映射模型中的虚拟标准手柄。原游戏背景对照使用独立测试副本，在副屏、窗口化和静音条件下执行。网页普通一面的 WebM 视频与原作河谷视频方向及裁切一致，截图见 `original-video.png` 和 `browser-game.png`。

九种机体逐一检查原生子弹池、Bomb 消耗与效果，六面、EX 和 Omniverse 逐一检查初始化、难度、逻辑游标及实际画面，结果均通过。Practice、Replay、Music、Key Config、Options 菜单，以及暂停、原生 R 重开、退出和再次启动均可运行。对应记录为 `characters-browser.json`、`stages-browser.json`、`media-browser.json` 和 `features-browser.json`。

键盘检查覆盖默认、WASD、自定义绑定、布局保存与恢复；手柄检查覆盖生产映射、轴、按钮、断开及键盘独立持有。实际触控表面检查限速滑动、触点取消及横竖屏；共用编辑器保存布局、双指放大与复位、全屏往返均通过。输入、手势、双指返回与低速、暂时禁移、自由移动标记和录像格式的十项本作模块检查通过。共用手柄、键盘、触控布局、安装及呈现模块检查为 10/10，通过记录见本作适配状态。`launcher-controls-browser.json` 保留原生位置变化和实际页面结果。

原版 EX 录像成功加载 73458 字节输入流，暂停保持游标，前进定位 240 和回退定位 60 均通过。实际键盘录制经原作保存询问、槽位和命名流程写出 `.rpy`；实际触控坐标录制写出带版本和原生流哈希的 `.thkkdr`，重新打开后的游戏状态、RNG 和计时与录制结束点一致。原作在 `cursor + 1 == count` 时停片的规则保留。`replay-browser.json` 和 `features-browser.json` 分别记录这两组验收。

同一正式 WASM 由 60、120、144 Hz 时间序列驱动，自由呈现次数分别为 121、241、289，启用 60 Hz 限制时均为 121；原生状态、RNG、逻辑计时和录像游标一致。固定逻辑状态额外呈现 100 次后，状态、文件清单和音频事件不变，判定点常显只存在于绘图命令中。实际高刷物理显示器、实体触屏、实体手柄及其他浏览器引擎的人工体验未执行。

音乐检测取得实际非零 PCM，标题切入关卡、视频纹理更新、BGM 与视频暂停继续、平台挂起恢复和无 BGM 模式均通过；损坏 OGG 注入触发生产音频健康错误事件。SFX 在 BGM 等待期间直接建立并启动音效节点，音乐与音效增益独立。保存刷新及退出重开通过；六个原版配置和存档文件的共用 ZIP 导入导出及覆盖确认通过文件服务 25 项回归。正式站点安装后关闭实际 HTTP 服务并启用浏览器离线模式，刷新、启动和读取同一份持久化数据均通过，见 `storage-browser.json` 和 `offline-browser.json`。

当前源码通过 UI TypeScript 检查。原始核心和显示源码相对来源提交保持原字节，迁移回归继续复用固定 60 个原始用例；此次功能边界变化另由上述正式 Runtime 验收覆盖。构建、资源转换与本地交付命令见本作开发说明，最终交付的 `SOURCE.json`、`PACKAGE-MANIFEST.json` 和 SHA-256 清单关联当前提交与产物。
