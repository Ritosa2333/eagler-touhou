# TH17 多人战斗、结算与录像 · 2026-11-06

多人战斗采用就近瞄准、Bomb 队友无敌和水獭灵全队护盾。满 P 席位能把 Power 引向最近的未满 P 队友，双人小 P 加 0.02，三人小 P 加 0.03。六面阴阳玉按原版 ECL 渐显，结算菜单处理 Player’s Score 和原版按键音效。

录像在结局及排名菜单期间沿用本局末关编号。播放与暂停拖动会提交新画面，录制时的运行包身份继续用于核对玩法规则。

桌面 Chromium 在同一页面内运行双席或三席，CPU 限速 2 倍，客端输入额外延迟 110 ms。旧版 1280×960 与新版 640×480 对照中，房主平均呈现从 13.8 到 30.9 帧/秒（双人）和从 11.8 到 26.9 帧/秒（三人）。该对照衡量新版默认配置的整体效果。双人和三人分别比较 1,053 和 1,052 个确认帧，验证了录像保存、持续呈现及暂停定位。六面原版 ECL 和贴图、Power 转交和水獭护盾回滚另外通过原生检查。
