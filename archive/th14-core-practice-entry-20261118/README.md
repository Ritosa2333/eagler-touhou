## 反例与修复

旧公开核心的灵梦 A Normal 实际普通开局后，经生产相同保存路径落盘，进入标志仍为 0，新增回归明确失败。修复后六自机分别经正常菜单进入 Normal 第一关、保存并退出，再启动全新 Application 读回，六写／六读均通过：第一关进入标志为 1、完成标志为 0；所有其他自机／难度／适用关卡的进入与完成标志保持 0。

六份新存档由原版 `4028e0`／`465840` 解密解压指令及独立镜像读取，每份 149,076 字节全相同。序列化角色编号和校验和与运行时记录按 `ScoreFile::save` 的明确转换对应；新进程读取的全部解码字节相同，读取后文件字节保持。仅控制 CRT 分配／复制／释放边界，未修改原版指令。

重新执行既有原版进入关卡指令参考的 450 项：六自机适用关卡／难度共 150 个普通控制项写入进入标志，300 个非普通控制项保持记录。该参考与六次实际 C++ 流程分开计数，不把受控指令段称作原版整局通关。
