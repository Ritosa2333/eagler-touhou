# TH17 Extra Boss 三人回滚压测 · 2026-11-06

三人 WebRTC 房使用 TH17 1.00b DATA，BGM 关闭。来宾席位二的输入和补发增加 145 ms 单向延迟及 0–20 ms 抖动。碰撞保护和固定输入由独立诊断构建提供，敌机、弹幕及符卡由原版 ECL 运行。两版的关底 Boss 测量使用 2 倍 Chromium CPU 限速。基线从开局限速，复测在第 9162 个确认帧启用限速。

两版分别比对 14880 个三端确认帧，关底段落和第 15000 帧终点状态一致。测量覆盖关底前四张符卡，进入第五段非符。Wasm 活跃堆全程采样峰值为 465.5 → 357.8 MiB，256 颗敌弹以上的采样峰值为 313.3 → 323.6 MiB。密集组纠错回调分别取 113 和 90 个样本，实际绘制每次平均 1.14 和 1.19 ms。[基线房间](baseline.json) · [优化版房间](optimized.json)
